## 2. Q1 设计/案例 vs 优化：5条证据 + 结论

### 证据E1：可行性报告**自己已经判断**

可行性报告原文（已MD化、可验证）：
> "本项目采用的核心简化方法，**不追求精确求解'最优容载比'的复杂模型，而是通过场景对比来获得规划建议**。"

→ 项目方已主动**放弃**优化路线，选定"场景对比"。**这是最强证据。**

### 证据E2：4项核心交付物中3项是"表/规则/建议"

| 交付物 | 形态 | 优化 vs 设计 |
|--------|------|----|
| 参数化电网建设成本公式 | 回归公式 | 参数估计（非优化） |
| 方案A vs 方案B 全寿命周期成本对比 | 对比表 | 情景对比（非优化） |
| AHP容载比多准则决策模型 | 判断矩阵+决策表 | 决策支持（非优化） |
| "一片一策"弹性容载比规划建议表 | 分类决策矩阵 | 决策支持（非优化） |

→ **没有一个**交付物形态是"求解最优解"。

### 证据E3：4个对标期刊样本的"路线分布"

| 期刊 | 主导路线 |
|------|--------|
| 浙江电力 | 优化（宋钰、徐非非）——投稿门槛高 |
| 山东电力技术 | 工程方法+案例（刘佳男） |
| 湖北电力 | 工程方法+建议（李胜洪、杜剑、王文娜） |
| 广西电力 | 工程方法+技术路线（李欣桐） |

→ **6/7篇**对标期刊样本走"设计+案例"路线。本课题论文若投稿对标期刊，**走优化路线反而格格不入**。

### 证据E4：合同要求"创新性不高"

合同条款明确：项目"创新性要求不高"。**优化研究**必须在算法层有新意（否则被审稿人否决），**设计/决策研究**只要在体系/思路上有新意即可。后者匹配度更高。

### 证据E5：数据样本规模不足以支撑优化

徐州地区110kV变电站样本数量级（数十座、5年数据），**不足以**支撑数据驱动的优化算法的训练-验证-泛化流程；典型变电站典型工况的5-10个案例点，**正好**适合"案例驱动的决策支持"。

### Q1 结论

**本课题应做"案例驱动的设计+决策支持研究"，不应做"优化问题研究"**。

具体定位是：
- **骨架**：方案A vs 方案B 的LCC情景对比（不是"找最优"）
- **血肉**：徐州5-8个典型片区的实测案例（不是"算例验证"）
- **皮肤**：AHP+等百分位+决策矩阵（不是"目标函数+约束+求解器"）

## 3. Q2 研究思路与目标是否需要调整：3处微调 + 1处重写

### 3.1 原研究思路（来自可行性报告）

```
① 数据库构建（新能源渗透水平-电网运行状态关联）
② 多场景电网规划方案与成本模型构建
③ 基于成本最优的弹性容载比决策分析
```

### 3.2 调整建议

#### 调整1：突出"反向极值校验"维度（💡 微调）

**问题**：原思路把"反向重过载"放在背景里一笔带过，但实际上：
- LCC对比方案A的核心技术触发条件就是反送越限
- 2025导则新增的"装机渗透率>2 或 电量渗透率>40%-50%"判据全部围绕反送
- F1刘文霞色带、F5李胜洪都明确指出反送是关键变量

**建议**：在数据库构建（步骤①）中**独立**列出"反向极值场景"维度，与"夏冬重载"并列；在LCC对比（步骤②）中**双向Z4**分开计算。

#### 调整2：AHP前置一道"鲁棒性测试"（💡 微调）

**问题**：F1刘文霞、F2刘炜彬都隐含一个风险——AHP权重容易陷入"专家共识=原导则"的自我强化循环。如果徐州地区咨询的专家就是当年制定≤2.0标准的同一批人，权重会向"维持≤2.0"倾斜，弹性结论会被稀释。

**建议**（方案A，2026-06-12定）：
- **论文**：权重由课题组结合徐州规划运行经验赋定（如实表述），以**±20%权重扰动敏感性测试**证明结论稳健——这同时也是对"专家共识=原导则"自我强化风险的缓解手段
- **主报告（可选增强）**：数据收资沟通时请甲方3-5名规划/运行工程师填一页两两比较打分表，几何平均聚合
- 注：合同报价表中专家咨询费为0，**不存在也不主动要求正式专家咨询会**

#### 调整3：决策矩阵不必追求完备（💡 微调）

**问题**：(源荷比×渗透率×联络度) 三轴若都分3档，理论上27格。但徐州实际案例**最多覆盖6-9格**，剩余格强行填值会失真。

**建议**：
- 明示"已验证格"（6-9个，基于真实案例）
- 明示"规则推断格"（10-15个，基于专家知识+插值）
- 明示"待补充格"（剩余）
- 论文中只展示已验证+规则推断格；技术报告中保留三类完整标注

#### 调整4：第3步"基于成本最优"的措辞需要重写（🔥 重写）

**问题**：原文用"基于成本最优"会让读者期待数学优化结果，但实际给出的是"成本最低方案+决策建议"——**期望管理失败**。

**建议**：将"基于成本最优的弹性容载比决策分析"重写为：

> "基于成本对比与多准则决策的'一片一策'弹性容载比建议生成"

——明确"对比+决策"代替"最优"，匹配真实交付物形态。

### 3.3 目标合理性审视

原目标摘录：
> "在徐州分布式新能源高渗透率地区，开展容载比相关的多项统计分析，量化不同容载比条件下电网建设成本，给出不同指标下经济性最优的电网规划方案建议，基于负荷、分布式光伏预测形成经济性最优的容载比弹性指标优化方案。"

**判断**：目标可达成，**两个"经济性最优"**措辞需要弱化为"经济性更优"或"全寿命周期成本可比的"，理由同调整4。
