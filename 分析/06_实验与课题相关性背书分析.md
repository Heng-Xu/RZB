## 2. 四个相关性缺口详析

### X1 🔴 低渗透段方案B恒优 —— 反噬课题叙事（最重要）

**数据证据**：`sweep_penetration.csv` 第一行：PV=500kWp（源荷比0.135、电量渗透率4.2%）时方案B仍占优 +17.0万/年；整条曲线15个点**无一处A占优或两案重合**。

**为什么这是问题**：
1. **课题叙事被反噬**。课题的立项逻辑是"高渗透率带来了新问题，所以需要弹性指标"。但实验显示弹性在**任何**渗透率下都更便宜——那弹性就不是高渗透的特殊需求，而是"刚性方案天生贵"。审稿人会问：低渗透片区导则也错了吗？
2. **甲方政治风险**。甲方是国网公司，论文结论不能等价于"现行导则的容载比约束在一切场景下都不经济"——这超出了课题授权（课题要的是"高渗透地区的弹性优化"，不是"推翻导则"）。
3. **根因在场景构造**：`make_plan_a` 不管渗透率多低都强制购买2km联络+按PV装机10%×2h配储。低渗透时反送根本不越限（导则也不要求校验），这些投资是**无效强制消费**——B的"优势"在低渗透段是A被冤枉出来的。

**最小修复**（约1天）：把方案A的措施改为**校验触发式**——
```
if 源荷比>2 或 电量渗透率>40%（2025导则判据）:
    A配储容量 = 反送超限量驱动（而非固定比例）
    A联络加强 = 触发
else:
    A无额外措施（A=纯刚性主变，与B在低渗透段成本重合/略优）
```
修复后预期曲线形态：低渗透段两案重合 → 越过导则判据阈值后分叉、B占优 → 92%渗透后B回落。**这条曲线才是课题想要的故事**："导则在传统场景仍然有效，弹性指标是高渗透场景的增量工具"——既支持课题又不否定导则。

### X2 🔴 主变自身损耗未建模 —— "110kV容载比"与实验口径错位

**数据证据**：`lcc_simulator.py` 中 `bidirectional_z4_loss` 只计算10kV馈线电阻损耗（`branch r_ohm`），全文无变压器空载损耗P0/负载损耗Pk项（grep确认0处）。

**为什么这是问题**：
1. 论文标题与课题对象是 **110kV电网容载比**，容载比的载体是**110kV主变**；而Z4实际算的全是10kV馈线损耗——"双向Z4"创新点声称的"反向时主变损耗特性变化"（α_rev=1.2的注释理由）在公式里根本没有对应项。
2. 电力专业审稿人对变压器损耗模型（P0+β²Pk）非常熟悉，对照公式即可发现缺位。
3. 更关键：**主变损耗才是容载比敏感项**——容载比高=主变容量大=P0（空载损耗，常年存在）大、β（负载率）低；容载比与Z4的真实耦合主要通过主变，不是馈线。当前模型里R对Z4几乎无影响，等于砍掉了"容载比-损耗"通道。

**最小修复**（约0.5-1天）：Z4补主变项——
```
Z4_tx = P0(S_rated)×8760 + β_fwd²×Pk(S_rated)×t_fwd + α_rev×β_rev²×Pk(S_rated)×t_rev
其中 β = 潮流/S_rated；P0、Pk 按容量从典型参数表插值（公开数据可得）
```
这一项加入后，"容载比越高→P0越大"的反向激励进入模型，方案B的大主变开始付出损耗代价——结论更立体，也补上了α_rev的物理落点。

### X3 🟠 联络度对R无效 —— 与课题第二层理论（肖峻TSC）脱节

**数据证据**：27格矩阵中，联络度弱/中/强三档下的R分布完全相同（每档都是{1.5, 2.3, 2.6}），CD只改变成本数值与技术方案文字。

**为什么这是问题**：可研明确把"联络度→上级容载比弹性空间"列为三层理论的第二层并引用肖峻2015；论文文献综述必然要引肖峻。如果实验里联络度对R**零影响**，审稿人会问"你引的理论在你的结果里去哪了"——理论框架与实验结果脱节。

**根因**：当前模型中CD只是方案A的联络建设量参数，没有建模"联络强→站间互济→同等可靠性下允许更低R"的机制（这正是TSC理论的内容）。

**两级处理**：
- **最小（写作策略，0天）**：论文中明确声明"联络度对推荐区间的修正依赖站间转供能力建模（TSC），属后续工作"，矩阵只声称源荷比主导——诚实但削弱第二层理论的存在感。
- **建议（修复，1天）**：在候选R的可行域中加入联络度修正——CD强时允许的R下限更低（站间互济可覆盖N-1缺口），即 `R_min(CD) = R_base - k×CD`（k由肖峻文中的量化关系标定）。修复后矩阵在"低源荷比×强联络"格会出现比1.5更低或区间下移的推荐，联络度轴恢复效力，肖峻理论有了实验落点。

### X4 🟠 正向压力（夏冬重载）维度缺失 —— "源荷双向"只验证了一半

**数据证据**：`penalties.outage_cost_yuan_per_kwh: 15`（VOLL失负荷成本）在YAML中定义但代码0处引用；模型中低R方案没有任何供电不足/可靠性代价。

**为什么这是问题**：
1. 课题问题陈述是"夏冬重载、春秋反送"**双向**压力；实验只让反向产生成本（Z4反向+弃光），正向重载没有任何惩罚——于是低源荷比格推荐R=1.5（最小主变最便宜），这正是"正向风险免费"的产物。
2. R=1.5的推荐与导则"快增长地区1.8-2.0"冲突（G10已指出负荷增长轴缺失），两个问题同源：**模型里没有"容载比过低的代价"**。可研L1明确说"容载比过低→供电能力不足、频繁扩容、应急成本高"——课题自己的第一层理论在实验里只实现了右半边（过高→浪费），左半边（过低→风险）缺位。

**最小修复**（约0.5天）：启用已定义的VOLL——给每个R档计算正向N-1场景的期望失负荷成本：
```
EENS ≈ max(0, 峰荷×(1+增长率)^n − 主变N-1剩余容量) × 持续小时 × 概率
Z_reliability = EENS × VOLL(15元/kWh)
```
即便用粗的解析近似，也能让低R在重载场景付出代价，低源荷比格的推荐自然回到导则区间（1.6-2.0），与导则衔接的问题（G10）同时缓解。

## 3. 修复后论文叙事预期（论文可声称 / 不可声称清单）

### 修复后可以声称（有实验背书）：
1. ✅ 在源荷比/渗透率低于导则判据时，刚性容载比仍是经济的（X1修复后）——**与导则一致**

3. ✅ 弹性放宽存在适用边界（电量渗透率≈90%级别），超界需"弹性+配储"组合
4. ✅ 推荐区间随源荷比分档单调上移，与2025导则"源荷比>2校验反向"判据衔接
5. ✅ 结论对折现率（4-8%）与储能成本（降50%）稳健
6. ✅ 三地区PV资源差异改变反送强度，验证"一片一策"的区域必要性
7. ✅（X2修复后）容载比通过主变空载/负载损耗影响LCC的双向机制
8. ✅（X3修复后）联络度强的片区推荐区间可下移——肖峻理论的实验呈现

### 任何情况下不可声称（无证据或超范围）：
1. ❌ "徐州地区实测数据表明……"——当前全部算例是IEEE33+公开数据，徐州只有PVGIS气象资源数据（论文必须如实写"以典型测试系统与公开气象数据验证方法"）
2. ❌ "弹性容载比在所有场景下优于刚性"——X1修复前这是结果但是错的，修复后这不再是结果
3. ❌ "等百分位分档结果"——未实现（B轨），论文用导则典型档位并声明
4. ❌ 对27格矩阵声称"已验证"——基础是单测试系统参数扫描，论文措辞用"方法演示"
