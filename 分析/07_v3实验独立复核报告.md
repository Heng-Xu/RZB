## 1.5 🔴🔴 最严重（结构性）：基准对比根本没用决策方法

承重的渗透率扫描（`sweep_penetration.csv`，论文"弹性 vs 刚性"主图）调用 `make_plan_a` / `make_plan_b`，二者把容载比**写死**：
- `make_plan_a`：`tx_a = peak_mva × RIGID_RATIO` → R 恒 **2.0**（`lcc_simulator.py:395`）
- `make_plan_b`：`tx = peak_mva × elastic_ratio`，`elastic_ratio=2.3` 默认 → R 恒 **2.3**（`lcc_simulator.py:412-416`）

**即主图是"固定 2.0 vs 固定 2.3"的对比，全程不调用决策矩阵。** 后果：
1. 课题的核心命题是"按片区特征**自适应**推荐 R（一片一策/决策矩阵）优于刚性单值 2.0"。但这张主图比的是两个**固定**值，**没有检验自适应方法本身**。
2. 低渗透段决策矩阵本应给 B 选 R=1.5（比 A 的 2.0 **更小、更便宜**），可扫描把 B 钉死在 2.3（更大），于是 B 被人为做成全程贵 ~18 万——这正是"近乎恒定的 −18 万偏移"的来源（B 多背 0.3 倍主变的 capex+P0 固定罚项）。
3. 真正该画的主图是 **"决策矩阵逐格选 R" vs "刚性 2.0"**：低渗透 B 取 1.5 省钱、高渗透 B 取 2.3-2.6 省钱、中间回 2.0——这才是"弹性双向"的正确呈现。当前代码从未运行过这个对比。

**这条比任何单个 X 缺口都根本**：哪怕 X1-X4 全修好，只要主图仍是固定 2.0 vs 固定 2.3，论文的中心实验就和中心论点脱节。

## 2. 逐项复核（X1-X4）

### X2 🟢 主变损耗 —— 正确
`lcc_simulator.py` `transformer_z4_loss` 实现 `P0·8760 + Pk·β_fwd²·t_fwd + Pk·β_rev²·t_rev·α_rev`；P0/Pk 按 S_rated 缩放（系数 0.0007 / 0.0045 kW/kVA，SZ11 级），α_rev=1.2 仅作用于反向项，量纲一致，β∈[0.5,0.78] 物理合理。这是 R→主变容量→P0 的真实成本通道，也是低渗透段 A 占优的物理来源。**保留。**

### X1 🟠 触发式场景 —— 实现了，但触发点错位、叙事被数据否证
已提交 `sweep_penetration.csv` 全 15 点 winner/Δ（Δ=B−A 年化万元，负=A 优）：

| pv | 源荷比 | 渗透% | Δ万/年 | winner |
|----|-------|------|--------|--------|
| 500–9000 | 0.135–2.42 | 4.2–75.1 | **−18.0（近乎恒定）** | **A** |
| 10000 | 2.69 | 83.5 | +8.67 | B |
| 11000 | 2.96 | 91.9 | +18.21 | B |
| 12000 | 3.23 | 100.2 | +8.27 | B |
| 13000–14000 | 3.50–3.77 | 108–117 | −3.26 / −16.38 | A |

**问题**：
1. 无"低渗透两案重合"——A 从源荷比 0.135 到 2.42 **一路严格便宜约 18 万/年（≈1.9%）**，是恒定差，不是收敛。
2. 触发点 ≠ 导则判据。代码按 R=2.0 反送越限触发（源荷比≈2.55 / pv≈9492），而非 spec/导则要求的"源荷比>2 或 渗透>40%"。在源荷比 2.15（pv 8000）、2.42（pv 9000）A 仍占优——**`实验/03` 的"弹性优势精确出现在导则源荷比 2 阈值之上"被否证**。
3. B 的占优窗仅 3 点（源荷比 2.69–3.23），且幅度 ≤1.7%——论文承重论点"弹性更优"的证据极薄。

### X3 🟠 联络度→R —— 退化（中=强）
`decision_matrix_raw.csv` 低源荷比段：弱(0.15)→R 1.8 / 成本 919.31；中(0.45)→R 1.5 / 889.37；强(0.80)→R 1.5 / **889.37（与中逐字相同）**。CD 仅经 N-1 项（`n1_transfer=cd·peak_kva`，需 `R<2(1−CD)` 才生效）影响，0.45 与 0.80 都让 R=1.5 免责，故**中、强机械等同**，"弱 1.8→中 1.5→强更低"的梯度叙事不成立。附：弱联络行 tech_scheme 仍标"强联络互济支撑"——标签错位。

### X4 🔴 N-1+VOLL 可靠性 —— 输出全程为 0（最严重）
`decision_matrix_raw.csv` 的 `reliability_wan` 列在**全部 27 格均为 0.0**（0/27 非零）。同样地 A/B 渗透扫描与 PV×R 扫描默认 CD=0.45 下可靠性恒为 0。X4 的全部目的（让低 R 在正向重载付代价、补"容载比过低的代价"左半边）在已发布结果中**未产生任何效果**。`实验/03 §2.1`"低 R 在重载付出代价、正向重载不再免费"在数据中为假。X4 另缺 spec 要求的负荷增长 `(1+growth)^n` 项，无法表达导则"快增长区需更高 R"。

## 3. 发现的 BUG（reviewer 提出，按严重度）

1. **[高] 弃光电量未从 Z4 反向潮流中扣除**：`tx_rev_kva = pv·0.9 − load_min − storage` 忽略 curtailment，B 在高渗透段被按未弃光的全额反向功率计损，人为抬高 B 的高渗透成本，**部分制造了"极高渗透回 A"区间（pv≥13000）**。修法：损耗计算前从反向潮流中扣 `curtailed_kw`。
2. **[高] X4 在默认 CD=0.45 下完全失效**（见上）。修法：降低默认 CD 或重标定 N-1 过载因子，使 R∈[1.5,2.0] 在 CD=0.45 时可靠性项起作用；否则所有 X4 结论须限定"仅弱联络格"。
3. **[中] X1 触发阈值 ≠ 导则判据**：改为按"源荷比>2 或 渗透>40%"门控，或诚实地把触发改称"反送越限判据"并放弃"导则判据"措辞。
4. **[低] X3 中=强**：把 R 下限改为连续 `R_min=R_base−k·CD`。

**修复后诚实结论（替代v3的"弹性恒优"）**：
1. 🟢 **升方向稳健**：高渗透→刚性2.0次优、应放宽（升R2.3-2.6或长反送下"中R+配储"）；对负荷增长g(2-8%)、折现率、储能成本均稳健（g×n 15/15 组合高渗透≥2.3）。
2. 🟠 **降方向条件性**：下探floor随负荷增长在 {1.5,1.8,2.0,2.3,2.6} 全程漂移（`sensitivity_growth.csv`/fig9）——advisor 预警的(g,n)脆弱性经 g×n 扫描证实，**不可headline固定1.8**，须作条件性表述。
3. 🟢 决策方法相对刚性2.0节省 **2-4%**，物理可解释、复现确定。
4. 区域三地最优R均1.8（同源荷比），气候差异改变反送暴露量级而非R；高真实反送时长(~3000h)下升方向落到"1.8+配储"而非升R2.3（t_rev-PV耦合，已作局限披露）。
