# 四、Rcap 的科学解释

后续不能再简单把 Rcap 理解为：

“每个片区都需要一个最佳容载比数字”。

应理解为：

**一个可能对规划新增容量产生约束作用的弹性规划参数。**

首先判断：

1. 当前片区是否需要新增容量；
2. Rcap 是否实际绑定；
3. 是否存在其他更先发生的技术约束；
4. 是否形成经济释放阈值；
5. Rcap 改变是否会改变最优规划方案；
6. 只有满足这些条件时，才讨论推荐区间或推荐阈值。

最终应形成类似：

“约束类型识别 → Rcap 有效性判断 → 阈值识别 → 工程建议”

的决策逻辑。
