# 论文写作与投稿方案

## 投稿决策
- 首选 **山东电力技术**（审稿2-4月、案例风格匹配、创新容忍中等）。
- 备选：湖北电力（修改最小）> 浙江电力（审稿慢3-5月、偏优化路线）> 广西电力。
- 硬截止 **2026.07.31投稿**；若9月底未录用立即转投湖北电力。

## 标题与结构
- 主标题：《高分布式新能源渗透率下110kV电网容载比一片一策决策方法》
- 5章约6500中文字符、公式10-12、图6表3（对标山东电力技术刘佳男范式）。
- §1引言 §2弹性指标与决策框架 §3双向Z4-LCC模型 §4算例(IEEE33+三地+决策矩阵+敏感性) §5结论。

## 论文主创新点（写作锚点，v4诚实版）
1. 首次在LCC成本结构显式建模反送电能损耗（Z4反向分量+主变P0/Pk双向）。
2. (源荷比×电量渗透率×联络度)三维分类决策矩阵应用于110kV高压配电层；决策方法相对刚性2.0节省2-4%。
3. **弹性多维条件性（2026-06-18 口径修正后修订；详 paper/01）**：**承重结论=刚性单值2.0系统性次优→须按(源荷比×电量渗透率×联络度×反送时长)差异化整定**（对g/折现率/储能/N-1假设均稳健）。**方向值是条件性示例、勿作独立headline**：升方向2.3仅在反送1362h成立，实测~3000h翻转为"1.5+配储"（升值对t_rev敏感）；降方向条件于N-1过载k_ol(1.0/1.1/1.3→floor 2.0/1.8/1.5)且低于导则下限1.8、本质为主变N-1定容、与高渗透DG弱相关。

## 可声称（有实验背书，v4）
- 刚性单值容载比2.0系统性次优；决策方法相对2.0节省2-4%（IEEE33+公开数据+PVGIS气象"方法演示"）。
- **升方向稳健**：高源荷比/高渗透（>导则反送判据）下应放宽容载比（升R至2.3-2.6，或长反送下转"中R1.8+配储"）。
- 联络度增强允许降低容载比（肖峻TSC的LCC量化），在中等负荷增长下最显著。
- 弹性优势对储能成本/反送时长敏感（条件性恰是"一片一策"依据）。

## 不可声称（红线，v4扩充）
- ❌"徐州实测电网数据"（只有PVGIS气象；拓扑用IEEE33）
- ❌"弹性在所有场景占优 / 弹性恒优"（已证伪）
- ❌**固定下探floor=1.8**、**三区段结构**、**"弹性优势精确出现在源荷比2之上"**——均为v3过度声称，已废（详[[experiment-model-design]] v4）
- ❌降方向给单一数值（须以g×n敏感性fig9作条件性呈现）
- ❌等百分位实测分档（B轨）；矩阵措辞用"方法演示"非"已验证"
