# 当前工作：四年更换间隔下按当年总费用逐年比选

本轮按用户同意的讨论结论重算两地区2021—2035年方案。正式六章、Word/WPS PDF及冻结采用案例未替换。

## 模型与入口

入口：`实验/研究/rebuild_2026/annual_cost_interval_2035_20261017`。原始解：`研究报告/试算/20261017_四年间隔总费用2035/{city,pizhou}/{rigid,elastic}`。

2021容量固定为市区3113.50 MVA、邳州2027.00 MVA。2022—2035逐年以上年在役设备和当年源荷求解。两次原主变位置更换年份之差至少为4，为研究工程实施假设；基期既往更换年份缺失，从2022年记录。主变、储能、付费联络投运后逐年承接。新购31.5、50、63、80 MVA，允许扩建位置第三台按50 MVA。

刚性、弹性共同使用当年新增主变、储能和联络总费用现值目标，取消配套费用20%容差和少建联络优先阶段。共同容载比下限、逐站转供MW预算、路径和源馈线组、受端余量、初始容量及锁定经济参数不变。刚性保留新增容量2.0控制，弹性取消该控制；无刚弹结果排序约束。

原时序库按路径和哈希继承，未重复复制。历史源荷为模板回算和补值序列，2025转供收资用于早期年度，EQ拓扑和区段为研究代理。邳州2021固定设备的事故缺口单列，未加入基期虚拟储能。储能按额定功率与可用电量/时长静态校核，无连续SOC优化。

## 结果

市区2035rigid：容量3566.00 MVA，容载比1.60，年末储能32.80 MW（70.52 MWh），累计新增联络68条，费用现值38479.14万元。年度最大条件费用间隙7.60%。

市区2035elastic：容量3563.00 MVA，容载比1.60，年末储能23.60 MW（50.74 MWh），累计新增联络65条，费用现值37012.96万元。年度最大条件费用间隙9.08%。

邳州2035rigid：容量2674.50 MVA，容载比1.90，年末储能234.80 MW（504.82 MWh），累计新增联络57条，费用现值56503.34万元。年度最大条件费用间隙3.44%。

邳州2035elastic：容量2814.00 MVA，容载比2.00，年末储能180.30 MW（387.64 MWh），累计新增联络57条，费用现值49545.72万元。年度最大条件费用间隙2.66%。

后期停止新增储能的能力检验逐年继承本轮上年资产，固定已有储能，原主变位置取四年间隔允许的最大候选规格。分别固定已有联络和开放新增联络自由选择，可行配置再核对全年。此为单年反事实，非连续不新增储能链。

市区2031—2035，只新增主变且不新增储能的可行年份：2031。
市区2031—2035，新增主变及联络且不新增储能的可行年份：2031、2032、2033。
邳州2031—2035，只新增主变且不新增储能的可行年份：无。
邳州2031—2035，新增主变及联络且不新增储能的可行年份：无。

原设备表46座有对应站点中，9座预留扩建容量超过50 MVA：63 MVA五座、80 MVA一座、100 MVA三座，均为1个预留位置。扩建工程造价原表仅提供50 MVA实例。本轮第三台候选仍为50 MVA，超过50 MVA的工程费用存在资料缺口；不可行结论仅对当前候选集成立。

费用按具体可行方案列示，年度条件下界和间隙保留，不宣称全期联合最优。前后比较同时改变更换间隔和选择顺序，差额为合并影响。
