# 当前工作：转供机制审查，待从2021重算两地区至2035年

用户否定上一版市区前推方案，指出免费转供及站间互济过于容易，要求两方案容载比下限相同，并希望弹性以较高容量替代较多储能和新增10kV联络。后续明确先分析转供应如何调整、对着结果目标找方向。本轮先完成机制审查及2025单年方向筛查，尚未生成新的2021—2035两地区全套逐年方案。正式报告及已确认20261015结果保持原文件，上一轮市区前推仅保留搜索与诊断依据，不作为本次采用结果。

## 发现与方向

市区168条既有模型边全部为按总转供率标定的EQ假设边，邳州77条中76条为EQ、1条为局部路径T01。全停全转原表提供J/K、线路数、不能全转原因，并不能直接确定上述站对连接、双向能力和各时刻任意切换。标定网络在正常与各故障截面独立重配供区，是本轮主要审查对象。

固定上一版市区2035设备，只关闭正常既有免费转供，两组49个正常截面均有13个失败，最大约束松弛分别93.64/80.02 MW；再限制事故只允许直接邻接时，N-1分别377/472个失败。数字是约束不满足程度，不是预计失负荷。只保留有路径证据的既有边属于资料覆盖下界对照，不能推断其余真实线路不存在。

拟调整为：既有事故能力不自动用于日常优化；正常方式登记固定供区，新增付费项目可改变正常供区；事故在原正常方案上限于本接线组及可达邻接区段追加切换；区段负荷与光伏由同一切换动作转移，资源共享与源端、线路、接收侧余量共同约束。正常禁用和直接事故限制是保守工程策略，不冒称标准逐字强制。

## 单年方向筛查

同一2021实际地区容量设备起点，2025只决定单年措施，市区两组共同下限1.50、邳州1.70。禁用正常既有免费通道、保留付费正常转供、事故仅直接邻接，不施加跨方案结果排序。市区刚/弹容量3113.50/3140.50 MVA，储能126.64/0.00 MWh，新增联络0/0条；邳州容量2027.00/2148.50 MVA，储能201.24/4.09 MWh，联络4/4条。四组费用求解间隙为零。

在邳州弹性费用参考5926.91万元的5%费用容差以内优先减少联络，得到2148.50 MVA、7.74 MWh、3条联络，费用6171.93万元、增幅4.13%。相对刚性三项方向均达到用户目标。该5%为工程优选条件，非标准条款或纯费用最优。费用参考保留，未施加容量或储能跨方案排序；市区两组零新增联络如实相同。共5套单年方案、4338个静态工况通过；尚未保证所有未来年度都有相同排序。

用户结果目标作为工程优选条件，与标准安全约束分别登记。2021共同起点本应相同，零新增联络年度保留相同，不制造无必要工程。
