# 徐州地区分布式新能源高渗透率110kV电网容载比弹性指标优化研究

## 研究本质判断（已定，[[experiment-model-design]]）
- 是**案例驱动的决策支持研究**，不是数学优化问题（5条证据支撑，可研原文"不追求精确求解最优容载比"）。
- 核心交付：(源荷比×电量渗透率×联络度)→(推荐容载比区间×技术方案) 的**分类决策矩阵**（"一片一策"），不是一条优化方程。
- 三层理论：①容载比-成本非线性 ②联络度→容载比弹性空间（肖峻2015 TSC）③全寿命周期成本LCC对比（年费用法，Z1-Z5）。仅第三层是本课题真做的部分。

## 论文核心结论（v4实验，2026-06-15独立复核+修复后；[[experiment-model-design]]）
- **v3"弹性恒优"已废**：v3独立复核（分析/07）发现承重缺陷——主图比的是固定2.0vs2.3（从不调用决策矩阵=G0）、X4可靠性恒为0、弃光重复计损。已修复为v4。
- **双向且条件性的弹性**（诚实论点，替代v3）：刚性单值2.0系统性次优；决策方法（逐档选最小LCC的R）相对2.0节省**2-4%**。
- 🟢 **升方向稳健**：高渗透/高源荷比→应放宽（升R2.3-2.6，长反送下转"中R1.8+配储"）；对负荷增长(2-8%)、折现率、储能成本稳健。
- 🟠 **降方向条件性**：容载比下探floor随负荷增长g在{1.5,1.8,2.0}漂移（g×n敏感性fig9）——**不可声称固定floor=1.8**，须条件性表述（饱和区降1.5、增长区守2.0）。advisor预警的(g,n)脆弱性已证实。
- X3联络度梯度（弱2.3/中1.8/强1.5）真实但清晰度依赖g（经X4的(1+g)^n N-1校核产生）。
- v4新增`sensitivity_growth.py`/fig9；v3结果备份于`实验/results_v3_stale/`。详见`实验/03`(v4)、`分析/07`§6。
