# 既有转供量与约束调整讨论

用户已选定正常允许调整供区的弹性无下限、刚性作为后续报告的数据与模型版本，两地共4组。版本号为`case_station_caps_normal_adjust_20261013`，详见`报告采用版本说明.md`；其余8组保留对照。
