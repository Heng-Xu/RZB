有效组指固定其余独立输入后、变化项至少有两个有效节点的背景组。有效节点指实际进入该项组内相关的节点。Pearson先组内去均值再汇总，节点等权，零容量响应组保留；Spearman在组内排序后采用相同受控范围。电量、反向净负荷及站级负载率沿电量序列统计，正向净负荷沿增长序列统计，两项投资比分别沿独立价格序列统计。系数描述本次有效仿真库。
