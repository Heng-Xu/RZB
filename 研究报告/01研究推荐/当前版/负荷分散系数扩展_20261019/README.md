# 负荷分散系数11节点推广数据

分散系数1.05—1.25，间隔0.02，共11点；展示以1.15分成两档。完整设计127578组，可行112437组、不可行15141组。各分散节点使用相同的源荷和网络联合域，并包含同样的增长边界补充。

- 推广矩阵与11点敏感性分析.xlsx：六张矩阵、288单元窗口依据、三个窗口宽度候选及11点完整序列。
- 统一有效样本.csv：全部112437个有效节点，保留完整精度及设备、费用。
- 不可行节点.csv：15141个不可行组合，未补造结果。
- 窗口与原始节点依据.json：原始上下界、算术中位数、实际代表节点、固定窗口及窗口内样本数。

窗口宽0.20，中心以0.05步长定位到最接近中位数的实际节点，同距取较大值。相同节点依据保留相同窗口。它用于容量初选，具体实施仍按站级设备与网络条件校核。

全部节点已回算容量及费用，矩阵每单元端点与代表节点以及11点敏感性共847个节点通过独立LP。原始求解JSONL无损压缩保存在研究报告/试算/20261019_负荷分散系数扩展，未压缩工作副本仍在本地保留。来源及核验分别位于既有标准目录。

新建联络工程计算限值取8.00 MVA、功率因数0.95时有功限值7.60 MW。当前区段参考规模7.49106117 MW低于该限值，区县案例和本次推广仍沿用该有效规模。
