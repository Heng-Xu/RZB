# 10.08反馈后的建模调整讨论稿

日期：2026年10月9日。本文供方案讨论，尚未实施模型调整或重算正式结果。依据为10.08 Word的10条批注、修订痕迹、会议记录、当前模型代码及已归档原始资料。现有报告、模型和结果保持原状。

建议把研究目标表述为：在供电安全与工程条件下，比较不同容载比及主变、联络、储能组合的费用和供电裕度，确定适合片区的推荐范围。允许市区为明确的供电裕度目标增加投资，费用变化和地区容载比排序由计算产生。

取消费用排序本身还不足以产生“经济最优且费用更高”的弹性方案。如果两方案初始条件、设备选择、供电要求和费用计算完全相同，弹性仅放宽容载比限制，其可行集合包含刚性集合，则精确求解应满足：

\[
C^*_{\mathrm{elastic}}\le C^*_{\mathrm{rigid}}.
\]

因此，市区允许增加费用，应落实为增强供电裕度、覆盖更高负荷或减少对临时转供的依赖等明确要求，再报告相应增量费用。若同等要求下得到明显更高的弹性最优费用，先检查可行集合、成本范围和求解误差。不能通过费用下限或人为提高容载比，制造高成本方案。

## 二、建议的求解方案和对照组

保留混合整数规划及逐年建设时序，先修正物理约束，不必为了增加评价目标更换算法。

| 方案 | 可选新增措施 | 用途 |
| --- | --- | --- |
| 原固定上限对照 | 主变、联络、储能；维持原2.00上限 | 与历史结果衔接，不能称其覆盖了导则所有增长档的推荐上限 |
| 弹性费用最优 | 主变、联络、储能；取消必须突破与地区排序 | 识别同等供电任务下的经济取值 |
| 仅新增联络 | 固定初始主变，不配置储能，仅建设联络 | 直接回应Word批注5；不可行时报告受限站、时段及缺口 |
| 主变与联络、无储能 | 允许增容和新增联络，储能为零 | 与“仅新增联络”分开，判断储能是否必要 |
| 供电裕度提升 | 在弹性措施集合内，提高可承受负荷或规定N-1余量 | 比较新增投资带来的供电收益 |

供电裕度建议用统一放大既定负荷分布后，仍能通过所有给定N-1校核的最大负荷增幅衡量。主变空余MVA不能直接等同于可供负荷。给定若干负荷增幅逐档求最小费用，可形成费用—供电裕度曲线；首轮可用0%、5%、10%作为研究情景，不能写成导则要求。每个负荷水平同时比较固定上限与弹性方案，以分离“提高服务要求”与“放宽容载比”的作用。没有故障概率与恢复过程资料时，不把该指标称为停电风险或供电可靠率改善。

刚性参考同时按导则增长档列出建议区间。若将分档上限用于新的严格约束对照，应另建一组，不与旧2.00上限混称。真实存量容量已超过参考区间时，保留资产并说明过渡安排，不能为了满足区间虚构拆除或削减现状负荷。

## 三、市区转供率及事故场景

已直接查看本地DL/T 5729—2023原文，第7.1.2(1)条、印刷第18页（PDF第28页）：A+、A类站间通过中压配电网转移负荷的比例为50%～70%，B、C类为30%～50%。这是规划参考范围，不是徐州市区现状能力的实测值。本轮公开检索未找到能核实徐州市区各分区负荷权重和实际可转能力的数据。

建议以会议提出的“A少、B多”为分区建模方向，初步采用A类60%、B类40%，分别检验A类50%、70%和B类30%、50%。这些中点是研究假定；现状不达推荐下限也应如实保留。已核实的逐站类别应优先使用，不能把原先统一指定A类当成现状分类。

若只能先用一个市区参数，暂用40%作B类主导的基准，并以50%检验较强互联条件。该简化值不代表混合区域的精确加权结果。已知同一统计条件下A类负荷权重后，可按：

\[
\rho_{\mathrm{eq}}=w_A\times60\%+(1-w_A)\times40\%.
\]

“A类站点少”不能推出其负荷权重小，权重应按与转供率定义一致的负荷基数计算，不能按行政面积或站数加权。分区转供率仅用于能力设定或汇总，最终可用转供仍由网络与受端约束决定。

事故校核至少包含：每次一台主变发生N-1，其他站保留健康设备；事故站剩余容量与转出支援共同满足需求；健康站在承接后不过载；每条已建通道在同一事故状态下满足容量限制。事故发生前后的潮流应各自校核，不能无条件把正常转接量与事故增量相加，也不能在没有运行重构依据时随意冲抵。不同N-1场景相互独立，不同时累计占用联络容量。

既有通道MW能力应固定或按明确改造增加。不能让既有能力随着年度负荷同比自动增长而无需建设。容载比分母始终采用约定的区域同期网供峰值，内部转供不增加区域总供电能力的账面总量。

候选联络以有依据的相邻站或规划通道为主。资料不足时，可先计算受限邻接与较充分互联两种边界，不能将全区任意站对可接当作已核实工程条件。邳州约28%的既有值来源于局部样本，迁移至县域仍需保留研究假定说明。

## 四、4 h储能与峰段的处理

建议主推荐矩阵固定采用4 h储能配置基准，保留4 h条件下的储能经济参数，取消主矩阵中的时长维度；2 h、6 h只在专项敏感性中检验。若之后决定保留时长为主参数，就固定储能价格，不再把两者同时展开成完整交叉矩阵。

需要分清：设备额定时长E/P、95%近峰段连续时间、实际容量缺口持续时间、N-1恢复时间。四者不能互相替代。当前100 kW/215 kWh储能柜约为2.15 h产品，把公式中的持续时间改成4，并不会自动得到4 h设备。

本轮只读核对的站级2025年模板为：邳州20站正向最长95%近峰段1～4 h；市区29站为1～5 h，其中1站为5 h。4 h可作为待检验的配置基准，但这些站级统计尚不能证明区域网供峰段为4 h，也不能证明全部N-1缺口均可由4 h储能覆盖。

后续应先按共同时间轴形成地区110 kV网供净负荷，核对区域峰段，再对每个关键站及事故计算容量缺口曲线：

\[
P_{\mathrm{gap}}(t)=\max\{0,P_{\mathrm{net}}(t)-P_{\mathrm{remaining}}(t)-P_{\mathrm{transfer}}(t)\}.
\]

缺口峰值决定最低放电功率，连续缺口积分决定所需输出能量；再计入充放电效率、可用SOC、容量衰减及补能条件。先用关键连续日或事件窗口优化，候选方案通过全年时序回放校核；发现未覆盖事件就补入。储能在日常削峰后的SOC必须与故障时可用能量一致，不能分别假定都满电。正向供电与反向吸纳应分别校核。

价格模型宜分开计功率设备和电池能量投资；资料不足时使用有来源的成套设备报价，不直接用2.15 h产品总价线性推成4 h项目造价。当前25年储能寿命与评价期不更新的设定也应核对产品依据，区分电站寿命与电池更换，列出寿命、残值和更新费用敏感性后再解释费用差异。

## 五、推荐矩阵的参数简化

建议主表按供电区域类别组织，只保留以下有独立作用的数值参数：

| 参数 | 建议处理 |
| --- | --- |
| 分布式电源装机渗透率 | 保留，用户最大负荷与网供峰值分开定义；电量渗透率用于补充解释 |
| 年负荷平均增长率 | 改用复合增长率，严格按导则四档分组 |
| 负荷分散系数 | 保留，改变不同时性时固定空间分配；集中程度另做专项对照 |
| 初始可用转供率 | 新增主维度，区分初始能力与规划结果 |
| 线路成本比例系数 | 替代主变与线路投资比，不再按架空为主、电缆为主拆表 |
| 4 h条件下主变与储能单位有效功率投资比 | 保留经济维度；储能时长固定，不再重复展开 |

线路成本系数可定义为：

\[
k_L=\frac{(1-f_c)c_{\mathrm{OH}}+f_c c_{\mathrm{CB}}}{c_{\mathrm{OH}}},\qquad
C_L=Lc_{\mathrm{OH}}k_L+C_{\mathrm{switch}}.
\]

其中电缆占比f_c、架空与电缆单位长度费用只用于从工程构成计算k_L，不再与k_L同时作为独立扫描维度。长度、开关及线路能力仍单独按项目计取。不同敷设条件如影响可建性或热限，应保留对应物理限制，不能仅以价格替代。

沿用当前历史研究基价时，架空24万元/km、电缆180万元/km对应系数1和7.5；旧10%、90%电缆构成对应1.65和6.85。这些仅用于新旧参数换算，未核实为本轮最新工程概算。甲方要求取消类型分类，不意味着可以取消造价组成和路线可建性。

DL/T 5729—2023表6.3.4（印刷第14页，PDF第24页）四档为：

| 年负荷平均增长率 | 导则建议容载比 |
| --- | --- |
| g≤2% | 1.5～1.7 |
| 2%＜g≤4% | 1.6～1.8 |
| 4%＜g≤7% | 1.7～1.9 |
| g＞7% | 1.8～2.0 |

不再把2%～7%合成一个正式区间；超过7%的研究样本若只算到10%，明确10%是试验范围，不是导则上界。导则没有规定分档的成本系数、时长等参数，应标为研究取值。合并相邻推荐单元时核查阈值两侧及中间点；离散设备选择下，端点一致不能证明整段一致。

矩阵至少输出容载比、费用、主变配置、储能功率与能量、新增联络规模、初始及规划可用转供能力、N-1供电裕度和可行性。经济最优推荐与增加供电裕度的推荐分开列示。

## 六、增长率、共同起点与主变序列

采用：

\[
g=\left(\frac{P_{2025}}{P_{2021}}\right)^{1/4}-1.
\]

2021—2025有4个增长间隔。按原始登记表复算，邳州旧增长率为0.0807422386，新值为0.0692319256；市区分别为0.0180002616和0.0133612931。这里小数是计算参数，报告百分数按整百分数展示。邳州新值未取整前低于7%，因此应进入中等增长档，参考范围由1.8～2.0变为1.7～1.9；市区仍属饱和期档。分档必须使用完整精度，不能按显示为7%的数值重新判档。

在相同起点、相同四年推演方式下，两地区目标年负荷均比旧方法下降。这只说明需求输入改变，容载比是容量与负荷的比值，离散容量调整会影响其最终方向，不能据此预报新容载比。

Word批注4询问共同起点改变了容量还是负荷，修订痕迹进一步把文字改为“容量取真实峰值负荷的两倍”。现有代码实际固定离散仿真设备，再令P0=S0/2。两者必须统一：

- 机制比较仍可保留约2.00的共同起点，但建议按甲方修订保留真实区域负荷，通过明确的离散容量重构获得接近2.00的初始站群，列出实际R0与偏差，不编造恰好成立的设备组合。
- 另用真实在役容量、负荷及可建设条件校核工程适用性。真实现状起点不强制为2.00；共同起点属于机制试验。
- 如讨论后继续沿用固定仿真容量、缩放负荷，应恢复与代码一致的文字，并说明未采纳甲方改写的原因。

主变序列分为“现有资产”和“新购候选”。Word批注1要求新购不再使用20、40 MVA并考虑80 MVA；批注6给出A类40～63 MVA、B类31.5～63 MVA的范围说明。这两处分别涉及通用设备序列与供电类别适用范围，不能直接合并为所有站均可购买80 MVA。

建议在役20、40 MVA设备如实保留；新购先按甲方意见筛选31.5、50、63、80 MVA，再按站点类别、站址、间隔、配套设备与适用文件限制。80 MVA列入具备条件站点的候选或专项情景，补齐工程价格与最大单台主变N-1校核。当前固定扩建第三台50 MVA的假设也应审查，不把所有站都视为有扩建位置。

## 七、相关性、上限及图文调整

3.5节应覆盖全部当前参数，但分清数据性质：历史样本用于描述实际关联；设计的仿真样本用于分析参数作用。不能将工程价格、固定时长等没有历史变化的数据硬塞进12个月的历史相关性矩阵。

建议提供参数清单、参数间关系矩阵、参数与推荐容载比的关系矩阵，并补充同一其他条件下的参数配对变化。连续参数采用Pearson与Spearman作描述，类别参数按类别比较或采用有说明的编码方法。主矩阵固定4 h时，该变量的相关系数未定义，应注明“固定参数”，其作用在2/4/6 h专项样本中分析。不能把未定义相关系数填成零。

完整正交设计中，输入参数彼此相关接近零是试验设计的结果；装机与电量渗透率的固定比例、容载比与负载率的共享计算量也应注明。价格和设备决策常呈阶跃变化，低线性相关不等于没有影响。成本、费用、供电裕度作为补充目标一并分析。当前负荷分散系数改变时还同时换了站间权重，应先拆开这两项影响，避免归因混淆。

会议所说“2.6上限推导”按主题定位。当前Markdown的2.6标题已是经济替代条件，不能仅按旧节号整节删除。建议取消把2.60作为统一上限结论的论证，保留必要的容量约束和措施替代关系。光伏装机及屋顶资源可形成反向容量需求，但通常不能唯一决定经济合理容载比上限。

求解容量上界用候选设备和站址形成的S_max/P_peak；推荐上端则在明确费用容差或供电裕度要求下，求相应可行解的容量边界。两种上界分别命名，不能把数值搜索边界称为推荐上限。若最优方案达到人工搜索边界，需扩展后复核。

负荷峰值图改为负载率。优先用视在功率除以同期容量；只有有功数据时，用明确的功率因数估计，标注“站级估计负载率”。第三章可固定现状容量展示需求压力，第五章采用方案对应年度容量展示措施实施后负载率，两者不可混用。正向与反向分别展示，主变N-1压力另列；区域平均负载率不能代替逐台主变负载率。

百分数统一按整百分数展示，原始数据、公式计算及区间判定保留精度；可靠率等若整数显示会丢失必要含义，应改用停电分钟等可辨识指标或单列说明。将“设备退出后”的故障场景改为“主变N-1后”；真实设备替换、退役的动作应仍按实际含义表述，不做破坏语义的全文机械替换。

## 八、可能出现的结果与试算顺序

以下为待检验判断，不是重算结论：

1. 市区既有转供能力较强时，联络利用或局部增容可能已能满足要求，费用最优容载比未必超过2.00。增加供电裕度的推荐方案可以更贵，但应说明新增费用对应多少可供负荷或余量。
2. 市区以B类为主、初始转供较弱时，联络建设或主变增容需求可能增加；供电类别变化与事故转供模型修正同时发生，其净效果需重算。
3. 邳州高光伏条件下仍可能有较强反向容量需求，但降低增长率、改变转供方式后，原来约2.20的结果及地区排序未必保持。两地原合计费用降低约70%的结论需重新检验。
4. 允许真实事故转供后，原固定上限方案的储能需求可能下降，使弹性费用优势收窄；4 h能量与SOC校核也可能增加部分方案的储能需求。两项作用不能提前抵消或指定结果。
5. 仅新增联络方案可能只在部分年份可行。联络能重新分配现有余量，区域同步容量不足时不能凭空补足缺口。
6. 线路成本较低时可能更多采用联络、减少本地主变增容；线路较贵时可能偏向主变或储能。整数规格、受端余量和拓扑限制下，不预设每个样本都严格单调。

建议先完成输入与规格修订，以及两地区共用的正常/N-1转供与储能校核模型；再做两地区、转供下中上三档、主要对照方案的小规模试算，报告可行性、费用、容载比、措施数量和供电裕度。确认结果能解释后再重算外推矩阵，最后同步第三章关联分析、第五章结果和摘要结论。

讨论首先需要确定：经济最优之外是否另列供电裕度提升方案；共同起点是否按甲方修订改为保留真实负荷并重构容量。其余如整数百分数、开根增长率、导则分档和补充无储能对照，已具备明确修订依据。
