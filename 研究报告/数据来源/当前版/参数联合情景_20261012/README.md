# 参数联合情景的来源依据

本目录的两份CSV从保留的原始收资逐行提取。转供数据取`实验/研究/data/tuomin/补充数据/徐州地区变电站全停全转情况分析汇总20250705.xlsx`首张表“负荷高峰期间变电站全停全转 ”，地区及站名有效、J/K列为数值的记录纳入；J为站外最大可供负荷，K为损失负荷。地区指标按ΣJ/(ΣJ+ΣK)汇总，原表行号列在站点来源表中。

本轮采用地区全部电压等级作取值背景：邳州28站、67.2975%，徐州市区59站、91.5471%。仅110 kV结果另留核验，未替换地区整体口径。仿真转供节点统一为10%～90%、步长10%；67%和91%只作地区数据背景。

邳州电缆长度占比来自`实验/研究/data/tuomin/电网建模数据_Agent整合版_V1.2/邳州10kV线路基础数据表.xlsx`，403条去重线路，电缆572.4851 km/总长5318.5635 km，约10.76%。市区约80%由用户2026年10月12日提供，当前没有对应的最新逐线路长度明细。

导则依据保留真实版本：DL/T 5729—2023第4.1.1条及表4.1.2、第7.1.2条、第7.3.1条、第8.1.5条提供供电分区、转供比例、接线及电缆应用背景；增长率2%、4%、7%分界对应其表6.3.4及2025年4月修订资料第6.2.2.1条表2。2025年4月修订资料第9.2.1.2条用于转供能力机制说明。文件哈希见锁定清单，章节定位与参数定义同时见锁定工作簿。

电缆/转供联合取值属于研究情景，地区资料用于支持代表条件；五站模板与实际地区站级案例分别使用。储能2/4/6 h为受控比较，原4 h共同基准及费用边界保持。
