# 逐站既有转供约束来源

`逐站既有转供能力及对应.csv`按110kV站名、站号逐项匹配2025年7月5日全停全转原表J列“站外最大可供负荷”。市区模型26座实体站匹配成功，其中夹河使用原表铜山条目；3座模拟站不新增既有额度。邳州20站全部匹配。

既有转出按`min(旧标定预算,J列MW)`限制，原表J/(J+K)只列示该站原始转供比例，不对全部时刻机械施加同一比例。逐站上限、原始站名和行号、原网络预算及来源地区分别保留。J列按现有收资能力冻结，未来改造能力须与具体投资对应。

`来源与口径.json`保存原Excel、站名对应表、模型输入及原方案解的哈希。地区全部电压等级91%/67%背景统计保留，与本轮样本站级约束分别说明；逐站额度收紧后不再重标定补足地区均值。
