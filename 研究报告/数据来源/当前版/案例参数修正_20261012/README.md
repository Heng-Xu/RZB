# 两地参数原始提取

`转供原表逐站提取.csv`和`转供统计范围.csv`直接读取2025年7月5日全停全转原表。J列站外最大可供负荷和K列损失负荷按地区汇总，采用ΣJ/(ΣJ+ΣK)。全部电压等级与仅110 kV分别列示，模型采用用户指定的地区全部电压等级口径。

`邳州电缆长度提取.csv`直接读取线路源表N列总长、P列电缆长度，403条线路去重汇总。市区80%来自用户收资。来源路径及哈希在`来源及参数.json`；该JSON同时保留首版共同起点标定记录，后续2025设备参考标定在承载力复核原始库inputs.json中。

最新方案见`研究报告/01研究推荐/当前版/案例承载力复核_20261012`。完整既有联络端点尚未收齐，原候选站对范围内的聚合通道仍作为研究等值假设。
