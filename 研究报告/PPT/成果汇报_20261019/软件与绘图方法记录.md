# 软件与绘图方法记录

PPT采用[PPT Master](https://github.com/hugohe3/ppt-master) 6.7.2的原生PPTX往返编辑流程，保留指定模板的4:3页面、Master与Layout。所有新页以原内容页为骨架。中文采用微软雅黑，模板未修改的继承元素保留其字体。文字、表格、流程箭头为PPT原生对象；数据图按报告数值用Matplotlib重绘，同时保留SVG、PDF与300 dpi PNG。

绘图采用[scientific-visualization](https://github.com/K-Dense-AI/claude-scientific-skills) 1.4工作流，面向现场投影调整字体和图件尺寸。Nature相关skills仅作为风格参考，未将本项目图表宣称为期刊投稿成图。线图保留完整年度或受控参数序列，刚性与弹性使用不同线型和标记；费用用同范围可行方案比较。矩阵推荐窗口为研究提出的容量初选范围。

程序化图表来源见`figure_manifest.json`及各图的manifest，原表、区域8760小时序列和报告字节快照在`data/`与`sources/`保留。两张AI设备概念图来源与用途见`images/AI概念图来源.json`，数值、文字与功率方向由原生元素承载。

Scientific Agent Skills引用：Kassis, T.; Agarwal, V.; He, Y.; Patel, D.; Brueckner, A. M. (2026). *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*. [arXiv:2609.00065](https://arxiv.org/abs/2609.00065), [DOI](https://doi.org/10.48550/arXiv.2609.00065)。该引用仅说明绘图工具的方法来源。
