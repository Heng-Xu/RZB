# AI表述与术语逐处审查

本轮只识别问题，不修改当前稿。使用[lieflat-less-ai-tone](/home/xh/.agents/skills/lieflat-less-ai-tone/SKILL.md)与[humanizer](/home/xh/.codex/skills/humanizer/SKILL.md)辅助核查。“AI表述”指可定位的语言模式，不代表能够判定文本由谁生成，更不使用AI检测分数评价报告。

## 审查规则

先保留技术报告语体，再按规则识别。lieflat仅处理明确触发的白名单问题；humanizer用于重复收尾、无信息增量的解释及修订过程口吻。两种skill有冲突时，采用更保守的判断，并以本轮“不改稿”要求为先。

专业术语重复、标准名称、主变—线路—储能三类措施的必要并列、公式变量说明、编号章节，不因格式整齐就列为AI问题。对技术限制的说明有实质信息，不以“消极”“自我否定”为由删除。

## 值得处理的表达

| ID | 位置与原文 | 问题性质与规则依据 | 为什么甲方可能再次指出 | 后续处理方向 |
| --- | --- | --- | --- | --- |
| A01 | 5.4.4～5.4.5：“两类方案的本站主变配置接近，差异主要通过区域其他站点的容量和负荷安排体现。” | 重复收尾候选，humanizer §2；事实不符另按Q04处理 | 100/70、100/90、126/113 MVA三组不同容量也被套用，文字不像在解释该站 | 先逐站判明相同、增大、减小，再保留有证据的本站解释；不能只换同义词 |
| A02 | 多站重复：“弹性方案储能减少× MW，主变N-1工况的容量支撑更多由在役主变和站间负荷配置承担。” | humanizer §2重复收尾；lieflat §3仅在相邻句法机械重复且没有必要并列功能时适用 | 多站同一句泛化机制，未说明本站哪种作用更主要；不能把“更多由”当作逐站因果验证 | 核对容量、转接与储能差异；没有独立机理证据时陈述事实即可 |
| A03 | 3.3.2：“数值的小数位用于复算，规划文字采用适当精度。” | 编辑过程口吻；属于语体问题，非lieflat确定命中 | 数字精度安排是编写规则，读者关心估计方法和结果，甲方已删除过类似处理说明 | 后续将精度规定集中于编制说明；正文保留结果及估计性质 |
| A04 | 4.2.4：“未预留站不因容量不足而自动获得新台位。” | humanizer §5，否定一个正文没有提出的替代做法 | 像向模型或改稿者解释程序行为；上一句已说需要预留位置 | 直接陈述扩建受预留位置约束，避免重复辩解；“预留条件”不能删 |
| A05 | 4.5.2：“避免只降低首次购置而保留原更新成本，造成情景定义不一致。” | humanizer §5候选；实施说明过细 | 当前经济评价期没有寿命更新，反复解释错误实现更像程序审查记录 | 保留价格倍数统一作用于相关科目的规则；把无实际发生的实现讨论压缩。此项为低优先级候选 |
| A06 | 2.1.2：“……现有协调控制普遍忽视调节时序与经济性、低压建模过度简化，有待进一步统筹调节时序与经济性。” | humanizer §2，局部重复总结候选 | 末尾再重复“调节时序与经济性”，没有增加具体信息；“普遍”还需来源支持 | 对照文献后保留具体不足，避免重复同一不足；不能擅自补研究结果 |
| A07 | 1.4.1：“给出每年主变容量、采购措施、储能配置、正常负荷转接及费用。” | 专业搭配问题，不冒称skill命中 | “采购措施”是要购买的设备还是建设安排不清楚 | 按实际输出区分“新购主变容量”“建设措施/年度采购量” |
| A08 | 2.5.2：“结果只能作为上侧压力指标。” | 专业措辞问题，不属于lieflat白名单直接命中 | “上侧”不说明是哪种量的上界，读者需要回看整段 | 明确为各站非同时反向峰值之和及其用途，不借去AI之名改变算法 |
| A09 | 1.3.3：“上述科目可能影响工程经济排序……” | 指代和逻辑衔接问题，非lieflat §11（这里有回指） | 前文刚列出模型已含费用，读者不清楚此处是在说已含科目还是遗漏科目 | 指明所讨论的费用项目，避免用空泛回指代替边界说明 |
| A10 | 2.1.3、2.1.4连续多篇“某作者＋算法＋若干数字＋说明……” | 信息组织偏摘要拼接；只列阅读负担，不作确定AI判定 | 一个长段串多种研究，数字很多，却较少说明哪些方法真正用于本报告 | 后续可让每段聚焦一个与本课题有关的问题；保持每项数字、作者和适用条件，不以skill重组全文 |
| A11 | 2.2.7与2.2.8重复“三级弹性”层级和1.86降至1.72案例 | humanizer §2重复信息 | 增设弹性规划小节后，旧段与新段信息重复 | 保留分层方法及与本研究的联系区别；不得把原文下降结论改成上升 |
| A12 | 4.2.3仍有“按净增有效MW摊价”“按新购50 MVA摊价” | 甲方明确改字未统一，专业用词问题 | 原修订已将其改为“单价”，再次看到会认为修订未落实 | 用按单位净增/新购容量折算的投资描述；计算分母继续区分 |

表中的确定事实问题主要是A01及对应Q04；AI模式问题的判断强度更低。A03、A07～A10、A12明确属于语体或术语问题，不伪装成skill自动判定结果。凡建议涉及信息删减或章节重组，均需在后续真正修订时依据用户范围重新核对；本轮没有执行。

## 命中检索但不应自动清理的表达

| 原文或现象 | 保留理由 |
| --- | --- |
| “并非以研究结果替代导则的适用条件” | 虽有否定结构，但其承担标准适用范围限定，不是无意义翻案。是否压缩需看相邻段，不直接按lieflat §1删除 |
| “95%……不表示全年功率样本的第95百分位，也不表示95%的保障概率” | 专业概念确实易混，区别有信息，属于必要解释 |
| “不能直接推为核定现状资产下的投资节约比例” | 当前仿真起点和费用边界决定该限制，不能为加强结论删掉 |
| 主变、储能、联络三类措施反复并列 | 是真实模型结构，属于lieflat §2的必要项目例外 |
| 连续出现“主变N-1”或标准全称 | 有助于术语一致，不强行换代词或同义词 |
| 第一章、第二章及1.1、1.2等编号 | 承担正式报告引用和层级功能，不能按“序数词当小标题”删掉 |
| “当……时”用于负荷达到门槛、设备退出或投运时点 | 确实表达条件/时点，符合lieflat §10例外 |
| 表格的平行句法及逐站表头 | 是查阅需要；模板化问题在错误或空泛解释，不能破坏必要结构 |
| “约”“估计”“本案例条件下” | 对应真实误差和适用范围，去AI不能提高事实断言强度 |

## 范文的使用边界

恢复的魏集PDF第6节以接入电压为条件直接给出推荐容量；第5.5节先列不同规模下的利用效率和典型运行方式。这种写法值得借鉴：每项建议能找到条件和计算依据，不必以一长串抽象名词抬高结论。

宿迁初稿和旧提取语料中的“精准落位”“高度契合”“全息数字中枢牵引”“动力学传导机制”等，不作为本报告的推荐表达。旧语料包含与本模型无关的全时序、置信度和动态校核内容，不能仅为显得专业而搬入。

## 后续语言检查的验收依据

每条拟修改语句应能对应甲方原意见、词表条目或skill规则，并核对修改前后的数值、比较对象、因果和适用条件是否保持。表格和生成段落与正文同等检查；本轮已发现，单看六章源会漏掉逐站自动生成文字及参数表中的残留。
