# 研究报告写作与科学表达要求

本规则依据当前实际模型和结果执行。历史版本中的开题目录锁定、存量容量豁免、累计等年成本及未实施方法要求已经失效。

## 1. 写作原则

语言逻辑连贯：按照背景与问题、资料与对象、方法、结果解释、工程建议组织七章，段落围绕具体问题展开。

术语科学准确：容量、功率、电量及费用单位必须与来源一致；区县背景、样本站范围和不同电压层分别说明。

符合人类阅读习惯：采用工程咨询报告语气，保持完整自然的中文段落，删除夸张评价、模板总结和内部开发口吻。humanizer检查不得改变数值、公式及证据强度。

## 2. 现行模型口径

- 规划决策期为2022至2025年，评价期为2022至2041年，增量费用现值折现至2021年，单位万元；当前包括首次投资、更新投资及固定运维。
- 规划参考容载比采用年度固定正向参考峰，不能称为措施后实测运行指标；反向极值单独处理。
- 刚性对照采用年度比值上限2.0和研究单元累计正向增配预算，弹性方案上限3.2且不设该预算；容量退出是允许的仿真动作，没有存量容量豁免。
- 正向容量、反向静态筛查及单台主变停运承载代理按实际实现说明；不冒充完整潮流、标准承载力或N−1工程校核。
- 储能以尖峰持续时间约束有效功率，尚未实现逐时荷电状态、效率及衰减核算。
- 区段转供按静态通道、供受端余量和跨年状态选择；80%反向系数不用于普通正向转供。
- 样本参考矩阵只描述现有路径，不编造连续可外推区间、独立验证或AHP权重。
- 损耗、拆改、残值及未包含的辅助工程费用明确标为未评估，不能写成真实零费用。

## 3. 图表、公式与文献

图表按照首次正式展示的章节及顺序编号，正文先引用，再展示和解释。改号必须同步图内题名、链接、来源登记；数据保持原精度。

公式采用标准LaTeX，前有用途说明，后有变量和单位说明。标准原式、实际求解式和未计算补充框架分别说明。

研究现状沿原综述主题组织；用于正文的事实和书目以原始论文、期刊或官方发布材料核定。无法核实的效果数字和书目不进入本版，保留原综述供追溯，不扩展无关方向。

## 4. 源文件与核验

当前七章Markdown及两份配套说明位于研究报告/03_MD，是本轮正文源文件。旧终稿只作为历史版本；不以旧模型检查规则阻止现行报告。

执行实验/研究/scripts/check_report_writing_quality.py检查语言底线，执行研究报告/03_MD/检查证据/核验阶段2.py核对图表、公式、原始结果及文件哈希。自动检查不能替代逐章通读。后续Word/PDF从本版Markdown装配，另行检查公式渲染和分页。

## 5. 正文表达

先交代条件再解释结果，费用下降需给出比较基准和配置原因。不得使用“首次提出”“填补空白”“国际领先”“充分证明”等无证据评价。程序路径、字段、提交信息和核验日志放在配套材料中，不进入对外正文。
