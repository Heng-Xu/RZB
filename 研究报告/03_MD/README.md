# 阶段2 Markdown底稿

本目录是现行七章研究报告的正文来源，以当前实际模型和结果为准。按01至07顺序阅读，配合《公式符号说明》和《数据来源说明》。完成情况及阶段3条件见[阶段2完成报告](阶段2完成报告.md)。

图表文件夹保存本版编号的正式图片及数据定位；原阶段1图表作为来源保留。检查证据记录文献核定、新旧题号对应、语言复核和数据核验。历史依据文件夹仅供追溯，旧生成脚本和规则不参与当前构建。

在项目根目录执行以下命令核查当前底稿：

```bash
python 实验/研究/scripts/check_final_report.py --root . --markdown 研究报告/03_MD --output-dir 研究报告/03_MD/检查证据/现行入口核验
python 研究报告/03_MD/检查证据/测试写作检查器.py
```

如需按相同源数据重新输出正式图，可使用项目绘图环境执行检查证据/重绘编号图.py。该程序不求解模型，不生成整篇Word或PDF。后续终稿从本目录装配，公式渲染及分页另行核查。
