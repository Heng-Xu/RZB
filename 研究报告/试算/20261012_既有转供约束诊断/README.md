# 既有转供诊断原始记录

`逐年既有转供量.csv`、`逐工况最小转供.csv`及`代表工况通道明细.csv`固定上版六组设备，重新求最小总转供调度，分列等效既有、已核实T01及新增通道。`原始解与最小转供对照.csv`保存原费用寻优解中未被目标惩罚的额外转供。

`对照逐工况最小转供.csv`逐项保存12组新方案的45,504个调度工况，`对照逐年转供量.csv`和`对照代表工况通道.csv`给出年度最大值与通道明细。

`逐站收资上限.csv`与`原设备增加逐站上限校核.csv`、`原设备逐站上限缺口.csv`记录逐站额度及原方案不足；仅改变上限时不为匹配地区汇总率放大网络。各故障工况互斥，不能将静态MW累加成年转供电量。

`约束对照`保存两地区逐站上限下、正常允许调整和正常供区固定两种规则各三类方案，共12组对照。带`refine_*`或`source_caps_*`的目录为独立求解，不覆盖先前迭代；当前采用同组通过全部静态工况的最低费用结果，由`05_review/当前版/1012既有转供约束诊断/约束对照独立核验.json`的`result_folder`登记。早期高费用可行候选保留，不作为最终比较值。

只读核验：`python -m 实验.研究.rebuild_2026.case_parameters_20261012.transfer_diagnostic --verify`。转供复算为`--audit`，原设备逐站上限影响为`--audit-caps`，导出为`--export`。寻优需指定`--region`、`--case`、`--policy`，重算应另取`--attempt`以保留原始记录。
