# 图表文字与视觉审查记录

范围：32项正式图表，逐项文字清单保存在source_data同编号JSON中。核对标题、图例、坐标轴、流程框、表头、表下注释及来源短句。按本地humanizer技能和用户指定规则检查表达，参考睢宁魏集容量规划报告的数据介绍方式。

## 语境修改

| 对象 | 审查处理 | 工程含义 |
| --- | --- | --- |
| 章节与叙事 | 按开题报告的运行特征、成本模型、一片一策和典型案例顺序重新编号 | 图表直接服务原定章节 |
| 模型与审查说明 | 7项独立说明图表移入配套文件；3项原备选不生成 | 正式图表以数据和结果为主 |
| 优劣判断 | 使用对应单元的费用降幅或具体配置，不写空泛“显著提升”“明显优于” | 保留研究条件下的数值含义 |
| 推荐范围 | 用样本参考范围、点值及支持案例表达 | 不把年度样本包络写成通用阈值 |
| 对照对象 | 统一为刚性/弹性方案，不称实际改造前后 | 区分规划计算与运行实绩 |
| 源荷比 | 题名和轴注明降压峰近似 | 分母说明简短保留 |
| 安全与运行 | 不出现可靠性提升率、完整N−1通过或逐时储能调度结论 | 无相应量化结果不作效果判断 |
| 流程框与结构图 | 技术路线按研究任务表达；五类指标共同进入片区归纳 | 避免空泛开始、处理、结束及错误顺序关系 |
| 数字与文本 | 不改变冻结原值；区间显示端点向外舍入 | 不因美化表达缩小样本包络 |
