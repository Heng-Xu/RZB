# 图表脚本使用说明

本套脚本读取阶段0准入数据，按开题报告章节生成图表，不调用优化求解器。工作目录为项目根目录。使用环境xuzhou110kv_clr。

依次执行：

```bash
/home/xh/anaconda3/envs/xuzhou110kv_clr/bin/python 研究报告/02图表/scripts/prepare_sources.py
/home/xh/anaconda3/envs/xuzhou110kv_clr/bin/python 研究报告/02图表/scripts/revise_plan.py
/home/xh/anaconda3/envs/xuzhou110kv_clr/bin/python 研究报告/02图表/scripts/generate_stage1.py
/home/xh/anaconda3/envs/xuzhou110kv_clr/bin/python 研究报告/02图表/scripts/audit_stage1.py
/home/xh/anaconda3/envs/xuzhou110kv_clr/bin/python 研究报告/02图表/scripts/complete_handoff.py
```

plan_stage1.py保留最初规划构建逻辑，最终应运行revise_plan.py形成开题章节版；不能只运行原规划脚本代替现行规划。

实际中文字体文件默认为/home/xh/.local/share/fonts/stage1/msyh.ttf，可通过STAGE1_CN_FONT指向同字体。西文字体使用/usr/share/fonts/truetype/msttcorefonts/Times_New_Roman.ttf。精确字体哈希和来源见source_data/字体登记.json，未安装字体时脚本报错，不静默替换。现有PNG和PDF可直接查看，SVG文字编辑需要相同字体。

final_figures内每个图号对应SVG、600 dpi PNG、PDF。final_tables内每个表号另有XLSX及单表Word片段。PNG插入宽度14.4 cm，表5-2为23.0 cm横向页。题名已包含在图片中，后续装配时避免重复题名；自动题注需要时可按最终编号处理。

source_data同编号CSV为绘制或显示数据，JSON保留准入记录原始精度、D编号、来源位置、单位、公式和补充区县数据；“原始数值.csv”单独保留完整数值。修改来源或模型结果后不能仅刷新图表，须先更新阶段0确认口径与来源核验。

图表说明文件供正文引用与工程解释使用。审查清单及最终核验是配套工作记录，不直接拼入研究报告正文。
