# 审查资料复核

主交付为本目录上一级的七项文件。数据来源目录保存PDF和JSON的同版副本。原模型、输入和原结果保持不变；审查表中的章号均为拟引用位置，不代表已经形成正文。

## 日常只读核验

在项目根目录运行：

```bash
/home/xh/anaconda3/envs/xuzhou110kv_clr/bin/python 研究报告/00审查/审计工具/核验冻结.py
```

该命令比较原件、审查资料和归档文件的SHA256，检查旧结果活动目录是否重新出现，不写文件。冻结清单自身不纳入自身哈希；其哈希及外部保存要求见清单相邻说明。

## 独立复算和交付核验

`独立核查.py`从原表及原设备事件复算年度场景、容量分配、约束和现金流，写入本阶段证据目录，不改模型结果。`核验交付.py`核对每条登记值与源位置，核对字典、JSON、PDF及废弃结果归档，写核验记录。`阶段0只读核查.ipynb`已经顺序执行，保存实际输出。

封存后需要重做这些步骤时，先复制审查资料到单独复核工作区，避免覆盖已封存日志。变更数据或模型应另建版本，不能通过修改冻结清单消除哈希变化。

## 完整隔离重求

`隔离复现.py`按本阶段491文件扩展快照复制原件，并携带原409文件清单，再运行模型测试、基础与价格路径检查和六路径重求。原409文件清单没有纳入根目录的储能价格登记及公告，单独按它复制不能完成复现；本阶段已补齐这些实际依赖。输出目录必须尚不存在，且不在原项目内。例如：

```bash
/home/xh/anaconda3/envs/xuzhou110kv_clr/bin/python 研究报告/00审查/审计工具/隔离复现.py --destination /tmp/rzb-stage0-new-review
```

本次重求证据保存在`证据/隔离重求结果/`，用于对账，不替换原逐站结果。同费用的不同逐站分配可以存在，仍以原解作为本阶段报告输入。完整路径的区域年度值和费用按绝对容差10⁻⁵、相对容差10⁻⁸核对。

重求后可运行`核对隔离结果.py --reproduced /tmp/rzb-stage0-new-review/reproduced`，核对共同起点、区域年度指标及费用。默认只在终端输出，不修改原结果。交付工具本身已另从扩展清单执行全套隔离复验，实际日志及对账文件位于`证据/交付工具隔离复验/`。

## 资料生成

`生成冻结资料.py`读取原表、原结果及本阶段独立核查证据，生成字典、JSON、PDF和完成说明。它不调用优化求解器，但会重写审查交付文件；封存后只在复核副本内运行。需要原项目专用Python环境，额外使用PyMuPDF、nbformat；打印字体使用系统Noto Serif CJK与DejaVu Serif，不修改字体字形。

PDF由Chrome读取本地打印HTML生成，再添加页码。若运行环境限制浏览器进程，应在获准的运行环境中单独打印该HTML到`证据/数据来源审查_浏览器打印.pdf`，然后用`生成冻结资料.py --skip-print`读取打印文件并完成交付。该选项不绕过运行环境审批，也不改变数据。

`清理废弃结果.py`是本次清理的执行记录，归档存在时拒绝重复运行。历史数据在压缩包内逐项校验后才删除活动副本。不得用该脚本扩大删除范围。

原版规则文件含前版成本表述。用户已确认本地v4为本阶段基准，后续正文须采用本审查核定的费用、参考容载比及样本边界。
