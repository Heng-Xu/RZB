# 本轮修订与验收说明

## 稿件与术语

- 年度规划指标统一为“容载比”。月度季节统计使用“容载比（月度分析值）”，说明固定年末主变容量、分母为月最大正向净负荷，不将月度计算量当作导则中的年度规划指标。
- 统一公用主变总容量、95%峰值持续时间、两类分布式电源渗透率、评价期费用降低比例及费用分项等名称，同步正文、表头、图轴、术语表和工作簿。全文将“口径”按实际含义改写为统计范围、数据记录或计算方法。
- 术语表增补为112项。120张数据表的每一列均登记为指标、统计量或说明列，35处独立公式按正式编号同步索引。术语表MD与DOCX同步更新。研究推导和月度分析量与标准原式分别说明。

## 3.5.4的结构与依据

小节改为“指标关联与外推参数选取”，先交代容量规划问题和导则依据，再说明历史数据关联、换算关系及第五章用途。相关性表统一为“指标一／指标二”，避免在未建立回归模型的情况下预设解释方向。

表3-14逐项列明选取依据、与其他参数的关系及第五章用途。主变与储能、主变与线路两类单位功率投资比均保留；线路价格未引起当前结果的容载比变化，并不等于对费用没有作用。

装机与电量渗透率的关联由各自定义推得：电量渗透率等于装机渗透率乘年利用小时，再除以8760倍用户年负荷率。对25200组原始结果独立复算，固定换算因子为0.273972602739726，Pearson相关系数约为1.00。第五章因此只将装机渗透率作为独立源荷参数；实际片区仍分别统计两项指标，未将这一固定情景关系外推为普遍实测结论。

## 原生WPS排版

修改前原生DOCX在本地WPS显示172页，原PDF的150页来自LibreOffice对公式图片副本的导出。两条排版路径不能证明原生Word分页一致。

本轮改为WPS从原生DOCX直接导出PDF，保留237处可编辑数学对象。正文固定17.4磅行距，复杂行内公式采用最小行距；补齐265处原先引用的未定义段落样式；移除模板网格并规范数学字体；允许目录域更新。表头与首条数据同页，短表整表排放，长表重复表头。参考文献固定16磅行距。

最终交付150页。核对PDF印出的46项目录、DOCX目录缓存及正文实际位置；抽查摘要、参数选择、公式、矩阵、短表及参考文献。全150页进行文字和图形边界检查。具体文件哈希与页面证据见同目录《版面抽查记录.json》《最终页面图像登记.json》。按用户后续指示以WPS作为验证重点；本环境未直接运行Windows Microsoft Word或WPS云端。

## 数据保持与维护

35个当前版原始CSV/JSON计算文件哈希与本轮修改前一致。推荐工作簿逐格比较593599个单元格，唯一变化为“主变总容量/MVA”改为“公用主变总容量/MVA”，无数值或公式变化。案例约束、费用及25200组外推/126000条站级记录的独立复核保持通过。

重建入口现采用“装配DOCX—WPS原生导出—接收PDF并同步目录—版面和术语核验”流程，避免后续重建再次恢复两套分页。原有prompt.md不纳入提交。
