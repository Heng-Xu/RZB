# 既有转供与新增约束独立核验

`转供量独立复核.json`记录原六组22,752个工况的固定设备最小总转供LP；`逐站上限影响审查.json`另对相同设备加入逐站收资上限，定位零费用方案的缺口。静态缺口是承载约束最小松弛量，不是预计年失负荷。

`约束对照独立核验.json`复建两地区12组方案完整约束矩阵，核对设备、费用及45,504个正常与故障工况，同一约束组保留各次求解有效下界的最大值及其与所选可行费用的间隙，并登记实际采用的独立寻优目录。`导出核验.json`核对工作簿单元格、各类检查工况数与采用方案的输入和解哈希；提交和CI同时检查导出文件哈希，防止继续交付旧方案表。

新增测试验证原表站名匹配和跨地区条目、逐站上限不重标定网络、最小必要转供量，以及正常固定供区时仍保留故障转供。连同上版规则共14项，提交钩子和CI执行同组测试及新对照核验。远端CI未运行。

依据使用本地2025年4月《配电网规划设计技术导则》修订资料8.1.2与9.2.1.2。相对独立供区的要求不自动推出全部正常转供必须为零，故本版将其列为对照运行假设。DL/T 5729—2023的发布和适用范围可在全国标准信息公共服务平台核对：https://std.samr.gov.cn/hb/search/stdHBDetailed?id=2E1288291AD60971E06397BE0A0ABFD2 。

正式六章和原Word/PDF及锁定矩阵保持原版；上版六组费用结果标注暂停用于最终推荐，原始求解记录保留。

`报告采用版本锁定清单.json`按用户选择登记正常允许调整供区的弹性无下限、刚性共4组，以及保留的8组对照。模型实际导入依赖、原始输入、解和费用记录保留哈希，报告正文从对应版本引用。

项目入口和工作区整理见`工作区整理清单.json`。清理限未跟踪的Python/pytest缓存，先保存本地ZIP并逐文件回读验证；源代码、原始库、用户审查预览及主方案和对照保持。交付文件和正式成果哈希由`交付清单.json`登记。
