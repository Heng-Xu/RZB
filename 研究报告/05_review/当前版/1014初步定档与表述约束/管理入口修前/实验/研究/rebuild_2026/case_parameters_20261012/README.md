## 参数和对照

地区转供率从2025年7月5日全停全转收资按ΣJ/(ΣJ+ΣK)汇总，采用用户指定的全部电压等级口径。市区0.9154713209916743、邳州0.6729748663666113。市区电缆长度占比0.80由用户提供；邳州403条去重线路为0.10763904576865538。新增10 kV联络独立计价，沿用3 km长度及端部6万元，单项造价分别452.40、128.38万元。

两地均计算刚性、无2.0下限弹性、有2.0下限弹性。刚性沿用新增容量2.0上限及负荷下降被动超限规则；两种弹性仅差C/P≥2.0条件，均允许超过2.0并受物理设备上界限制。

## 承载力调整

原两类地区工况遗漏部分站级局部重载。现用已保存的站级序列选择各站正向峰值和最低净负荷所在的完整同期矢量，连同地区极值共市区45、邳州26个静态截面，逐年校核正常与各站最大单台主变N−1。原补值、年度峰值标定及正反向校核保留；本轮不开展SOC优化。

既有等效通道在原候选站对范围内，先依据2025参考设备容量和同期负荷标定转供收资，再固定用于各年方案。压缩容量后重新计算接收站余量，不能在压缩设备上重标定通道。地区收资不能唯一确定实际联络路径，聚合通道仍是明确的研究假设。

压缩设备单独核查，首年补强在2022年计费。市区原模拟三站保留设备和无通道设置。设备及负荷样本范围与地区实际统计分别说明，结果不要求人为匹配现实容载比或地区费用排序。

输入和摘要存在时寻优入口拒绝覆盖。重新寻优应在独立副本中调整输出路径；求解结果可能受时限影响，比较可行方案费用并保存有效下界和间隙。

`run.py`、`verify.py`和`report.py`保留首版仅两类地区工况的参数对照，其结果已由承载力复核版接替。`capacity_audit.py`保留识别首版邳州首年遗漏工况的证据。`研究报告/试算/20261012_案例承载力复核`为压缩起点标定的中间对照，后续以`20261012_案例承载力复核_存量网络固定`为本轮试算原始库。
