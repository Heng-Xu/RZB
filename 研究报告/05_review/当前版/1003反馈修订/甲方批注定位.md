# 10.03 甲方批注定位

## 批注 0

意见：先要说明弹性容载比的定义，毕竟它不是一个规范中已有的定义，比如：弹性容载比是指在满足相同技术约束条件下，通过全寿命周期成本比较确定的、允许适度偏离导则刚性上限的容载比取值。

锚定：弹性

上下文：研究统一容载比、年网供最大负荷及分布式电源渗透率的统计口径，分析年度负荷、光伏规模和站级净负荷特征，以实际工程及建设费用采购资料建立全寿命费用模型。刚性、弹性方案在同一区县共用容载比2.00的仿真起点，后续四年在正常运行、单台主变退出主变N-1、设备持续在役、转供能力及供电可靠性负荷守恒约束下联合寻优。市区初始站间转供率假定为50%，邳州依据局部馈线数据测算为28.29%；既有转供能力按零新增建设投资利用，新建联络按项目增加能力并计费。

案例第4年邳州刚性、弹性容载比分别为1.96、2.21，市区为1.95、2.21。两地区刚性、弹性方案新增措施全寿命费用现值分别为208566.29万元和35683.63万元，弹性费用降低82.89%。弹性方案增加主变、减少静态退出工况主变N-1工况所需储能，在相同技术约束与参考价格下经济性优于刚性。

在案例参数与容载比计算关系基础上，进一步构造A类、B/C类两类一般站群，拓展装机渗透率、年负荷平均增长率、95%峰值持续时间和两个工程成本比，完成12600组目标年静态寻优，形成仅列参数条件与推荐容载比区间的通用矩阵。研究表明，容载比应结合双向净负荷、峰段持续时间及站间转供能力确定，规划中宜先核定既有能力，再联合比选增容、配储和新增联络。规划建议优先采用弹性指标确定比选范围，保留刚性基准进行费用对照，并以实际资产、线路和工程价格核定具体方案。

锚定：1.1.3 容载比弹性研究的工程意义

上下文：储能在短时尖峰场景下可以提供容量支撑，但其额定功率和额定能量必须同时满足需求。100 kW/215 kWh储能柜在持续时间超过2.15 h后，受能量约束的持续支撑功率低于额定功率。将储能额定MW直接抵扣所有站级峰值，会高估其能力；只按MWh计价而忽略持续时间，则无法比较不同峰段条件下的工程费用。峰值持续时间因此是本报告推荐矩阵的必要参数[9][10]。

1.1.3 容载比弹性研究的工程意义

本项目研究容载比控制与建设方案之间的关系。对给定区域负荷、设备初态和候选措施，先求满足技术条件的主变、储能及联络配置，再计算年度容载比和全寿命费用。这样形成的推荐值具有对应的建设措施及约束条件，便于说明采用某个比值需要付出多少投资、获得何种容量配置，以及哪些条件发生变化后需要重新比选。
