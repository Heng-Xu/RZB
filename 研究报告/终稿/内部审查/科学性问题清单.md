# 终稿科学性问题及处理记录

| 类别 | 底稿主要问题 | 终稿处理 |
|---|---|---|
| 模型定义 | 物理容载比、规划控制值和存量容量关系容易混淆 | 明确2021年实际在役容量为共同起点，控制值只约束新增容量 |
| 模型起点 | 标准化容量可能被误作正式方案起点 | 正式方法仅采用实际在役资产；标准化形式未用于主模型 |
| 反向潮流 | 反向功率可能被误并入传统容载比分母 | 保持正向最大供电负荷为分母，反向潮流单独设指标和约束 |
| 时序解释 | 变电站年度极值可能被误加为片区同步峰值 | 采用局部最大反向潮流比例；仅QX-00005使用正式8760小时连续分析 |
| 可靠性与消纳 | 未量化指标可能被填为零 | 不量化期望缺供电量，不报告弃光率为零或新能源全部消纳 |
| 10 kV分析 | 容量筛查可能被描述为完整潮流验证 | 定位为局部网络容量与互济能力分析，保留阻抗和拓扑限制 |
| 推荐方法 | 人为高、中、低等级不能直接供规划人员计算 | 改为4项实际指标组合与规划响应直接对应的矩阵 |
| 矩阵验证 | 以片区正式分类直接生成矩阵结果会形成循环验证 | 查询规则仅接收技术可行性和4项指标；片区编号、正式建议类别及控制值扫描结果均不作为输入 |
| 区间边界 | 少量样本容易产生虚构连续区间 | 数据完整且技术可行的片区只列实际样本点组合，其余组合转入专项优化 |
| 推荐结果 | 非主导与技术约束片区可能被强行给出数值 | 分别保留“容载比非主导约束”和“技术约束优先” |
| 上限识别 | 扫描上界可能被误写成推荐上限 | QX-00001和QX-00005均只给建议下限，明确上限未识别 |
| 年化敏感性 | 汇总文字标签可能掩盖单场景结果 | 直接核对阈值、扩建、储能、成本和可行性，不引用内部标签 |
| 报告表达 | 正文含程序字段、文件路径和开发过程语言 | 全文重写为工程研究表达，图表全部采用中文名称和工程单位 |
