# 终稿科学性问题及处理记录

本清单记录研究报告从工作底稿到正式七章终稿过程中发现的主要问题。审查原则是：数值一致不等于科学语义一致，内容科学也不能替代项目正式成果结构的一致性。因此模型定义、目标函数、单位、验证性质、开题目录约束和适用边界均纳入终稿审查。

| 类别 | 发现的问题 | 最终处理 |
|---|---|---|
| 报告结构 | 二次重构过程中曾按方法逻辑自行扩展为10章，偏离开题报告已经确定的正式研究报告目录 | 撤回10章结构；严格恢复开题报告规定的7个一级章和22个二级节标题，并将其写入自动QA硬约束，后续不得自行改章名或章节数量 |
| 模型定义 | 物理容载比、规划控制值和存量容量关系容易混淆 | 明确2021年实际在役容量为共同起点，Rcap只约束规划期新增容量，既有容量不为满足Rcap而退役 |
| 模型起点 | 标准化容量可能被误作正式方案起点 | 正式主模型仅采用2021年实际在役资产；2×P2021仅保留为二级敏感性基准，不进入甲方主结论 |
| 物理容载比分母 | 原报告虽采用正向峰值，但没有说明储能等措施会改变不同规划路径的同步正向峰值 | 增加路径净负荷与正向同步峰值公式，明确P⁺按规划路径重新计算，不是跨方案固定常数 |
| 反向潮流 | 反向功率可能被误并入传统容载比分母 | 保持正向最大供电负荷为分母，反向潮流单列指标、设备承载条件和储能约束 |
| 优化目标 | 原报告只写单项投资“年化”，没有给出2022—2025年多年度目标函数 | 增加规划期目标函数：对2022—2025年各年度在役措施等年成本求和，措施投运后在后续在役年度持续计入 |
| 成本语义与单位 | 188.1800、481.9566、1745.5283、3359.0522等正式字段为cumulative in-service EAC，但原报告误写为“年化规划成本/万元·年⁻¹” | 统一改为“2022—2025年规划期累计在役等年成本/万元”；单项EAC仍保留“万元/年”量纲；自动审查新增语义硬校验 |
| 时序解释 | 变电站年度极值可能被误加为片区同步峰值；不同片区时序证据能力不同 | 采用局部最大反向潮流比例；QX-00005明确为正式2025年8760小时连续SOC回放，其他片区仅采用静态真实数据+经验持续时间场景 |
| 储能物理边界 | 若未写清充放电方向约束，可能误解为通过跨零充放电人为改善容载比 | 明确充电仅吸收本地反向/剩余功率且不跨零，放电仅服务本地正向负荷且不得形成外送 |
| 求解方法 | 历史项目语境中曾出现NSGA-II，可能与当前冻结v3.2主模型混淆 | 正式报告明确当前主规划器为确定性离散状态枚举/动态保留+HiGHS线性时序校核，不声称使用随机NSGA-II求正式结果 |
| AHP章节 | 开题报告明确规定“5.3 基于层次分析法的指标赋权”，但冻结v3.2正式Rcap结果并非由AHP加权求得；若为填满章节而事后编造权重，会改变正式模型因果链 | 严格保留5.3章节和AHP判断矩阵、一致性检验方法；当前无经专家确认的判断矩阵，因此不虚构具体权重，不用主观权重改写2.50/2.30正式结果；AHP定位为后续工程辅助决策接口 |
| 可靠性与消纳 | 未建模指标可能被填为零 | 不量化EENS，不报告弃光率为零或“新能源全部消纳”；未建模量保持未识别 |
| 10 kV分析 | 容量筛查可能被描述为完整潮流验证 | 定位为局部网络容量、接入位置与互济能力分析；缺少完整阻抗/拓扑时不声称AC或DC潮流结果 |
| 线路指标命名 | “网络容量支撑裕度”容易被理解为经过潮流和N-1校核的综合网络安全裕度，实际仅由最大线路统计负载率构造 | 正文和图件统一改为“110 kV线路统计负载余度”，并明确不等同电压、热稳定或完整潮流安全裕度 |
| 指标筛选 | 7个完整样本的Spearman相关系数约0.86容易被误作统计结论 | 仅作为小样本探索性信息冗余筛查，不作显著性判断和因果推断 |
| 推荐方法 | 人为高、中、低等级或样本间隙分箱会制造未经验证的连续区间 | 保留4项实际指标作为片区特征描述，主体矩阵改为“样本支持参考矩阵”；未覆盖组合转专项优化 |
| 区间边界 | 当前数值推荐仅QX-00001和QX-00005两个样本，不能支撑连续四维推荐区间 | 明确目前只能给出样本点与正式规划响应，不把相邻数值范围解释为可推广区间 |
| 矩阵验证 | 原“独立查询/反向验证”虽然查询函数不读取片区编号，但规则本身仍由同一批样本构建，属于循环使用同一数据 | 改称“样本内一致性检查”；明确不是独立验证、交叉验证或外部验证，不用其证明新片区预测能力 |
| 推荐结果 | 非主导与技术约束片区可能被强行给出数值 | 分别保留“容载比非主导约束”和“技术约束优先”，避免为形式完整填入虚假数值 |
| 上限识别 | 扫描上界3.0可能被误写成推荐上限 | QX-00001、QX-00005均只给建议下限；稳健近优集合延伸到3.0，故明确“上限未识别” |
| 敏感性解释 | 稳健近优下限稳定不等于每个敏感性情景的设备数量逐项完全一致 | 报告改为描述响应类型与Rcap近优集合的稳健性；5%稳健交集覆盖17个正式情景（含6个联合压力角点） |
| 新片区应用 | 若直接按四项指标“匹配”2.50/2.30，容易造成未经专项优化的套值 | 2.50/2.30仅作为高度相似片区的Rcap扫描和方案比选参考起点，正式值仍需该片区技术校核与优化确认 |
| Word/PDF分页 | 七章重排后第五章末段曾仅剩一行文字落在单独页面，随后第六章另起新页，形成近空白页 | 通过凝练第五章末段使其完整落在前页，不直接删除PDF页面；最终PDF为31页且无疑似空白页 |
| 报告表达 | 正文含程序字段、开发过程语言或模型内部标签会降低正式度 | 正文采用工程研究表达；程序字段、文件路径、内部标签仅保留在追溯材料，不进入正式报告 |
| 自动审查 | 原自动检查只验证数值字符串是否出现，且未约束开题目录 | 现已同时校验7章/22节开题目录、成本语义、单位、验证性质、线路指标命名、公式数量、图表交叉引用、空白页和旧术语禁用 |

## 当前科学性结论

冻结v3.2模型与正式结果未因本轮报告重构而改变。正式研究报告现已恢复并严格遵循开题报告规定的七章目录，同时保留二次科学审查中对多年度成本目标、路径内同步正向峰值、存量容量豁免、时序证据等级、样本参考矩阵和AHP适用边界等关键修正。

最终自动检查结果为`passed=true`、`issues=[]`：7章、22个二级节、6张图、8个Word表格、13个原生Word公式、31页PDF、8片区参考规则检查和10项正式数值追溯全部通过。该版本可作为当前正式研究报告终稿基线。
