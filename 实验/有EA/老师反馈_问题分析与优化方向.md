# 老师反馈：问题分析、项目核查与优化方向

> 针对老师对当前 EA 实验（`实验/有EA/`）提出的三个问题，逐条做：**① 复述问题 → ② 现状核查（对照代码）→ ③ 判断（问题是否成立）→ ④ 优化方向**。
> 结论先行：**三个问题都切中要害**；其中**问题2（缺线级/系统潮流约束）是真缺口、且便宜可补**，**问题1（用前沿证明决策变量价值）和问题3（增强 NSGA-II）能显著提升论文质量**。

## 问题1：拐点（运行点）的确定 —— 应由 Pareto 前沿确认两个决策变量把前沿"往更小方向"推

**① 老师的问题**：容载比 R 与配储 P 的"最优"具体值怎么定（拐点如何采用）？应使用 Pareto 前沿，确认这两个决策变量的取值能让**整条前沿在双目标象限向更小（更优）方向移动**。

**② 现状核查（代码）**：
- 我们**确实用 Pareto 前沿**取运行点：`E1_pareto` 中 `ideal=F.min; d=‖(F−ideal)/span‖; ki=argmin(d)` —— 即**归一化后距理想点最近**的非支配点作"拐点"，其每站 (R\*,P\*) 即推荐策略。
- 但**只做了"vs 全县刚性 2.0"的单点对比（E2b）**，**没有"前沿 vs 受限前沿"的对比**来证明"两个决策变量把整条前沿往里推"。

**③ 判断**：方向正确（确实从前沿读决策值），但**老师真正要的第二层——用前沿证明决策自由度的价值——目前缺失**。另外当前"拐点"是"距理想点最近"的折中点，并非严格意义的**最大曲率膝点**。

**④ 优化方向（P1，做）**：
- **核心：决策自由度消融对比（直接回答老师）**。在**完全相同的 gate + 容载比带约束**下，画 4 条前沿做 apples-to-apples 对比：
  ① 完整 (R + 储能)；② 仅调 R（储能=0）；③ 仅配储（R 固定=2.0）；④ 刚性（R=2.0 无储，单点）。
  **证明完整前沿支配各受限前沿**（整体向左下/更小双目标移动）→ 这就是"两个决策变量带来前沿内移"的量化证据。
  > 注意：四条前沿必须在**同一约束**下生成，才公平。
- **次要（cosmetic，点到为止）**：拐点选取由"距理想点最近"升级为**最大曲率膝点**（Kneedle / 距前沿两端点连线最远点），并显式报告方法；同时给"菜单"式 3 个参考点（最省成本 / 拐点 / 最低风险）以示透明。

## 问题2：约束似乎只考虑站内、缺线级系统约束 —— 站内求解后整合到县级会不会违反约束？

**① 老师的问题**：约束只建在站内，没有线级/系统级约束；会不会出现"各站求解后、整合成系统/县级时不满足约束"的情况？

**② 现状核查（代码）**：约束有两条：
- **① 逐站反向承载力闸**（站内）：`0.9·PV − 0.3·峰 − 储能 ≤ 0.85·R·峰`；
- **② 县级聚合容载比带**（县级）：`Σ主变 /(同时率0.85 × Σ峰荷) ∈ [1.8,2.2]`。
- 求解方式：NSGA-II **对全县 K 座站联合优化**（决策向量含所有站的 R,P），约束②**施加在整合后的全县解上**（pymoo 约束支配，前沿点已实证全可行）。

**③ 判断**：
- **老师指出的"缺系统级约束"成立**——这是真缺口，应当补。
- 一处需澄清（**不是反驳**）：因为是**全县联合求解、且容载比带本就施加在整合解上**，所以"**站内各自解完、整合后违反县级约束**"这一**具体失败模式不会发生**（我们没有"先各站独立优化再拼"这一步）。
- **真正缺的是"线级/上级 110kV 网络的潮流约束"**：现有县级约束是**容量比（容载比带）**，不是**潮流约束**；多座站**同时反送**汇集到上级 220kV 主变 / 110kV 线路的**聚合反向潮流**没有校核。高同时反送时，单站各自合规也可能**collectively 压垮上级线路/主变或抬高系统电压**——当前模型不会捕捉。

**④ 优化方向（P2，先做：便宜 + 纠正性）**：
- **新增"上级聚合反向潮流约束"**（县级硬约束③）：`Σ_j 各站净反向注入 ≤ 上级 110kV 线路 / 220kV 主变反向容量`。
- **关键物理（评审纠正，务必正确）**：聚合反向潮流要用**反向同时率 ≈ 1**（光伏出力天气强相关、近区各站近乎齐发），**不能沿用负荷的 0.85**；否则会**低估上级负担**。上级反向容量上限应**锚定 220kV 主变反向容量**（或作敏感性扫描），不要当自由参数。
- **附带收益**：这条约束**进一步加强站间耦合**（各站反送共用上级通道）→ **强化"为何必须用 EA"**的论证，与 E4 可扩展性相互印证。

## 问题3：物理评价函数如何介入、NSGA-II 如何与约束结合、能否在 NSGA-II 上做改进以对比更优

**① 老师的问题**：基于物理模型的评价函数如何介入？NSGA-II 搜索器如何与约束共同结合？能否在 NSGA-II 上做改进，与原方案对比更优？

**② 现状核查（代码）**：
- **评价函数介入**：`compute()` = **逐候选评分器**（3.8 ms/次）。一个 NSGA-II 个体 = 全县一套 (R,P) → 为每站构造 `ScenarioConfig` → `compute()` 一次性返回 **f₁、f₂ 与约束违反 G**（每站 gate + 带上下限）。
- **NSGA-II 与约束结合**：pymoo NSGA-II 用 **可行性优先的约束支配（constraint-domination）**——不可行解按约束违反量 CV 排在可行解之后；可行解再按非支配排序 + 拥挤距离选择。**不是惩罚函数法**（未用罚权重）。实证：前沿点全可行。

**③ 判断 + ④ 优化方向（P3，算法新意，最费力，含一个 framing 陷阱）**：
- **⚠ 必须避开的陷阱**：**不能声称"增强版能找到更好的前沿"**——因为 **E2 已证 vanilla NSGA-II 在小实例已达真前沿（HV比 K=5→1.000、K=8→0.991）**，没有提升空间；声称更优会与 E2 自相矛盾，老师/审稿人会当场识破。
- **诚实且可达成的改进 = 收敛效率 + 大规模可扩展**：
  - **小/中 K、固定有限预算**：增强版用**更少评价次数/代数达到目标 HV**（画 HV-vs-代数、或 evals-to-target 对比）；
  - **大 K（20–40）、固定预算**：vanilla **不收敛**（由 K=5 需 pop150/gen400 外推），增强版**最终前沿确实更优** —— 这是**最强、最诚实的"更优"**，且直接接 E4 可扩展性论证。
- **增强手段（推荐组合）**：
  - **带修复算子（repair）**：把越带的 R 向量投影回 [1.8,2.2]（按比例缩放各站 R）→ 个体**始终可行** → 收敛更快、前沿更稳；
  - **启发式热启动（warm-start）**：用每站"最小成本可行 (R,P)"初始化部分种群，替代纯随机 LHS；
  - （可选）记忆式局部搜索 / 混整数主变档（31.5/40/50/63 MVA）。
- **对比实验**：**增强 NSGA-II vs 原版 NSGA-II（再带 NSGA-III）**，报 **HV-vs-评价次数收敛曲线 + 大 K 末代 HV**；claim 框定为**效率与可扩展性**，不是小实例终态质量。

## 优先级与路线（6 页、约 2 周）

| 优先级 | 工作 | 为什么 | 工作量 |
|---|---|---|---|
| **P2（先做）** | 上级聚合反向潮流约束（反向同时率≈1，锚定 220kV 反向容量） | 纠正性缺口、便宜、且强化"为何用 EA" | 小 |
| **P1（做）** | 决策自由度消融：完整(R+储能) vs 仅R / 仅储 / 刚性，**证明前沿内移** | 直接回答老师"两个决策变量推动前沿"；清晰 | 中 |
| **P3（时间允许）** | 增强 NSGA-II（修复+热启动）vs 原版，**效率+大K**对比 | 补算法新意（审稿曾提"算法偏弱"）；注意 framing 陷阱 | 大 |

**对论文的意义**：P2 让约束体系物理完整（站内 + 线级/系统）；P1 把"省12.3%单点"升级为"决策自由度使整条前沿内移"的强论证；P3 把标准 NSGA-II 升级为有算法贡献的增强版。三者合起来，正是把论文从"中等"推到"扎实 + 有新意"的关键。

> 实现位置：均在 `实验/有EA/scripts/`（`county_model.py` 加上级约束与反向同时率；`ea_county.py` 加 E7 消融 / E8 增强算法；`ea_figures.py` 加对应图）。不影响 `无EA/` 与既有结果。

## 执行结果（2026-06-30，已落地 P2 + P3；P1 暂缓）
> 用户定调"提升规模凸显进化算法"，本轮做了 **P2（系统约束→baseline）+ P3（增强 NSGA-II 超越 baseline，大 K 为主）**；P1（决策自由度消融）按用户取舍暂缓。详见 `有EA/03_EA实验结果摘要.md §3.5`。

**P2 — 上级系统潮流约束（问题2）已加入**：`Σ站净反向上送·η(=1.0) ≤ 0.85·R₂₂₀·(0.85·Σ峰)`，约束数 K+2→K+3，三类约束已归一化。
- 影响(K=20)：成本下限 +28 万（≈0.15%，前沿外移）；R₂₂₀∈{1.6,1.8,2.0} 稳健。
- **诚实结论**：约束物理完整、答复了"站内合规、系统违约"之虑；但对本合成县**近乎不绑定**（各站过逐站闸已配储能使聚合反送本就低于上级限额），仅更弱上级电网/更集中反送的县才显著绑定。

**P3 — 增强 NSGA-II（问题3，算法创新点）已实现并验证更优**：修复算子 + 启发式热启动。
- **同问题（含系统约束）、同固定预算、3 seed** 下，末代 HV 比（增强/经典）：**K10 1.01× → K20 1.09× → K30 1.41× → K40 1.45×**，**优势随规模单调扩大**。
- K=40 收敛：经典随机初始在高维约束下早期下挫、gen100 仍欠收敛；增强快速收敛趋平。
- **framing 守住**：小 K（1.01×）≈parity、**不宣称更优**（经典已达最优，与 E2 一致）；"更优"只在固定预算 + 大 K。
- 图：`fig_scaling_gap.png`（头条）、`fig_enhanced_convergence.png`、`fig_system_constraint.png`。

**P1（决策自由度消融，证明 R+储能把前沿内移）= 暂缓**，可作为后续补强（直接回应"两个决策变量推动前沿"）。
