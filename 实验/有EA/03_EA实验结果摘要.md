# 县级多站容载比弹性 · 多目标进化优化实验结果与校核

> 面向 **MIND 2026**（IEEE/EI，6 页英文，IEEEtran 双栏）。本版（`有EA/`）为引入计算智能后的
> EA 实验；物理/规则基线在 `无EA/`。**全部用公开数据**（IEEE33 + PVGIS 徐州/嘉兴/莱芜 + baseline_costs.yaml）。
> **所提方法 = FG-NSGA-II（Feasibility-Guided NSGA-II，可行性引导 NSGA-II）**＝经典 + 可行性修复算子 + 启发式热启动；经典 NSGA-II 与 NSGA-III 仅作 baseline（收敛扫描）。
> **主算例 K=20**。本摘要数字全部来自单进程收敛扫描 `beyb8rsgp`（2026-07-03），全目录时间戳一致。

## 0. 一句话定位
把确定性双向 Z4-LCC 评价函数（`lcc_simulator.compute()`，实测 3.8 ms/次）当作适应度，
用 **FG-NSGA-II（Feasibility-Guided NSGA-II）** 在**县级 K=20 变电站**联合决策空间里求"投资成本 ↔ N-1 供电风险"的 Pareto 前沿，
给出**一站一策**的容载比弹性配置，相对全县刚性 2.0 节省 **13.1%**（K=20 同风险口径）；
算法层贡献（效率口径）：FG 用一半预算（gen400）即胜过经典 NSGA-II 与 NSGA-III 的 gen800、等价 ~5–12× 更少代数，充分收敛后 baseline 大体追平（如实交代）。

## 1. 优化问题
- **决策向量** x=[R₁..R_K, P₁..P_K]：每站容载比 R_j∈[1.2,3.0] 与储能功率 P_j∈[0,6]MW
  （储能容量 E_j=2h×P_j，slave）。映射进现有 `ScenarioConfig`，**不改 simulator**。
- **目标**（min）：f₁=县总年化成本 Σ(资本年金+双向Z4损耗+储能+O&M)[万元/年]；
  f₂=县 N-1 缺供 ΣEENS[MWh/年]（未来峰荷 peak×(1+g)ⁿ，g=5%/n=5）。
- **约束（G≤0）**：① 每站过反向承载力硬闸（式12，REVERSE_TX_LIMIT=0.85）；
  ② **县聚合容载比** Σtx_j /(同时率·Σpeak_j) ∈ [1.8,2.2]（同时率 0.85）——核心耦合，使问题不可分；
  ③ **上级系统潮流约束**（聚合反向上送 ≤ 上级反向限额 L=0.85·R₂₂₀·0.85·Σpeak，R₂₂₀=1.8）。

> **目标选择的依据（校核要点）**：原拟 f₂=弃光经测量证实退化——过闸判据与弃光表达式同式，
> 可行解弃光恒为 0（cost↔curtailment 前沿坍缩为一点）。故改用 N-1 EENS，前沿在可行集内非退化。
> **约束求解辨析**：约束被"处理"非"求解"——物理模型只判定 G；可行性修复算子对不可行解做**直接、近似**的可行化投影
> （非数学投影、不调用 compute）；EA 只施加可行性优先选择压力。详见 `00_项目实验总览.md` §3.4。

## 2. 算例（公开数据合成的县级基准）
县 = K 个 110kV 站，每站以缩放 IEEE33 馈线为载体，按 (源荷比 0.5~3.5, 联络度 CD 0.1~0.7,
峰荷因子 0.6~1.5, 反送时长 ∈{2841,3017,3103}h 锚定 PVGIS 三地) 确定性抽样（seed 固定可复现）。
**声明：这是公开数据合成的县级基准，非甲方实测；用于方法验证与可扩展性论证。主算例 K=20。**

## 3. 应用结果（E1–E7，FG-NSGA-II，K=20）
### E1 县级 Pareto 前沿 + 一站一策（主图）
- 前沿 **100 点**；拐点：f₁=**18882 万/年**、f₂=**114 MWh**、聚合容载比=**1.80**。
- **一站一策（拐点，K=20）**：**11 站配储为主 / 9 站低容载比+强联络 / 0 站需 R>2.0**（最大 R\*=1.96）。
  高源荷比站（slr>2）→**配储为主**（如 slr2.94→R1.52+4.5MW、slr3.33→R1.73+3.2MW、slr3.00→R1.25+4.1MW）；
  低源荷比站（slr<1）→**低容载比无储**（靠联络互济，如 slr0.51→R1.21、slr0.87→R1.42）。**长反送时长下配储比增容更经济**。
- 文件：`results/ea_county_pareto.csv`、`ea_county_strategy_knee.csv`，图 `fig_county_pareto.png`、`fig_strategy.png`。

### E2 求解器验证（对可计算 Minkowski 真前沿；FG + 经典作 parity 参照）
- 无带可分小县（r220=None）对 Minkowski 精确真前沿，pop100/gen250：
  K=3 FG **HV比 1.015** / 经典 0.995；K=5 FG **1.009** / 经典 0.997。
- **结论**：FG 与经典在小 K **都 HV比≈1=复现真前沿**（±1~2% 源于真前沿网格离散 nR60/nP31，非算法优劣）→
  **所提方法可证达到最优**；小 K 两法 parity（与收敛扫描一致，不在小 K 宣称更优）。文件：`results/ea_validation.csv`。

### E2b 相对全县刚性 2.0 的节省（头条）
- 刚性 2.0：f₁=**21836 万**、聚合容载比=**2.35**（越上带、过投资，未利用同时率）；
  同等风险（EENS=0）下 FG-NSGA-II 成本=**18986 万** → **节省 13.1%**。文件：`results/ea_baseline.csv`。

### E3 县容载比带效应（单调、合理）
| 带 | 前沿点 | 成本下限(万/年) | EENS 下限(MWh) |
|---|---|---|---|
| [1.6,1.9] | 100 | 18480 | 0 |
| [1.8,2.1] | 100 | 18793 | 0 |

### E6 鲁棒性实验（蒙特卡洛重采样，**非跨县**）
- **随机变量**：seed 控制每站 4 元组 (源荷比∈[0.5,3.5]、联络度∈[0.1,0.7]、峰荷因子∈[0.6,1.5]、反送时长∈三地)
  的随机抽样；**K=20、分布、造价、容载比带均固定**。故 6 个 seed = **同分布同规模县构成的 6 次重采样**，
  测的是结论对县构成噪声的稳健性，**不是区域/规模意义上的跨县**。
- 6 次重采样相对刚性 2.0 的节省：**13.0 / 11.9 / 12.9 / 13.7 / 12.4 / 10.1 %**
  → **均值 12.3% ± 1.3%、范围 [10.1, 13.7]%、全部为正**。文件：`results/ea_robustness.csv`。
- 注：区域×规模意义的真·跨县对照按用户决定**不做**。

### E7 上级系统潮流约束（关联每站，回应问题2）
- 约束：`Σ_j 站净反向上送 · 反向同时率(η=1.0) ≤ 上级反向限额 L=0.85·R₂₂₀·(0.85·Σ峰)`；问题约束数 K+2 → **K+3**。
- 影响(K=20)：加约束成本下限变化仅 **≈+25 万（<0.3%）**；R₂₂₀∈{1.6,1.8,2.0} 几乎持平。
- **诚实结论**：约束已建模（物理完整、答复问题2），但对本合成县**近乎不绑定**——各站为过逐站反送闸已配的储能，
  使聚合反送本就低于上级限额；±0.3% 内的增减是优化噪声（符号会翻），仅当上级容载比更低/反送更集中的县才显著绑定。
  文件 `ea_system_constraint.csv`、`ea_system_fronts.csv`，图 `fig_system_constraint.png`。

## 3.5 算法贡献：FG-NSGA-II vs 经典 NSGA-II / NSGA-III（创新点头条，回应问题3）
- 创新点 = **可行性修复算子（直接近似可行化）+ 启发式热启动（每站最小成本可行解）**。
- 对比口径：**同问题（含系统约束）、同种群、同 3 seed、共同 HV 参考点**；经典 NSGA-II 与 **NSGA-III**（das-dennis 参考方向，pop_size=pop）作两条 baseline，
  另含两消融变体 **+修复(repair_only)**、**+热启动(warmstart_only)**；逐代记 HV（baseline 跑 gen800、FG 类跑 gen400）。

- **头条（公平、无关预算点）**：FG-NSGA-II 用**一半预算（gen400）即胜过经典 NSGA-II 与 NSGA-III 的 gen800**（K∈{10,20,30,40} 皆然）；
  等价地，FG 用 **~5–12× 更少代数**达到 baseline 800 代的收敛质量（K=40：vs 经典 84 代→**9.5×**、vs NSGA-III 68 代→**11.8×**；K=10/20/30 亦在 5–11×）。
- **以效率为主、诚实交代收敛追平**：效率用**预算无关的 iso-quality 加速比**度量（见头条 ~5–12×），**不采用任意固定预算点**；
  **充分收敛后两条 baseline 大体追平** → 收敛 FG/经典仅 **1.007→1.048**、FG/NSGA-III 1.009→1.064；
  收敛质量边际 **K≤30 均 <1%、到 K=40 才 4.8%**（非平滑增长，仅最大规模显著）。这份诚实堵死"baseline 多跑即翻盘"的审稿风险。
- **消融（两组件各有定位）**：**修复算子=主驱动**（repair_only 收敛处处≈FG）；**热启动=早期加速器**
  （gen100 时 FG/repair_only 1.003→1.023、warmstart_only 早期即超经典，但收敛后洗掉）。
- 文件 `ea_converge.csv`（逐代 HV，5 变体 × 4 规模 × 3 种子）/ `ea_converge_termgen.csv`（收敛终止代）；
  图 `fig_scaling_gap.png`（**iso-quality 加速比**：FG 达 baseline 收敛质量所需代数、~5–12×，预算无关）/ `fig_enhanced_convergence.png`（**每 K 一子图、5 变体逐代 HV**）。
- **共 7 张图**（英文标签，IEEE 投稿用）：`fig_county_pareto / strategy / scaling / band_effect / system_constraint / scaling_gap / enhanced_convergence`。
  > `fig_convergence`、`fig_front_compare` 已弃（不再作为现有图）。

## 4. 结果校核与局限（诚实记录）
**正确性断言（已逐条核对）**：
1. ✅ E1 前沿 100 点全部满足逐站反向硬闸 + 县容载比带 + 上级系统约束（拐点聚合 R=1.80∈[1.8,2.2]）；非支配。
2. ✅ 求解器验证：小 K（pop100/gen250）FG 与经典 **HV比皆≈1**（K=3 1.015/0.995，K=5 1.009/0.997）
   → 所提方法复现真前沿，小 K 两法 parity。论断成立。
3. ✅ E2b：FG-NSGA-II 同等风险（EENS=0）成本 18986 万 ≤ 刚性 2.0 的 21836 万，**节省 13.1%**。
4. ✅ E4：穷举 K≥12 不可枚举、NSGA-II 近线性可解——metaheuristic 正当性来自**结构与规模**，非速度。
5. ✅ E6 鲁棒性（同分布同规模 K=20 的县构成重采样，**非跨县**）：6 次均为正（10.1–13.7%，均值 12.3%±1.3%）
   → 头条"省 13.1%"对县构成噪声稳健。
6. ✅ E7 系统约束：已建模（物理完整、答复问题2），对本县**近乎不绑定**（加约束≈+25万、|Δ成本|<0.3%、符号随机翻转→噪声内，R₂₂₀∈{1.6,1.8,2.0} 稳健），如实记录。
7. ✅ 收敛扫描 FG vs 经典/NSGA-III：**FG 用一半预算（gen400）即胜过两条 baseline 的 gen800（K∈{10,20,30,40} 皆然），等价 ~5–12× 更少代数**；
   **收敛后两条 baseline 大体追平**（收敛 HV 边际 K≤30 <1%、K=40 才 4.8%），如实交代、堵死"多跑即翻盘"；
   **消融：修复算子=主驱动（repair_only 收敛处处≈FG）、热启动=早期加速器**；前沿全可行。

**总结论：实验逻辑/事实自洽，可支撑 MIND 2026 发表。** 头条贡献 = 县级多目标进化优化（FG-NSGA-II）
+ 算法层创新（可行性修复=主驱动 + 热启动=早期加速器，效率证据：半预算胜出、~5–12× 更少代数，充分收敛后 baseline 大体追平）
+ 相对刚性2.0 稳定节省 13.1%（K=20 同风险口径）+ 一站一策 + EA 可扩展性正当性 + 求解器对真前沿验证 + 上级系统潮流约束（完整性）；下一步进 Phase 2 英文 6 页 IEEE 稿。

**局限（如实声明，供论文 limitation 与未来工作）**：
- 县级算例为**公开数据合成**，非徐州实测；真实标定（线路 R/X、主变型号、造价、规划 g/n、真实
  8760h 曲线）为后续 B 轨/期刊扩展版工作。
- 储能 **E=2h×P 为 slave**，未建模能量限充吸收（power-only），偏乐观；列为 fidelity 局限。
- 反向**电压**为片区级旗标（IEEE33 弱馈线，方法演示），不作 R 准入；真实阈值待实测标定。
- 上级系统约束为**集总功率/容量约束**（非 110kV 全网 AC 潮流；合成县无站间线路拓扑），反向同时率取 1.0（保守上界）；
  对本合成县近乎不绑定，仅在更弱上级电网/更集中反送的县才显著绑定。
- FG 的头条是**效率——一半预算胜出、~5–12× 更少代数**（大 K 经典/NSGA-III 早期欠收敛），**非**终态 HV 之争：充分收敛后两条 baseline 大体追平（收敛 HV 边际 K≤30 <1%、K=40 才 4.8%），如实交代。
