## 0. 一句话定位
把确定性的**双向 Z4-LCC 物理模型**当作评价函数（适应度），用 **FG-NSGA-II（Feasibility-Guided NSGA-II）** 在**一个县内 K=20 座变电站**的
联合决策空间里，求"**投资成本 ↔ N-1 供电风险**"的 Pareto 前沿，给出**一站一策**的容载比与储能配置；
相对现行"全县刚性 R=2.0"稳定节省 **13.1%**（同风险口径）。**算法层贡献（效率口径）**：FG-NSGA-II 用**一半预算（gen400）即胜过
经典 NSGA-II 与 NSGA-III 的 gen800**（K∈{10,20,30,40} 皆然）、等价 **~5–12× 更少代数**达到 baseline 800 代的收敛质量；充分收敛后两条 baseline 大体追平（如实交代）。

## 2. 核心思想：约束 vs 目标（理解全篇的钥匙）
> **约束 = "什么方案算数"（可行性闸，硬性、是/否）；目标 = "在算数的方案里追求什么"（权衡，软性、多少）。**
> EA 做的事：在**约束**圈定的可行空间里，沿**目标**找出最好的一整排（非支配）方案。

## 3. 问题建模

### 3.1 控制对象（决策变量 = EA 的"手"）
对**每座站 j** 控制 **2 个连续量**：

| 控制量 | 范围 | 物理含义 / 映射 |
|---|---|---|
| **R_j 容载比** | [1.2, 3.0] | 实际在**定主变容量** `tx = R_j × 峰荷` |
| **P_j 储能功率(MW)** | [0, 6] | `storage_mw`；容量 E=2h×P 跟随（非独立动作）|

决策向量 **x = [R₁…R_K, P₁…P_K]**。
> **关键澄清**：EA 控制的是 **R、P**；**"反向承载力"不是控制量而是约束**（由 R、P 算出的一道判定）；
> **N-1 风险是目标 f₂**，不是控制量。

**动作维度 = 2K**（主算例 **K=20 → 40 维**）。**节点账（K=20）**：决策节点（变电站）**20 个**；
电气母线 **660 个**（每站建在 33 母线 IEEE33 馈线上）；主变 **40 台**（每站 2 台）；PV 注入母线 **120 个**。

### 3.2 约束维度（硬约束，违反即淘汰）
**① 反向承载力闸（物理安全，逐站）**
　`0.9·P_PV − 0.3·P_峰 − P_储能 ≤ 0.85·R·P_峰`（式12）
含义：中午光伏倒送、扣储能吸收后，**流过主变的反向视在功率 ≤ 主变额定的 85%**（留 15% 裕度）。
- **不含网损**：这是瞬时功率 vs 主变容量的容量约束；网损单独算、计入成本 f₁。
- **反向电压（1.05 p.u.）**：算了并作"片区旗标"报告，但**未作硬约束**（弱馈线方法演示，真实阈值待实测标定）。

**② 县级容载比带（规程 + 耦合，全县）**
　`Σ主变容量 /（同时率0.85 × Σ峰荷）∈ [1.8, 2.2]`
含义：县整体既不欠建（<1.8）也不过建（>2.2）。**这条把各站绑在一起 → 问题不可分 → 必须用 EA。**

**③ 上级系统潮流约束（聚合反向承载力，全县；按老师反馈补入）**
　`Σ_j 站净反向上送 · 反向同时率(η=1.0) ≤ 上级反向限额 L_rev(R₂₂₀)`，其中 `L_rev = 0.85·R₂₂₀·(0.85·Σ峰荷)`，**R₂₂₀=1.8**（并扫 1.6/2.0 敏感性）。
含义：把各站的反向上送在 **220kV 上级母线**处聚合，受上级主变反向承载力约束——**让站与站不仅靠容载比带、也在系统潮流上相互关联**。
> N-1 可靠性**不在约束里**（放目标 f₂）——不"禁止"风险，而是让决策者在前沿上权衡。

### 3.3 目标维度（双目标，同时最小化，互相冲突）
- **f₁ = 县总年化成本（万元/年）**，子项：
  `f₁ =（Z1主变 + Z2线路 + Z储能 − Z5残值）× CRF + Z3运维 + Z4双向网损 + 弃光(≈0)`
  - 资本年金化：主变 Z1、线路 Z2、储能投资、减残值 Z5，乘资本回收系数 CRF（r=6%、25 年）；
  - 逐年运行：运维 Z3（主变+线路+储能各费率）、**双向 Z4 网损**（馈线正/反 + 主变空载/负载正/负载反，×电价，项目创新点）、弃光惩罚（可行解≈0）。
- **f₂ = 县未来规划年 N-1 供电风险 ΣEENS（MWh/年）**：按**未来峰荷** peak×(1+g)ⁿ（g=5%, n=5）校核缺供电量。
- **冲突来源**：R↓/少储 → 省钱(f₁↓)但 N-1 余量小(f₂↑)；R↑ → 安全(f₂↓)但贵(f₁↑)。**故无唯一最优，只有 Pareto 前沿。**
- **为何是"成本↔风险"而非"成本↔弃光"**：实测发现过反送闸判据与弃光表达式**同式** → 可行解弃光恒为 0。

### 3.4 评价函数 + 搜索器（融合逻辑 + FG-NSGA-II）

**两个部件：**
- **物理模型 `compute()` = 评价器**（3.8 ms/次）：输入一套全县方案 → 一次算出目标 (f₁,f₂) 与三约束的违约向量 G。**只做判定、不做求解，无需代理模型。**
- **FG-NSGA-II = 搜索器（所提方法）** = 经典 NSGA-II（非支配排序 + 拥挤度 + 可行性优先）再加两个算子：
  - **可行性修复算子 FeasRepair**：对每个候选解，用闭式/贪心规则**一次前向**搬到**近似可行**（缩放 R 入带 → 逐站补储能/必要时升 R 过反送闸 → 补储能满足系统约束）；
  - **启发式热启动 WarmStartSampling**：LHS 多样性 + 注入 25% "低 R + 0 储"种子，全部先过修复 → **初始种群即近似可行**。
  > **公平性**：两个算子**全程不调用目标函数**（纯 numpy），故 FG-NSGA-II 与 baseline **每代目标评估次数严格相等 = pop×gen**——增益来自"起点更可行、全程更可行 → 收敛更快"，不是多花预算（详见 §5.B）。

**关于约束：本质上没有"求解"，只有"处理"（constraint handling）。** 约束从不被解析地解出，全程只被三件事**处理**：

| 对约束做什么 | 谁做 | 是"求解"吗 |
|---|---|---|
| **判定**：算出违约向量 G（可行否、超多少）| 物理模型 | 否——只校核，不改 x |
| **修复**：把不可行解搬到**近似**可行 | 可行性修复算子（仅 FG-NSGA-II）| 否——启发式近似、不保证可行、非数学投影（不求最近点）、不调用 `compute()` |
| **选择**：可行＞不可行、两不可行比 CV，淘汰出可行种群 | EA 的 constraint-domination | 否——统计意义上的可行性"涌现" |

> 三者没有一个是严格意义的求解：判定是校核、修复是启发式近似、选择是淘汰。**约束被"处理"，不被"解出"。** 论文措辞用 *constraint handling / repair operator / near-feasible*，避免 "solve / solver"。

**经典 vs FG-NSGA-II——差别正在"约束处理方式"（创新点所在）：**
- **经典 NSGA-II（baseline）**：只有"判定 + 选择"。可行性靠选择压力**涌现**（随机变异撞出可行解、不可行被淘汰）。高维（大 K）下可行域 = 带 ∩ 逐站闸 ∩ 系统约束 的交集占比骤小，越来越难撞进去 → **早期收敛慢、可行解稀**。
- **FG-NSGA-II（所提）**：多了"可行性修复"——每个个体进种群前已被搬到近似可行，**绕过"随机撞可行域"这道坎** → **收敛更快**：一半预算即胜过 baseline 满预算，等价 ~5–12× 更少代数（详见 §5.B）。

**EA 的真正职责、及为何不可替代：** EA **不"解"约束**，它**搜索优化问题的解**——在（近似）可行域里找出"成本↔风险"非支配前沿。修复只给"可行"、**给不出前沿**（它不看目标、不寻优）；2K 维里"哪些可行组合非支配"必须靠 EA 搜索，且 K≥12 穷举爆炸（E4）→ **EA 不可替代**。

> **一句话融合**：**物理模型判定约束 + 修复近似处理可行性 + EA 搜索目标前沿**——约束是被*处理*的（非求解），前沿是被 EA *搜索*出来的。

## 4. 算例：县模型（公开数据合成）
- **县 = K 座 110kV 站**（主算例 **K=20**），每座以缩放 IEEE33 馈线为载体，按四个量**逐站随机抽样**：
  源荷比∈[0.5,3.5]、联络度 CD∈[0.10,0.70]、峰荷因子∈[0.6,1.5]、反送时长 t_rev∈{2841,3017,3103}（三地）。
- **渗透率怎么定/高低界线**：以**源荷比**（PV装机/峰荷）为主参数；电量渗透率 ≈ 源荷比×0.31（约 15%–109%）。
  高/低不是主观阈值，而是**反送闸**决定的临界：`源荷比_临界=(0.85R+0.3)/0.9`（R=2.0→**2.22**）；高于→反送绑定（需储能/增容）。
- **同时率 0.85**：聚合峰荷 < 各站峰荷之和，是县级容载比可低于站级的物理来源。
- **为何主算例选 K=20**：经典 NSGA-II 在 K=20 已开始欠收敛（见 §5.B，早期收敛慢），FG-NSGA-II 在此显著受益 →
  **把"应用最优"与"算法创新"绑定在同一规模**；K≥12 起穷举已不可行（E4），EA 的正当性也在此体现。
- **声明：合成县级基准，非甲方实测**；用于方法验证与可扩展性论证。

## 5. 实验设计与结果（两类：应用 E1–E7 用 FG-NSGA-II 解问题；算法收敛扫描比经典/NSGA-III/FG）

> **两类实验自变量/因变量正好相反**：
> **E1–E7（应用/工程）**＝固定算法（FG-NSGA-II）、变问题（方案/约束/规模/县），回答"问题长什么样、省多少、稳不稳"；
> **收敛扫描（方法/算法）**＝固定问题（同一个县）、变算法（经典 NSGA-II / NSGA-III / FG-NSGA-II + 两消融变体），逐代记 HV，回答"FG 快不快、快多少、随规模怎么变"。
> 二者交付物正交、**不重复**；baseline（经典 NSGA-II、NSGA-III）**只在收敛扫描出现**。

### 5.B 算法贡献（FG-NSGA-II vs 经典/NSGA-III，收敛扫描，论文创新点头条）

**收敛扫描**：对 **K∈{10,20,30,40}** 同一县（`build_county(K,seed=0)`，含系统约束 R₂₂₀=1.8、带 [1.8,2.2]），
用**完全相同**的种群与**相同 3 个种子**跑 **5 个变体**——经典 NSGA-II、NSGA-III、FG-NSGA-II，及两个消融变体
**+修复(repair_only)**、**+热启动(warmstart_only)**——并记录**逐代 HV**（`ea_converge.csv`）。
baseline 跑到 gen800、FG 类变体跑到 gen400（收敛终止代见 `ea_converge_termgen.csv`）。

> **头条（公平、无关预算点）**：FG-NSGA-II 用**一半预算（gen400）即胜过经典 NSGA-II 与 NSGA-III 的 gen800**（K∈{10,20,30,40} 皆然）；
> 等价地，FG 用 **~5–12× 更少代数**达到 baseline 800 代的收敛质量（K=40：vs 经典 84 代→**9.5×**、vs NSGA-III 68 代→**11.8×**；K=10/20/30 亦在 5–11×）。
>
> **以效率为主、诚实交代收敛追平**：效率用**预算无关的 iso-quality 加速比**度量（见头条 ~5–12×），**不采用任意固定预算点**；
> **充分收敛后两条 baseline 大体追平** → 收敛 FG/经典仅 **1.007→1.048**、FG/NSGA-III 1.009→1.064；
> 收敛质量边际 **K≤30 均 <1%、到 K=40 才 4.8%**（非平滑增长，仅最大规模显著）。这份诚实堵死"baseline 多跑即翻盘"的审稿风险。
>
> **消融（两组件各有定位）**：**修复算子=主驱动**（repair_only 收敛处处≈FG）；**热启动=早期加速器**
> （gen100 时 FG/repair_only 1.003→1.023、warmstart_only 早期即超经典，但收敛后洗掉）。

**严谨性 / 客观性（受控对照，可复核）**：

| 控制项 | 各变体是否一致 | 说明 |
|---|---|---|
| 问题 | ✅ 同 `CountyProblem(stations,band,r220)`、同 `build_county(K,seed=0)` | 与 E1/E7 同口径 |
| 约束 | ✅ 逐站闸 + 带[1.8,2.2] + 上级系统约束 R₂₂₀=1.8 | 各臂完全相同 |
| 种群 | ✅ 同 pop（NSGA-III 参考方向数=pop → pop_size=pop）；baseline gen800、FG 类 gen400 | 每代评估次数严格相等 = pop×gen |
| 随机性 | ✅ 同 3 个种子，取 mean±std | 计入随机性 |
| HV 参考点 | ✅ 由**所有变体末代前沿共同**确定 | 对同一 nadir 测 HV |
| **唯一变量** | 算法本身（经典 / NSGA-III / FG / +修复 / +热启动）| FG 的两个算子**不调用目标函数** → 每代预算不偏向 FG |

> **诚实交代**（已体现、未夸大）：修复/热启动每代多一点点 CPU（纯 numpy，相对每代 K 次 ~3.8ms 的 compute 可忽略）；
> **头条是效率——一半预算胜出、~5–12× 加速**；充分收敛后 baseline 大体追平（收敛 HV 边际 K≤30 <1%、K=40 才 4.8%），如实交代。
> 数据来自单进程收敛扫描（**5 变体 × 4 规模 × 3 种子**逐代 HV）。

## 6. 结果校核与定性澄清（诚实记录）

**定性边界（讨论中明确）**：
- **应用主结果（E1/E2b/E3/E7）= 单个代表县**（seed=0, **K=20**）；一站一策与"省 13.1%"均来自此县。
- **E6 是鲁棒性实验、不是跨县**：seed 只随机每站（源荷比/联络度/峰荷因子/反送时长），**K、分布、造价、带均固定**
  → 同分布同规模县构成的 6 次重采样。**真·跨县（区域×规模）未做**（县间无电气耦合，跨县只应是鲁棒性或对照）。

**正确性断言（已逐条核对）**：① 前沿全可行（逐站闸+带+系统约束）+非支配；② 求解器对真前沿小 K HV比≈1（FG+经典皆 parity）；
③ FG-NSGA-II 同风险成本 ≤ 刚性 2.0（省 **13.1%**）；④ 穷举 K≥12 不可解、NSGA-II 近线性 → EA 必要；
⑤ **FG-NSGA-II 用一半预算（gen400）即胜过经典 NSGA-II 与 NSGA-III 的 gen800（K∈{10,20,30,40} 皆然），等价 ~5–12× 更少代数**；
**收敛后两条 baseline 大体追平**（收敛 HV 边际 K≤30 <1%、K=40 才 4.8%），如实交代、堵死"多跑即翻盘"；
**消融：修复算子=主驱动（repair_only 收敛处处≈FG）、热启动=早期加速器**；
⑥ 上级系统约束已建模、对本合成县近乎不绑定（加约束 **≈+25 万、<0.3%**、符号随机翻转→噪声内）如实披露。

**局限（论文须如实披露，列 future work）**：
- 县级算例为**公开数据合成**，非徐州实测（实测标定为 B 轨/期刊扩展）；
- 储能 **E=2h 跟随**、未建能量限充吸收（power-only，偏乐观）；
- 反向电压为**片区旗标**（弱馈线演示），不作 R 准入；
- 上级系统约束对本合成县**近乎不绑定**（参数口径来自推导，非实测；真实县反送强时才显著）；
- **绝对成本沿用演示损耗模型 → 正文以相对 % 为主**；
- 展示的是"**向下弹性**"（用异质+储能+同时率把县容载比降到 1.80<2.0），叙事勿写成"向上增容"。

## 7. 结论与下一步
- **结论**：实验逻辑/事实自洽，**可支撑 MIND 2026（EI）发表**。贡献链：
  **县级多目标进化优化（FG-NSGA-II）→ 算法层创新（可行性修复=主驱动 + 热启动=早期加速器，效率证据：半预算胜出、~5–12× 更少代数）→ 相对刚性 2.0 稳定省 13.1%（同时率+异质+配储）→ 一站一策 → EA 可扩展性正当性 → 求解器对真前沿验证 → 上级系统约束模型完整性**。
  经典 NSGA-II 与 NSGA-III 退居 baseline（仅收敛扫描），论文主线讲 FG-NSGA-II 与其创新点。
- **下一步 = Phase 2**：英文 6 页 IEEE(IEEEtran) 稿（头条＝FG-NSGA-II 效率增益"半预算胜出 + ~5–12× 加速"，含**经典 NSGA-II / NSGA-III / FG + 两消融变体**收敛对比；E2/E4 验证+动机；E1/E2b 应用 K=20；E3/E6/E7 压缩）。
