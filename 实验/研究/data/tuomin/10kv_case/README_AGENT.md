## 数据质量特别说明
### SRC06“装机容量(kVA)”
该字段与现场配变容量观察存在明显不一致，例如墩南线字段仅200kVA但配变台数39，因此只保留原始值，禁止作为馈线总负荷容量或PV装机。

### 节点负荷
这是规划级空间种子，不是逐配变实测P/Q。基准采用现场配变kVA权重；若电压或某支路成为瓶颈，必须再跑uniform-leaf空间敏感性。

### 开关设备
首轮规划使用导线Imax与SRC06馈线最大允许电流的较小值。若结果最终绑定到某个联络/分段开关，才定点核该开关铭牌；无需重新大范围收资。
