# real_2025 可审查可视化设计

## 目标

从最终 `results/runs/real-2025-contract-v2` 只读读取矩阵，在 `results/real_2025_visuals/` 生成一版可人工审查的静态图、长表和清单。图表用于解释推荐和不确定性，不替代精确矩阵。

## 输入与边界

- 输入只允许 `run_id=real-2025-contract-v2` 的 `county_110_matrix.csv` 和 `county_35_matrix.csv`；必须保留其 `manifest.json` 指纹。
- 110 kV 和 35 kV 分面绘制，不做跨电压等级容量、成本或 CLR 加总。
- C0/A/B 是方案状态和比较系列，不输出三张相互独立的主矩阵。
- `clr_official_reference` 与 `A_clr_after`/`B_clr_after` 使用固定的正向基准分母；区间图的区间只表示候选/经验情景不确定性，不是目标阈值。
- N-1 内部容量筛查和网络节点匹配不进入甲方推荐图。

## 甲方推荐主表（精确呈现层）

- 主表采用旧表 A 的转置式结构：第一列为指标名称，后续列为脱敏片区/高压分区；首个结果行固定为“当前推荐容载比 R_rec（成本最小可行方案）”。
- 后续指标行至少包括现状 R0、光伏渗透率、正向峰值、措施组合、A/B EAC、证据等级、可行性和质量备注。
- 110 kV 主表允许给出正式当前经济推荐；35 kV 主表必须保留“辅助/非唯一最优”语义。
- 旧合成 `R(2030)`、未来年份变量和未经过真实候选求解的填充值不得进入主表。
- 候选容载比档位扫描表如需输出，只能作为成本敏感性附件，不能替代主表。

## 图表契约

### 1. 容载比区间图（每个电压等级一张）

- 横轴：CLR；纵轴：脱敏县区 ID。
- 浅灰区间线：`candidate_clr_min` 到 `candidate_clr_max`。
- 黑色圆点：现状 `clr_official_reference`。
- 橙色菱形和蓝色方形：A/B 可行时的措施后 CLR；不可行时显示文字原因。
- 证据等级、是否可行和无法唯一优化用文字/线型同时表示，不依赖颜色单一区分。

### 2. 方案可行性与 EAC 图（每个电压等级一张）

- 以县区为行、C0/A/B 为列的状态网格；单元格同时保留状态文字。
- 旁侧显示 A/B 的等效年成本（EAC）；不可行时不绘制伪造数值。
- C0 成本固定为 0，但不合规状态不当作推荐。

### 3. 证据与数据问题图

- 统计 110/35 kV 各自的 A/B/C 证据等级与问题数量。
- 展示 QX-00005 时序审批门禁、35 kV 容量口径差异和缺失场景等影响，不将数据缺口伪装成可行措施。

## 交付与血缘

`results/real_2025_visuals/` 必须包含：

- 110/35 kV 转置式指标推荐主表（CSV/Markdown）；
- PNG 和 SVG 静态图；
- 图表使用的长表 CSV；
- `visual_manifest.json`，包含输入运行 ID、输入文件 SHA-256、图表契约、环境和输出文件 SHA-256；
- `README.md`，说明每张图的读法、单位、证据等级和不可行原因。

所有图表必须包含标题、单位/分母说明、数据日期、运行 ID 或来源指纹，并在输出后做文件存在性、字段和视觉检查。
