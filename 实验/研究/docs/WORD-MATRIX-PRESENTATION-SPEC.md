# v3 Word 矩阵成果展现规范

版本：3.1  
确定日期：2026-08-14  
适用范围：v3 真实运行生成的 110 kV 推荐矩阵、35 kV 辅助矩阵和技术附表。

详细实现设计：[v3 最终 Word 矩阵展示优化设计](superpowers/specs/2026-08-14-v3-word-final-presentation-design.md)。

## 1. 页面与表格

- 使用 A4 横向、深蓝色标题、浅色表头和适度窄边距；
- 主表使用固定行序、分组行、重复表头、页脚和状态底色；不生成图片或图表；
- 第一列为中文指标，后续列为脱敏片区；
- 110 kV 与 35 kV 分章节、分表、分开计算，不跨电压等级合计；
- 容载比、容量、负荷、光伏和成本按统一精度呈现，区间使用短横线「–」；
- 正式查值源为 CSV/Markdown，Word 只用于人工审查。

## 2. 正式路径显示

Word 中使用以下路径代码和中文名称：

| 路径代码 | 中文显示名称 |
| --- | --- |
| `PATH_ACTUAL_2021_2025` | 2021—2025 实际（事实对照） |
| `PATH_OPT_CLR_UNBOUNDED` | 不限制容载比优化 |
| `PATH_OPT_CLR_LE_2` | 控制容载比不超过 2.0 优化 |

历史 `SCHEME_C0`、`SCHEME_A`、`SCHEME_B` 不得进入 v3 正式表题、图题或主表单元格。`EVIDENCE_A/B/C` 只作为证据等级显示。

## 3. 主矩阵行序

主表至少包含以下指标行：

1. 推荐容载比区间及中心值；
2. 三条路径 2025 年容载比；
3. 三条路径累计年化成本；
4. 严格约束增量成本；
5. 公用变容量（MVA）；
6. 正向最大净负荷（MW）；
7. 反向峰值（MW）；
8. 正向容量缺口（MW）；
9. 反向承载缺口（MW）；
10. 正向缺口设备数；
11. 反向缺口设备数；
12. 措施触发约束；
13. 推荐措施；
14. 证据等级。

正式展示字段还包括推荐容载比中心值、推荐区间有效样本数、推荐区间形成方法、公用变容量、正向最大净负荷和反向峰值状态。容量和正向峰值只能来自已审批的同电压年度官方锚点；没有正式同步反向峰值时显示“未形成同步反向峰值”，不得用 0 或静态站级极值相加代替。

说明字段放在表前或表后；表格单元格不放机器字段、哈希、JSON、候选编号或长备注。不可行、未识别、未形成唯一推荐和数据缺口使用统一中文状态词。

展示层只对已验证矩阵做中文化、格式化和状态标识，不在 Word 生成阶段重新计算容载比、成本、缺口或推荐措施。实际路径“未识别”保留为“未识别（设备动作成本未闭合）”，严格路径不可行保留为“不可行”。

## 4. 技术附表

QX-00005 的三路径逐年轨迹、年度动作、年度 CAPEX、在役 EAC、累计 EAC、SOC/物理回放和内部容量网络压力检查放入技术附表。技术附表允许使用机器字段和候选编号，但必须保留血缘、质量标记、审批状态和输入 SHA-256。

不再生成五张正式年度 Word 矩阵。旧年度矩阵、旧 Word 和旧可视化必须归档并标注“旧契约、不得正式引用”。
