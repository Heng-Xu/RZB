## 阶段验证记录

### 旧合成基线

运行命令：

```bash
env MPLCONFIGDIR=/tmp/mplcfg_xuzhou conda run -n xuzhou110kv_clr bash scripts/runtests.sh
```

结果：收集 79 项，`79 passed in 95.05s`。该结果只证明旧合成脚手架可回归，不证明真实模型正确。

### 阶段 0 红灯

运行命令：

```bash
env MPLCONFIGDIR=/tmp/mplcfg_xuzhou conda run -n xuzhou110kv_clr bash scripts/runtests.sh \
  tests/test_model_contract.py tests/test_clr.py \
  tests/test_reverse_capacity.py tests/test_planner_contract.py -q
```

结果：20 项中 11 项通过、9 项按预期失败。失败均由旧业务行为或正式接口缺失引起。

### 阶段 1 至阶段 9 增量验证

已建立并通过下列测试组：

- 真实数据适配与源文件哈希守恒：`tests/test_real_data_adapter.py`；
