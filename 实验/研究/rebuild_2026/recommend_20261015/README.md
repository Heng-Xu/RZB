# 增容替代推荐方案

2026-10-15 用户授权按增容优先的取向给出合理结果。本目录为独立后继试算，保留正式报告和前两轮冻结资料。

`model.py`：同初始设备、年度负荷及逐站转供预算；正常转供比例按年固定，按送端正向净负荷缩放。该比例是聚合供区代理。正常不使用备用储能；事故仅允许与故障站直接相连的通道转接。正常及健康站反向80%，故障站按最大一台退出后剩余主变能力校核，储能沿用规定时长与可用能量约束。既有76条等效通道继承原地区标定，逐站能力再限制；不冒称真实开关拓扑已经核实。

分别计算刚性、费用目标的弹性经济参考和弹性增容替代。后者增加明确的规划选择条件：逐年主变≥刚性105%，储能≤刚性50%，累计新联络≤刚性，末年至少少2条。105%等数值为本次方案取向，不能作为承载力标准或自由寻优结论。原经济单价、设备寿命与评价期保持。保留费用下界、间隙、未通过工况的早期候选及分离过程。

`matrices.py`：复用第一轮5832节点原始库中的2916个重新选配节点，不改节点结果。与同节点存量组比较响应，固定支撑时间分别归纳27张矩阵，完整记录无响应与不可行结果。合并相邻节点须同时设备一致和费用一致。315 MVA为五站每站至少两台31.5 MVA的模型组合下限；电缆占比仍为价格映射，原始载流量核对不支持按电缆占比虚构输送增益。

运行入口（项目根目录，采用既有 xuzhou110kv_clr 环境）：

```text
python -m 实验.研究.rebuild_2026.recommend_20261015.model --case rigid --seconds 180
python -m 实验.研究.rebuild_2026.recommend_20261015.model --case elastic_free --seconds 240
python -m 实验.研究.rebuild_2026.recommend_20261015.model --case elastic_selected --seconds 240
python -m 实验.研究.rebuild_2026.recommend_20261015.export
python -m 实验.研究.rebuild_2026.recommend_20261015.matrices
python -m 实验.研究.rebuild_2026.recommend_20261015.verify --matrix-lp
python -m 实验.研究.rebuild_2026.recommend_20261015.memo
python -m 实验.研究.rebuild_2026.recommend_20261015.lock_review --write
```

独立复核包含原解变量与导出资产、选定约束的矩阵复算、所有同期正常及N−1工况的网络LP、补齐8760小时正常固定比例调度、费用复算、1808个矩阵区间端点的独立LP、工作簿与CSV逐格比对。正常时序不替换原年度规划负荷。结论不扩展至全年SOC、新能源利用率、上级反送接纳、电压及短路安全。
