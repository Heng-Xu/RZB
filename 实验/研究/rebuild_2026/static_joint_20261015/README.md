# 两区县静态联合替代方案

按用户最新要求，回到正常与N-1共同参与的静态替代框架，不新增SOC，不保留正常储能禁用、正常联络禁用或年度比例固定的运行限制。2021年固定，2022—2025优化。

## 方案设置

两地区为邳州、市区，各有共同仿真起点和保留2021原表地区容量起点，各起点分别比较刚性与弹性，共8组。起点设备、年度负荷、逐站J/(J+K)转供预算、候选网络及经济参数继承首轮冻结输入。原表总量对应2027、3113.5 MVA，逐站组合沿用已冻结标定，不重新拟合。

正常及N-1均允许储能有效功率和联络分配参与，保留线路/馈线共享限额、逐站既有转供预算、接收侧余量、正常反向80%及最大单台主变退出校核。邳州正向储能2h，市区6h，反向沿用各站原时长。

共同增加的建设组织条件为：同一主变位置在四年期内最多更换一次，新购设备继续在役。它处理首轮土山2022/2024连续采购替换的问题，是实施假设，不是新安全标准，也未修改40年寿命或费用参数。不同主变位置及第三台仍可分年建设。

刚性保留容载比2.0新增容量控制；弹性不受该容量上限。先以费用为目标生成弹性经济参考，再在该参考费用5%以内优先减少末年累计新联络，保留次选费用较低的可行布局。5%是工程优选容差；没有设置弹性容量高于刚性、储能低于刚性等跨方案排序约束。经济参考和实际增量费用均单列。工程优选不称为自由费用全局最优或已证全局最少联络。

旧版指定对照可作为MILP候选起点，但不继承其容量、储能和联络排序约束。所有采用布局均重新求解运行变量并逐工况校核。存量本已充足时允许两方案相同、零新增费用，不为制造差异增加设备。

## 运行与交付

```bash
python -m 实验.研究.rebuild_2026.static_joint_20261015.model --region pizhou --baseline compressed --case rigid --seconds 150
python -m 实验.研究.rebuild_2026.static_joint_20261015.model --region pizhou --baseline compressed --case elastic_free --certify
python -m 实验.研究.rebuild_2026.static_joint_20261015.choose --region pizhou --baseline compressed --seconds 150
python -m 实验.研究.rebuild_2026.static_joint_20261015.export
python -m pytest -q 实验/研究/rebuild_2026/static_joint_20261015/test_model.py
python -m 实验.研究.rebuild_2026.static_joint_20261015.verify --full-lp
python -m 实验.研究.rebuild_2026.static_joint_20261015.lock_review --write
```

其他组按对应region、baseline、case运行，已可行且满足一次采购条件的旧布局通过`--certify`重组运行变量及校核，沿用有效松弛费用下界；它不是从原表重新做2021年寻优。普通`verify`核对原解、资产、费用、功率收支和工作簿，`--full-lp`另重跑全部30336个工况。
