# 会后建模复核

本入口按2026年10月15日任务实施逐站转供、承载约束复核、保留2021原表地区容量的对照及转供完整序列分析。20261014初步定档和20261012锁定库保留，新计算写入独立目录。

## 案例

`cases.py`复用既有年度负荷、地区及各站局部极值同期截面、设备候选、具体馈线候选和现行经济参数。两地区、两种起点分别计算刚性与弹性自由寻优，并另算用户指定的替代对照。

逐站既有转供率按原表J/(J+K)计算，当年既有转出预算取`min(J, rho_i * 当年站级最大正向净负荷)`，并继续受通道、共用馈线和接收主变限制。原地区统一标定图的拓扑和线路热限保留，逐站资料没有证明的新路径不增加。该率的年度作用为研究情景，原表J作为固定物理能力上限。

反向80%筛查依据2025年4月修订稿第6.5.3条。DL/T 2041—2025第6.4条区分分列/单台、并列及具备秒级调控条件，本试算对正常方式及健康站采用正常反向80%，故障站按最大一台主变停运后的剩余容量不过载校核。80%不再乘到故障后剩余容量上。主变并列与故障后转接为模型运行假设。电压、短路、电能质量和上级电网系统级接纳边界需要相应资料，不能用本静态容量约束代替。

`compressed`保留报告共同压缩设备；`annual_2021`保留2021年原表地区总容量：邳州2027 MVA、市区3113.5 MVA。2021逐台资料不齐，逐站双主变组合按2025站级容量比例标定，三座市区模拟站保留其参考权重，输入文件冻结后各方案共用。此项是保留地区总量的规划对照，不能称为2021逐台实测设备复原。

`elastic_free`仅以费用为经济目标，容量由安全与设备约束确定。`elastic_target`明确加入用户指定的比较条件：弹性容量逐年至少比所参考刚性可行方案多0.5 MVA，在役储能及累计联络不多于刚性，末年刚性联络非零时至少少1条。0.5 MVA取候选容量组合的半兆伏安分辨率，用于表示严格大于；它是比较条件，不是供电安全准则。两种弹性结果分别保存，不将指定约束的结果称为自由寻优自然结论。

指定对照的MILP未充分收敛时，`target_warm.py`在自由解上枚举末年新线删减、局部主变升档和储能补缺，并用增容替代尚未采购的储能。固定布局后解运行LP、逐年复算费用，再用自由模型和同一指定问题已有的有效下界给出费用间隙。固定布局LP最优不等于整个规划问题全局最优；原求解状态、枚举过程和可行证书分开保存。

`*_reverse80`目录为补充80%条件后的当前试算。无该后缀目录保留逐站转供调整、反向100%边界的受控诊断。`certify_legacy`仅在输入的设备、网络及逐站预算相同时，逐工况复查较宽反向限值所得设备；通过后可保留其费用和有效松弛下界，原解来源及证书单列。

## 推广

`matrix.py`比较三种明确的费用和设备条件：

- `stock`：每站两台50 MVA为已有资产，原购置费用不再计入，只允许维持或升档，地区存量下限500 MVA。
- `stock_allcost`：保留同一500 MVA容量下限，全部主变计价，用于分离存量下限与投资计价的作用。
- `greenfield`：按现行新增设备序列31.5、50、63、80 MVA重新选配两台主变，全部采购计价；第三台50 MVA仍受位置条件限制。新增50 MVA成为最大单台时单独校核其停运，不能继续固定只移除第二台。五站双主变的设备组合下限为315 MVA。

`*_procurement.jsonl`为上述四档采购规格的本轮主结果。先前包含20、40 MVA新购选项的六档试算保留在`*_reverse80.jsonl`，只作扩展规格诊断，不用于主矩阵交付。

网络转供参数仍沿用原五站模板，按共同100 MVA/站参考设备标定，规划配置重新通过正常及各站N-1校核。转接只改变用电负荷归属，电源留在原站，区域净负荷守恒。存量改造费用与全部选配费用具有不同初始资产条件，不能将两模型总费用直接相减称为工程节省。

完整转供序列固定其余参数，10%至90%按10个百分点取点。复核设计覆盖装机0.5/1.5/2.5、增长0/4%/5.5%/8%、电缆10%/30%/50%、支撑2/4/6 h、分散1/1.10/1.15，合计每模型2916、两模型5832节点。两类源荷条件、设备选择和全部平台段均保留；9张新矩阵的432个单元只表示有限节点的包络，不宣称已重算原32112有效样本库。

较宽反向限值、较短支撑时长及较低局部峰值分散程度构成受控松弛。旧设备在当前全部工况经独立LP核验，且其可行费用与有效松弛下界满足精度时，可以复用证书；其他节点继续MILP寻优。正间隙保留。原始逐条记录和复用来源哈希均保存。
