# 当年需求驱动的逐年规划

2021地区总容量固定为市区3113.50MVA、邳州2027.00MVA。2022—2035分别以上年采用的在役设备、当年负荷和光伏求解，已投运设备承接至下一年。同一原主变位置全期最多更换一次。新购选择31.5、50、63、80MVA，允许位置的第三台按50MVA投运。年度容量不套2035规格下限、固定远景工程清单或建设进度包络。

两方案负荷及容载比下限相同。刚性容量上限为上年容量与当年峰值两倍的较大值，弹性取消该上限。主表弹性沿用上一轮配套费用优先：先减少本年新增储能与联络费用，在该候选配套费用20%范围内优先减少联络，再比较总费用；采购规格按当年需求选择。另保留总费用5%容差的弹性经济对照。逐年保存可行方案、分阶段参考、条件下界和间隙，不施加刚弹排序约束。

46座有Excel对应的站点保留原表J列既有转供MW上限，三个模拟站按零。该上限各年固定，正常校准供区与故障追加共同占用，逐路径、馈线及受端主变同时校核。新增路径另受20%源荷区段研究限额。EQ聚合端口组数按能力与基期区段峰值估计，路径并非已核实的实际竣工拓扑。2025收资用于早期回算，早期逐线投运资料缺失。

历史2021—2024按全市光伏装机相对2025比例回算，负荷比例保持各年区域正向统计峰值。2025逐点还原，未来输入沿用既有预测。2021供区校准不增设设备；邳州N1缺口保留，2022起实施补强。历史为源荷模板回算，保留补值标识。

2021校准的少量既有正常转供区段可回切原属站，其上限保持校准值；回切后由原属站设备承担对应源荷。年度正常方式与故障预案各自全年固定。先前将校准区段锁定到全期的试算在市区2033因受端余量收紧而不可行，原始记录保留于试算的“未采用”子目录。
