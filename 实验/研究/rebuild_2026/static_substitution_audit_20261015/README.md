
默认输出到 `研究报告/05_review/当前版/1015静态替代机制检查/静态替代机制核验.json`。可通过第一个位置参数指定独立核验目录。

核验内容包括：

- 确认首轮与最新邳州原表起点组的设备、网络、年度负荷、逐站预算和费用输入相同。
- 固定首轮刚性可行解，仅改变正常储能可用性、事故仅直接相连通道两项运行设置，复核四组各2184个正常/N-1工况。该对照放宽了最新模型的年度固定比例转供，失败仍可作为最新模型的不可行证据。
- 通过通道置零的正向、反向各5 MW缺口试验，检查正常储能在首轮与最新运行LP中的实际作用。
- 独立LP复核报告原库9个、10月15日存量与重新选配库18个转供节点，覆盖完整10%—90%序列，不只取区间端点。
- 提取转供率标定同时改变的通道、馈线热限、接收余量和逐站转出预算，保留模型和原解SHA256。

检查结论位于 `研究报告/05_review/当前版/1015静态替代机制检查/建模机制检查结论.md`。旧解回放是静态可行性证据，不能替代后续统一模型下的经济比选。
