# 四年更换间隔与年度总费用方案

本轮依据用户同意的讨论结论重算两地区2021—2035年方案。2021容量保持市区3113.50 MVA、邳州2027.00 MVA，2022—2035只使用当年源荷、同口径年度规划峰值及上年在役设备。主变、储能和付费联络逐年承接。

原四年算例的“一次更换”改为任意连续四个规划年度内同一原主变位置最多更换一次，即相邻更换年份之差至少为4。该间隔为研究工程实施假设，基期更换年份缺失，模型从2022年登记。刚性、弹性共同采用，避免比较混用边界。新购31.5、50、63、80 MVA，原允许扩建站的第三台仍为50 MVA。

逐行回到原设备明细核对后，46座有对应站点中9座预留扩建容量超过50 MVA（63 MVA五座、80 MVA一座、100 MVA三座，均为1个预留位置）。现有扩建工程造价实例仅有50 MVA项目，本轮沿用可计价的50 MVA第三台。输入中“暂无扩大规格的工程证据”指完整可计价工程候选资料，不表示设备表没有更大预留容量。超过50 MVA第三台的工程费用仍待补充，当前不可行性结论只对本轮候选集成立，不是全部现实扩建空间的结论。原表逐行核对及造价依据保存在来源目录。

两种方案均按当年新增主变、储能和联络的全部费用现值直接寻优，取消前版弹性配套费用20%容差及少建联络优先步骤。刚性保留新增容量2.0控制，弹性取消该控制，两个方案共同的容载比下限保持。未人为规定刚弹容量、储能、联络或费用的排序。

源荷、原表既有转供MW预算、固定年度预案、共享路径、源馈线组及受端限制、锁定价格和经济参数均沿用已核验前版。`prepare.py`以路径和哈希引用前版时序文件，不重复复制8760小时原库。2025转供收资用于早期回算、EQ拓扑及源荷区段仍为研究代理。邳州2021固定设备的事故缺口单列，未添加基期虚拟储能。储能为静态时长支撑，无连续SOC优化。

复现入口（项目指定Python环境，数值计算建议设置`OPENBLAS_NUM_THREADS=1`）：

```text
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.prepare
python -m pytest -p no:cacheprovider -q 实验/研究/rebuild_2026/annual_cost_interval_2035_20261017/test_model.py
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.run --region city --case rigid --seconds 20 --refine-seconds 120
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.run --region city --case elastic --seconds 20 --refine-seconds 120
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.run --region pizhou --case rigid --seconds 12
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.run --region pizhou --case elastic --seconds 12
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.verify
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.probe
python -m 实验.研究.rebuild_2026.annual_cost_interval_2035_20261017.export
```

`run.py`保存完整整数向量、历次条件下界、间隙、上年资产哈希及最近更换年份。`verify.py`重新装配全部整数约束，以固定供区矩阵核对8760小时，再独立计算采购差量、维护、折现及更换间隔。年度下界只对应该年度既定上年资产，不是全期联合最优下界。

市区2022—2030先采用12秒初搜/30秒加强预算，2031起以20秒初搜/120秒加强预算连续重算；初次市区候选另行归档。继续运行会按上年资产哈希复用已完成年度，不拼接不匹配的后续结果。强化搜索主要针对条件费用间隙较大年度。

每个地区及方案持有独立进程锁，拒绝并发写入。对已有接线资源可行但存在逐时供需缺口的候选，`repair.py`按固定预案计算各站需要的最小储能柜数，形成经全部约束及全年校核的可行热启动。补足量仅作求解候选，不加为后续搜索下界；最后仍按完整工程费用比较和逐年承接。

`probe.py`对2031—2035年分别检验停止新增储能的能力：固定上年储能，主变取四年间隔允许的最大规格，分别固定已有联络和开放全部候选联络。可行候选再核对全年；仅当求解器证明不可行时记为不可行。此为单年反事实检验，极限配置不作经济方案，不能拼成一条连续无新增储能链。

当前输出采用既有标准目录：原始解在`研究报告/试算/20261017_四年间隔总费用2035`，对照表在`研究报告/01研究推荐/当前版/四年间隔总费用2035_20261017`，来源与核验分别在相应当前版目录。本轮不替换正式六章源稿和冻结采用案例。
