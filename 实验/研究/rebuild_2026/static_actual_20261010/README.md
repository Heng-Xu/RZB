# 实际年度负荷下的两地静态试算

本轮遵循用户最新确认：原容载比表的年度容量、负荷是核心数据；保留最新共同仿真起点；不再使用增长率替代已有年度负荷。研究采用静态分析，不补充逐时数据、不开展SOC仿真。此前要求“严格依据原有数据”已明确为核心统计取源表，缺失工程参数可作有标注的假设。

市区起点2900 MVA，邳州1463.5 MVA，均保持原仿真设置。原表实际容量作为历史对照，不自动叠加进优化容量，也不冒称上述仿真资产是历史实际存量。

刚性方案采用 `C_y <= max(C_(y-1), 2 P_y)`，且容量非减。该条件用二进制析取准确表达：当年不扩容，或扩容后仍不超过当年实际负荷的2倍。超限仅能来自已建容量的保留，不能把历史负荷峰值当作以后继续扩容的额度。弹性下限2.001及原物理设备上界保持，费用仍为唯一主目标，不强制费用和地区排序。

用户进一步确认：市区容载比小于邳州不作为强制条件。两地大小关系仅作结果观察，不作为方案定稿阻碍，不为匹配排序追加容量。

两地都采用邳州最新的网络结构：先确定候选边，投运前不可用，馈线转出/接收余量共享、源站不能重复转出接收负荷，健康邻站受主变容量限制，单站最大一台主变N-1；既有馈线互联和邻站新出线分开计数，后者占用接收站备用间隔。

邳州保留原280条边（T01存量、279条付费候选）。市区使用同上级电源作为候选筛选假设（不是10kV连通证据），生成604条付费候选。根据已用间隔数等分静态站峰值负荷，以原7.49106117 MW新线容量作为缺失馈线热限的参考值，最多保留四组既有馈线配对及每个方向两组新出线。所有长度仍为原3 km研究假设。三座缺少设备行的模拟站暂无网络候选和新增间隔，不代表事实不存在。市区40%仅保留为原参数记录，不再形成无明确路径的免费全区转供；本次市区因此是已列假设下的保守网络试算，仍需候选及存量网络敏感性复核。

仅使用已归档的两个区县静态工况表：正向峰值和最低净负荷（邳州为反向峰值），按原表各年降压峰值标定。反向工况同倍率为沿用净负荷结构的研究假设，不是该年实测反送最大值，不额外引入新能源增长率。两地储能均按原持续时间及0.76可用电量系数折算有效功率；市区沿用6 h、邳州2 h正向持续时间。静态工况不覆盖各站局部极值或全年运行；本次较旧结果的费用变化同时受实际年度负荷、静态工况简化、市区网络约束同步影响，不能仅归因于负荷更正。

完整结果与逐项假设见 `研究报告/试算/20261010_实际年度负荷静态试算`。求解保存可行解、费用下界、最优间隙；达到时限的候选不称精确最优。允许储能组包含无储能组，必要时用已核查的更便宜零储能候选更新允许储能组，以避免将搜索误差误判成储能价值。2026年10月10日按用户授权将旧过程移入校验备份，当前输入已冻结，正式报告未修改。
