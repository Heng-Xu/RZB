# 固定区段转供的两地区逐年规划

本入口独立计算市区、邳州2021—2035方案，不覆盖20261015正式报告采用结果。2021地区总容量分别固定3113.50、2027.00 MVA，逐站设备沿用归档标定组合；2022—2035按年承接投运资产。

`prepare.py`直接读取用户预测Markdown。未来负荷、光伏分别取相对2025倍数，缺年等增量插值；光伏单位在比例中消去。规划峰值保留110kV统计口径。历史净负荷模板与逐年统计峰值保持。源荷代理、缺测标识、原始文件SHA256留在独立来源目录。

`model.py`只复用原投资变量和费用，不生成旧自由转供工况。可切换对象为同站等比例源荷块，全期同一数量和形状，负荷与光伏共同移动。区段没有完整真实线路对应，属于明示规划代理。统一2MW设计上界、每代理端口组最多5段、最多3个受端馈线和2座邻站为保守研究设置；不是将架空线路条款直接宣布适用于全部电缆。

正常方式仅新增付费项目可调整供区，既有统计能力仅用于事故。事故保留正常接线，只追加切换故障站原属区段，正常接线及每站事故预案均在全年固定。每个源荷块只有一个供电来源；源端、路径热限、共享受端馈线余量、既有逐站J列能力及主变余量同时约束。

`run.py`固定上年实际采用资产，决定当年新增；同一主变位置全期最多更换一次。刚性与弹性使用完全相同下限与安全条件，刚性保留2.0新增容量控制，弹性取消该控制。采用方案为`rigid`和`elastic_reserve`，`elastic_balanced`保留配套设施工程优选过程。弹性每年在自身费用参考5%以内，要求储能和联络均不超过该费用参考，等权压低两项相对规模。费用参考储能为零时用2.15MWh归一基数。随后由`reserve.py`在同一年度费用包络内提高当年已经采购位置的额定容量并在后续年份保留；同容量增量优先提高N-1剩余容量。容量优选采用整规格多重选择背包。追加容量后的费用基准用原参考布局在新既有设备上复核，不重新称为费用最优，规划下界登记为零。没有施加刚弹结果排序约束。`elastic_engineering`为仅优先少建联络的对照搜索，保留在原始资料，不作为推荐逐年方案。

这是年度滚动可行方案，费用参考不等于全期联合全局最优。原始整数解、费用下界和间隙、工程优选目标及年度参考分别保存。2021固定起点不通过修改容量或新增设施补齐，其零切换缺口单列；2022年起的所有采用布局需通过全年独立校核。

`verify.py`逐年从NPZ原始解重建主模型矩阵、整数和资产连续性，再独立重建供区矩阵检查补齐后8760小时的正常及各站最大主变故障。储能采用静态有效功率和规定时长口径，未引入SOC运行。`stress.py`保存2035固定设备/预案对负荷或光伏增加5%的承载压力检查，不将压力条件称为重新规划结果。
