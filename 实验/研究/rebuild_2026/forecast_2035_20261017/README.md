# 市区实际容量起点接续至2035年

独立试算，原20261015静态联合替代成果及正式报告保持原文件。2025年末两方案均为3113.50 MVA，零储能、零累计新增联络；逐站设备继承冻结配置。计算2026—2035每年的主变更换、第三台投运、储能柜数和联络投运，年间继承资产，并逐年校核正常及最大单台主变退出工况。同一主变位置在本次前推期最多更换一次。

输入直接读取用户的《负荷和光伏装机预测.md》。保留已有年度节点，只对缺年按相邻节点等增量插值，再计算同比和相对2025年的倍率。市区总负荷倍率作用于原110 kV研究范围，徐州市光伏装机倍率作用于市区光伏代理。2025年源荷分量利用已归档night_central负荷代理重构，逐点恢复原净负荷；定义、夜间原有反向分量的处理及缺口登记在来源目录。

模型逐年约束与冻结入口`static_joint_20261015.model.build`相同。采用`rolling.py`逐年固定上年资产，求当年新增，并在完整十年模型中固定设备复核。刚性使用2.0新增容量控制及1.60分档下限，弹性取消容载比上下限。两组无容量、储能或联络排序要求。本次快速交付为弹性经济参考；未再进行5%费用容差内简化联络的第二次工程优选。
