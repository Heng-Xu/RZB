### 2.1 三阶段实验路径

```

    └─ AHP权重定值
    └─ 等百分位分档
    └─ 27格决策矩阵填值（6-9格已验证）
    └─ 权重±20%扰动测试
```

### 2.2 实验变量定义

#### 2.2.1 输入变量（三维分类轴）

| 变量 | 取值范围 | 分档 | 数据来源 |
|------|--------|------|---------|
| 源荷比 ρ | [0, 3.0] | 低[0,1] / 中(1,2] / 高(2,3] | 2025导则定义 |
| 电量渗透率 η | [0%, 80%] | 低[0,30%] / 中(30,50%] / 高(50,80%] | 2025导则定义 |
| 联络度 CD | [0, 1] | 弱[0,0.3] / 中(0.3,0.6] / 强(0.6,1.0] | 肖峻2015 |

→ 3×3×3 = **27格**决策矩阵。

#### 2.2.2 决策变量（每格输出）

| 变量 | 含义 |
|------|------|
| R̂ | 推荐容载比区间 [R_low, R_high] |
| TS | 推荐技术方案组合（增容/配储/联络加强的组合权重） |
| LCC_A | 方案A(刚性≤2.0+配储)的年费用 |
| LCC_B | 方案B(弹性放宽+增容)的年费用 |
| ΔLCC | (LCC_A - LCC_B) / LCC_A |
| RobustFlag | AHP权重扰动下结论稳健性标志 |

#### 2.2.3 约束

- N-1校验通过
- 反向重过载校验通过（2025导则）
- 主变正常负载率上下限
- 电压合格率 ≥ 99.5%

### 2.3 双向Z4数学表达式

**传统Z4（单向）**：

```
Z4_single = T × Σ_i ( P_i² × R_i ) × t_loss
```

其中 P_i 为支路潮流，R_i 为支路电阻，t_loss 为年最大损耗利用时间。

**本文双向Z4**：

```
Z4_bidirectional = T × Σ_i [ α_fwd × P_fwd,i² × R_i × t_fwd + α_rev × P_rev,i² × R_i × t_rev ]
```

其中：
- α_fwd, α_rev：正/反向损耗加权系数（默认α_fwd=1，α_rev=1.2考虑反向时变压器空载损耗占比上升）
- P_fwd,i, P_rev,i：分场景平均潮流
- t_fwd, t_rev：年正向/反向运行小时数（基于PVGIS光伏出力曲线与负荷曲线叠加生成）

→ 这是论文**核心创新公式**。

### 2.4 等百分位分档算法

对每个变量X（源荷比/渗透率/联络度）：

1. 收集所有片区的X值
2. 计算33%、67%百分位
3. 分档：低 < P33 ≤ 中 < P67 ≤ 高

→ 不固定阈值，由实际数据自动校准。

## 3. 数据集设计

### 3.1 IEEE 33-bus 基础算例

| 参数 | 值 |
|------|---|
| 节点数 | 33 |
| 支路数 | 32（径向） |
| 基准电压 | 12.66 kV |
| 总负荷 | 3715 kW + 2300 kVAr |
| 数据源 | Baran & Wu, 1989, *IEEE Trans. on Power Delivery*, 4(2):1401-1407 |
| 文件 | `datasets/ieee33/ieee33_bus.csv`, `ieee33_branch.csv` |

**实验配置**：
- 视为某110kV变电站下属10kV配电网
- 主变容量假设：50 MVA × 2 台主变 = 100 MVA
- 容载比基线 = 100 MVA / 3.715 MW ≈ 26.9（仅topology作框架，需要重新标定负荷）
- **真实场景**：把 3715 kW 视为某变电站10kV侧的"特征片区"，作为决策矩阵单点验证

### 3.2 PV出力曲线（PVGIS API）

| 参数 | 值 |
|------|---|
| 地点 | 徐州（34.27°N, 117.18°E）+ 嘉兴+莱芜 三个代表点 |
| 时间分辨率 | 1小时 |
| 时段 | TMY（典型气象年） |
| 倾角 | 30°（按本地最佳） |
| 数据源 | PVGIS API (https://re.jrc.ec.europa.eu/api/v5_2/seriescalc) |

### 3.3 负荷曲线

| 参数 | 值 |
|------|---|
| 类型 | 综合性负荷（含工业、商业、居民） |
| 时间分辨率 | 1小时 |
| 数据源 | 中国典型城市负荷曲线（02报告中已含） + Elia/CAISO开放数据作对照 |

### 3.4 成本参数（baseline_costs.yaml）

详见 `datasets/cost_params/baseline_costs.yaml`，包含：
- Z1: 110kV变电站建造成本（按容量分档）
- Z2: 10kV线路单位长度造价
- Z3: 年运维率
- Z4: 双向损耗参数
- Z5: 残值率
- 折现率：基线6%，敏感性4%-8%
- 储能造价：CNESA白皮书摘要

### 3.5 中国实际片区案例

| 片区 | 数据源 | 容量 | 渗透率 |
|------|------|------|--------|
| 山东莱芜 | `课题前期资料/02_2024灵活性资源报告.md` 表3.x | ~80MVA | 高 (>60%) |
| 山东聊城 | 同上 | ~120MVA | 中 (30-50%) |
| 浙江嘉兴 | 浙江省案例集2023 | ~100MVA | 高 |

## 6. 评估指标

### 6.1 模型验证指标
- Z4双向公式数值连续性：α_rev=1时退化到传统Z4，差异<0.1%
- 潮流求解收敛性：所有场景100%收敛
- 决策矩阵格子稳健率：≥80%格在±20%权重扰动下结论不变

### 6.2 论文实验结果指标
- ΔLCC在三维空间的分布：要呈现"方案B在中高渗透率显著占优"的趋势
- 推荐容载比区间宽度：应随渗透率上升而扩大（弹性增加）
- 一片一策表覆盖度：≥6格基于真实数据、≥10格基于规则推断
