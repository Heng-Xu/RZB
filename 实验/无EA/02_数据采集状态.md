## 三、当前可直接运行的实验

### 3.1 已经可以跑

```bash
cd 实验

# 1. IEEE 33-bus 拓扑摘要
python scripts/ieee33_loader.py --validate --rebase 20

# 2. 单场景 LCC 计算
python scripts/lcc_simulator.py --case ieee33 --scenario elastic \
    --tx 20 --pv 2500

# 3. 方案A vs B 完整对比
python scripts/lcc_simulator.py --compare --case ieee33 --pv 2500

# 4. 不同PV装机扫描（建议手动循环）
for pv in 500 1000 2000 3000 4000; do
    python scripts/lcc_simulator.py --compare --case ieee33 --pv $pv --json
done > results/sweep_pv.json
```

### 3.2 验证结果速览（2026-06-12 baseline）

| 项 | 方案A（刚性+配储） | 方案B（弹性+增容） | ΔLCC | 优选 |
|----|--------------|--------------|------|------|
| 容载比 | 2.0 | 2.3 | — | — |
| 总投资（万元） | 12175 | 11547 | -628 | B |
| 年化总成本（万元/年） | 1241.24 | 1172.21 | -69.03 | **B(弹性)** |
| Z4反向占比 | 5.24% | 5.24% | — | — |

→ **Z4 反向占比 5.24%** 是本次仿真在 PV=2500 kWp 工况下的结果。在 PV 提高到 4000 kWp 时占比预期可达 15-25%，与论文创新点立论相符。
