# IEEE 33-bus 配电系统数据

## 数据来源

Baran, M. E., & Wu, F. F. (1989). Network reconfiguration in distribution systems for loss reduction and load balancing. *IEEE Transactions on Power Delivery*, 4(2), 1401-1407.

## 系统参数

| 参数 | 值 |
|------|---|
| 节点数 | 33 |
| 支路数 | 32（径向拓扑） |
| 基准电压 | 12.66 kV |
| 基准容量 | 10 MVA |
| 总有功负荷 | 3715 kW |
| 总无功负荷 | 2300 kVAr |
| 总视在功率 | ≈4.37 MVA |

## 文件结构

### `ieee33_bus.csv`
| 字段 | 含义 | 单位 |
|------|------|------|
| bus | 节点编号 | 1-33 |
| p_load_kw | 有功负荷 | kW |
| q_load_kvar | 无功负荷 | kVAr |
| bus_type | 节点类型 | slack/pq |

### `ieee33_branch.csv`
| 字段 | 含义 | 单位 |
|------|------|------|
| from_bus | 起始节点 | 1-33 |
| to_bus | 终止节点 | 1-33 |
| r_ohm | 电阻 | Ω |
| x_ohm | 电抗 | Ω |
| length_km_est | 线路长度估计 | km（按典型截面0.33Ω/km推算） |

> 长度为估计值，用于 Z2 线路造价计算。如MATPOWER数据无明确长度信息，按电阻/单位电阻反推。

## 本课题使用方式

将该系统视为某110kV变电站下属的10kV配电网（一个"片区"），用于：

1. **决策矩阵的"中渗透率/中联络度/中源荷比"格的单点验证**
2. **PV节点注入**：选定6-12个节点（约30%-50%节点比例）加PV
3. **反向潮流场景生成**：午间小负荷+PV满发→部分支路反向
4. **Z4双向损耗计算**：分场景累加正反向损耗
5. **方案A/B对比**：方案A加储能于关键节点；方案B无储但提高主变容量

## 容载比换算

原系统主变容量未明示。本课题假设：
- 主变容量 = 10 MVA × 2台（典型10kV变电站）= 20 MVA → 容载比≈4.6（偏高，可作"高容载比"工况）
- 或主变 = 5 MVA × 2台 = 10 MVA → 容载比≈2.3（接近"刚性约束临界"）
- 或主变 = 3 MVA × 2台 = 6 MVA → 容载比≈1.4（偏紧，"扩容压力"工况）

→ 三个工况组合可用于本课题"刚性 vs 弹性"对比实验。

## 加入PV的节点选择（建议）

| 渗透率档 | PV节点 | 总PV容量 |
|---------|-------|---------|
| 低（<30%电量） | 24, 25 | 约1 MWp |
| 中（30-50%） | 24, 25, 30, 32 | 约2.5 MWp |
| 高（50-80%） | 18, 22, 24, 25, 30, 32 | 约4 MWp |

→ 通过调整PV容量产生不同渗透率档位，配合不同主变容量假设填决策矩阵。
