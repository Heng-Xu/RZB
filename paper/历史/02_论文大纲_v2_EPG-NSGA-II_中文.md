## 摘要 Abstract〔单段，约 150 字，一段到底〕

- **首句**：高渗透分布式光伏正把县级 110 kV 变电站变成双向潮流枢纽，而现行"全县统一（刚性）容载比"规划口径在各站源荷差异大时普遍过投资。
- 〔中段①〕本文把**容载比弹性**建成"县总年化成本 ↔ N-1 缺供风险（EENS）"的双目标优化问题，决策量为每站容载比与储能功率。
- 〔中段②〕并提出 **EPG-NSGA-II** 求解：在最影响可行性的两个搜索环节注入电网工程先验，即**可行性保持热启动采样**（可行初始化）与**约束次序修复投影**（把不可行子代闭式投影回可行流形）。
- **末句（量化结论，双重优势）**：在公开数据合成的县级基准上，EPG-NSGA-II 在**各规模**都以约 **5–12× 更少的代数**达到基线的收敛质量；且**相对基线的质量优势随规模单调增大——问题越大、可行域越窄，EPG 收敛到越优的前沿**，到最大规模 K=40 以一半预算（gen400）反超跑满预算（gen800）的 NSGA-II 前沿 **+4.8% 超体积**（三种子皆胜）。其一站一策弹性配置相对刚性 2.0 在同风险下**节省 13.1%**。
- 〔关键词 Index Terms：容载比；分布式新能源；多目标进化优化；约束处理；NSGA-II。〕

## I. 引言 INTRODUCTION〔Motivation 链 4 段 + contributions 段〕

**P1（背景+应用 → 缺陷①：非弹性容载比）**
- 首句：高渗透分布式光伏使县级 110 kV 变电站呈现显著双向潮流，传统"全县统一容载比"（如取 2.0 的单一值）已难以作为合理的规划代理指标。
- 〔展开：统一 2.0 忽视各站源荷比、联络度差异——高源荷比站反送欠约束、低源荷比站过投资；应改用**空间差异化（弹性）**的逐站容载比。〕

**P2（现有方法缺陷 → 缺陷②：优化计算，无法高效利用工程先验）**
- 首句：逐站配置天然适合多目标进化算法，但通用 NSGA-II / NSGA-III 会把大部分预算耗在电网工程约束划出的**狭窄、不可分**可行域之外，且无法利用规划人员已掌握的工程先验。
- 〔展开：可行域窄且不可分（县聚合容载比带把全站耦合起来）+ 评价昂贵（确定性 Z4-LCC 每次约 3.8 ms）→ 随机初始化与盲目变异大量产出不可行解、收敛慢。这是"计算效率/先验利用"问题，不是建模问题。**规模越大、可行域越窄，这种浪费越严重**——为大规模下工程先验更大的红利埋下伏笔。〕

**P3（针对性改进 → 所提方法）**
- 首句：不可行几乎都产生于两个环节：种群**初始化**与子代**约束处理**。本文正是在这两处注入工程先验，得到 **EPG-NSGA-II**。
- 〔展开：环节① 用工程先验直接构造可行初始种群（热启动）；环节② 把不可行子代按约束耦合次序闭式投影回可行流形（修复投影）；两者都是"把领域可行性知识写进算子"。〕

**P4（三条贡献 Main contributions，列点）**
- 首句：本文有三点贡献。
- **贡献1（方法框架）**：提出 EPG-NSGA-II，将两个工程先验算子——**可行性保持热启动采样**与**约束次序修复投影**——嵌入 NSGA-II，且两算子内部**从不调用（昂贵的）目标函数**。
- **贡献2（重点环节改进）**：设计**约束次序修复投影**，它单次前向、闭式，按约束**耦合强弱次序**修复（县容载比带 → 逐站反送闸 → 上级系统 → 带下限回补），并令**执行变量（储能）先于结构变量（容载比）**调整。
- **贡献3（建模 + 实验验证：效率 + 大规模质量）**：构建公开数据县级基准，证明 EPG-NSGA-II 在各规模都以约 **5–12× 更少代数**达到基线收敛质量，且在**最大规模 K=40 以一半预算反超基线的收敛前沿（+4.8% vs NSGA-II，三种子皆胜）**——印证"问题越大、工程先验红利越大"；并用逐组件消融归因（修复=主驱动、热启动=早期加速器）。

## II. 所提方法 THE PROPOSED EPG-NSGA-II

### II-A. 弹性容载比优化模型 Elastic Capacity-Load-Ratio Optimization Model

**P1（弹性容载比定义）**
- 首句：本文将**容载比弹性**定义为"给每座变电站分配各自的容载比 Rⱼ，而非全县统一常数"，使容量随本地净负荷与反送条件而异。

**P2（决策向量+边界）**
- 首句：决策向量联合优化逐站容载比与储能，x = [R₁…R_K, P₁…P_K]，其中 Rⱼ∈[1.2, 3.0]、储能功率 Pⱼ∈[0, 6] MW（储能容量 Eⱼ=2h×Pⱼ 为从属量）。
- 〔映射进现有 `ScenarioConfig`，不改评价 simulator。〕

**P3（两目标，min）**
- 首句：优化在两个相互冲突的目标间折中：最小化县总年化成本，同时压低 N-1 供电风险。
- 〔式(1)〕 **f₁** = Σⱼ（资本年金 + **双向 Z4 网损** + 储能 + 运维）[万元/年]。
- 〔式(2)〕 **f₂** = Σⱼ N-1 期望缺供电量 EENS [MWh/年]，负荷取未来峰荷 peakⱼ·(1+g)ⁿ（g=5%、n=5）。

**P4（三条工程约束 → 窄且不可分的可行域）**
- 首句：三条工程约束共同划出一个狭窄、不可分的可行域。
- 〔式(3)〕 ① **逐站反送硬闸**：rev_upⱼ ≤ β·Rⱼ·peakⱼ，β=0.85。
- 〔式(4)〕 ② **县聚合容载比带（核心耦合）**：aggR = Σⱼ(Rⱼ·peakⱼ)/(δ·Σⱼpeakⱼ) ∈ [1.8, 2.2]，同时率 δ=0.85——把全站耦合，使问题不可分。
- 〔式(5)〕 ③ **上级系统潮流限额**：Σⱼ rev_upⱼ·η ≤ β·R₂₂₀·δ·Σⱼpeakⱼ，R₂₂₀=1.8，反送同时率 η=1.0。

### II-B. 工程先验引导的搜索 Engineering-Prior-Guided Search

**P1（总述 + 指向 Algorithm 1）**
- 首句：EPG-NSGA-II 保留 NSGA-II 主干，仅把随机初始化与盲目约束处理替换为两个工程先验算子，整体流程见 Algorithm 1。

**P2（组件① 热启动 = 早期加速器）**
- 首句：**可行性保持热启动采样**由工程约束直接构造逐站**最小成本可行解**为初始种群播种，使搜索从可行流形上起步，而非靠随机初始化偶然进入可行域。
- 〔定位：*早期加速器*——让初始种群即近可行、显著加快早期收敛；其单独优势在充分收敛后被洗掉（见 §III-B 消融）。〕

**P3（组件② 修复投影 = 主驱动）**
- 首句：**约束次序修复投影**把每个不可行子代在一次前向传播中投影回可行流形，**按约束耦合次序修复、且全程不评价 f₁/f₂**。
- 〔五步有序投影（来自 §II-A 三约束，次序不可乱）：〕
  1. 夹取 R∈[1.2,3.0]、P∈[0,6]；
  2. **先修带（全局耦合）**：按 band_lo/aggR 或 band_hi/aggR 整体等比缩放 R；
  3. **逐站反送闸（执行变量优先）**：先升储能 Pⱼ 吸收反送；仅当储能触顶才升 Rⱼ；
  4. **上级系统（聚合、只动储能）**：对反送最大的站贪心加储，直到 Σrev_up·η ≤ 限额 L；
  5. **带下限回补**：若第 3 步升 R 触顶被裁致 aggR 低于下限，把缺额均摊到未触顶的 Rⱼ。
- 〔关键设计（写进贡献2）：执行变量 P 先于结构变量 R；全程闭式、不调 compute；约束按耦合强弱排序，保证后一步不破坏前一步。〕

**P4（选择压力）**
- 首句：两个算子都使种群保持近可行，选择阶段只需施加约束支配（可行性优先）压力，搜索因而集中在"成本↔风险"折中上。

**Algorithm 1（伪代码，方法节起始，卡在 II-B）**
- 中文题注：`Algorithm 1：EPG-NSGA-II 主流程。`（英文题注扩写时给）
```
输入：K 站的县构成、容载比带[1.8,2.2]、R₂₂₀、种群 pop=100、代数 gen
输出：Pareto 前沿 F 及其拐点处的一站一策
1  P ← 可行性保持热启动采样(stations, band, R₂₂₀)        // 工程先验初始化
2  用确定性 Z4-LCC 评价 P 的 (f₁,f₂)
3  for t = 1 … gen:
4      Q ← 交叉+变异(P)
5      Q ← 约束次序修复投影(Q)                          // 五步闭式，不评价目标
6      评价 Q 的 (f₁,f₂)
7      P ← 环境选择(P ∪ Q)：非支配排序 + 可行性优先 + 拥挤度
8  返回 P 的非支配前沿 F 及其拐点解
```

## III. 实验研究 EXPERIMENTAL STUDY〔K=20 主算例；Fig.1 讲"解好不好"，Table I 讲"算得快不快+归因"，互补不同质〕

### III-A. 实验设置 Setup
- 首句：实验用一套**公开数据合成的县级基准**：由缩放 IEEE 33 节点馈线与 PVGIS（徐州/嘉兴/莱芜）辐照合成，随机种子固定以保证可复现。
- 〔口径：pop=100（固定）、K∈{10,20,30,40}、每配置 3 seeds、每个 K 用全变体末代前沿的**共同 HV 参考点**；因 pop 固定，**代数 gen ∝ 评价次数 NFE=pop×gen ∝ 墙钟**，故"更少代数=等比更少评价=公平"；基线跑 gen800、EPG 类跑 gen400。〕

### III-B. 算法效率、随规模递增的质量优势与消融 Efficiency, Scale-Growing Quality Advantage, and Ablation〔Table I〕
- **P1（效率，各规模）**：EPG-NSGA-II 在所有规模都以 **4.8–11.8× 更少的代数**达到 NSGA-II 与 NSGA-III 跑满 800 代的收敛超体积；等价地，只用一半预算（gen400）即已胜过两条基线的 gen800。
- **P2（规模越大越优越——质量优势随规模单调增大）**：工程先验的红利随规模单调增大——**收敛超体积比随 K 递增**（vs NSGA-II 1.007→1.007→1.009→**1.048**、vs NSGA-III 1.009→1.016→1.030→**1.064**，K=10/20/30/40）：小规模近似**打平**（K≤20 对公平基线 NSGA-II 仅约 0.7%，与 Minkowski 真前沿验证一致——经典 EA 本就能收敛到真前沿）；随问题增大、可行域越窄越难，差距越拉越大，到 **K=40 达 +4.8%（vs NSGA-II，三种子 +4.4/+4.5/+5.5% 全胜）/ +6.4%（vs NSGA-III）**。而此时基线末 100 代仅约 0.2%/百代、近乎走平，在收敛预算内填不平该差距——故这是**真实的质量优势（且 EPG 只用一半预算 gen400），而非收敛更慢**。
- **P3（消融归因）**：消融分离两个先验——**仅修复**变体在收敛处几乎等同完整 EPG（repair-only/EPG = 0.997–1.000），故**约束次序修复投影是主驱动**；而**仅热启动**变体在早期领先（gen100 时 warm-start-only/classic 大 K 下最高约 1.046）但收敛后被洗掉，故**可行性保持热启动采样是早期加速器**。

### III-C. K=20 县级应用 County-Level Application at K=20〔Fig. 1，图已生成 `results/figures/fig1_application.png`〕
- **P1（前沿+拐点）**：在主算例 K=20，EPG-NSGA-II 得到 100 点的成本↔风险 Pareto 前沿，其拐点运行于聚合容载比 **1.80**，成本 f₁=**18882 万元/年**、风险 f₂=**114 MWh/年**。
- **P2（一站一策=弹性容载比矩阵）**：拐点是一套空间差异化配置——**11 站配储为主、9 站低容载比+强联络、0 站需 R>2.0**（最大 R\*=**1.96**）：高源荷比站取储能（如 slr2.94→R1.53+4.48MW），低源荷比站取低容载比无储（如 slr0.51→R1.20）。
- **P3（相对刚性 2.0 的节省，应用头条）**：相对**全县统一（刚性）容载比 2.0**（其强制聚合达 2.35、过投资），弹性配置在同风险（EENS=0）下**节省 13.1%**。
- **Fig. 1 中文题注**：`图 1. K=20 县级结果。(a) 成本↔风险 Pareto 前沿（100 点）及拐点（聚合容载比 1.80）。(b) 拐点处弹性容载比矩阵：20 站各自的容载比 R 与储能 P——高源荷比站配储为主，其余低容载比+强联络，无站需 R>2.0。`（英文题注扩写时给）

## IV. 结论 CONCLUSION
- **P1（收束）**：本文提出 EPG-NSGA-II，将两个工程先验算子嵌入 NSGA-II，使高渗透县域电网的容载比规划**既在各规模更快收敛、又随规模增大收敛到越发更优的前沿**。
- **P2（未来工作）**：真实电网标定、能量受限储能建模、以及更多种子上的正式显著性检验（Wilcoxon）留作扩展版工作。
