# 2. 公式与模型修改要求

## 2.1 修正公式 (4)：去掉 aggregate ratio 分母中的 δ

### 当前问题

新版中 aggregate capacity-load ratio 写法类似：

```latex
1.8 \leq \frac{\sum_j R_j L_j}{\delta \sum_j L_j} \leq 2.2
```

其中：

```latex
\delta = 0.85
```

这会导致统一基线 (R=2.0) 被计算成：

```latex
\frac{2.0}{0.85}=2.35
```

于是正文写成：

```text
uniform R=2.0 baseline ... forces an aggregate ratio of 2.35
```

这会造成严重逻辑问题：
如果 aggregate ratio 上限是 2.2，那么统一 (R=2.0) 基线被你自己的约束定义为不可行方案。这样后文再与该基线做 equal-risk comparison 就不严谨。

---

## 2.2 推荐修改

请把 aggregate capacity-load ratio 改为标准负荷加权平均：

```latex
\[
\underline R
\leq
\frac{\sum_{j=1}^{K} R_j L_j^{p}}{\sum_{j=1}^{K} L_j^{p}}
\leq
\overline R .
\tag{4}
\]
```

其中：

```latex
\underline R = 1.8,\quad \overline R = 2.2
```

如果全文暂时仍使用 (L_j) 而非 (L_j^p)，请统一改为 (L_j^p)。原因见下一节。

---

## 2.3 删除或改写 “aggregate ratio of 2.35”

请删除正文中类似表述：

```text
which forces an aggregate ratio of 2.35
```

替换为：

```text
The uniform \(R=2.0\) case is used as a conventional planning baseline, while the elastic solutions are selected within the prescribed aggregate-ratio band.
```

或更简洁：

```text
The uniform \(R=2.0\) case provides a conventional planning baseline for comparison.
```

---

## 2.4 δ 的正确位置

(\delta) 不要放在 aggregate capacity-load ratio 的分母中。
建议仅用于上级电网反送约束：

```latex
\[
\eta \sum_{j=1}^{K} \tilde r_j(P_j)
\leq
\beta R_{220}\delta \sum_{j=1}^{K} L_j^{p}.
\tag{7}
\]
```

正文解释：

```text
The coefficient \(\delta\) is used only in the upstream reverse-power constraint to represent the effective coincidence or transfer coefficient at the upper-level interface.
```

# 3. 统一 (L_j) 与 (L_j^p) 的口径

## 3.1 当前问题

新版中已经定义：

```latex
L_j^p = L_j(1+g)^n
```

但正文又写：

```text
The planning-year peak \(L_j^p\) enters the N-1 risk, while the current peak \(L_j\) sizes capacity and bounds reverse power.
```

这会引起审稿质疑：
论文是规划模型，容量配置、反送约束和风险评估都应面向规划期。如果容量约束用当前负荷，而风险用未来负荷，模型口径不统一。

---

## 3.2 推荐统一方式

全文统一使用 (L_j^p) 作为规划期峰荷。

新增或保留定义：

```latex
\[
L_j^{p}=L_j(1+g)^n .
\tag{2}
\]
```

正文解释：

```text
Here \(L_j\) is the current peak load, \(g\) is the annual load growth rate, \(n\) is the planning horizon, and \(L_j^{p}\) denotes the planning-year peak load.
```

---

## 3.3 需要统一替换的位置

请检查并替换以下公式中的 (L_j)：

### aggregate ratio

由：

```latex
\frac{\sum_j R_jL_j}{\sum_jL_j}
```

改为：

```latex
\frac{\sum_j R_jL_j^p}{\sum_jL_j^p}
```

### 站级反送约束

由：

```latex
\tilde r_j(P_j) \leq \beta R_j L_j
```

改为：

```latex
\tilde r_j(P_j) \leq \beta R_j L_j^p
```

### 上级反送约束

由：

```latex
\eta\sum_j\tilde r_j(P_j)
\leq
\beta R_{220}\delta\sum_jL_j
```

改为：

```latex
\eta\sum_j\tilde r_j(P_j)
\leq
\beta R_{220}\delta\sum_jL_j^p
```

### 年化成本

由：

```latex
c_R R_j L_j
```

改为：

```latex
c_R R_j L_j^p
```

或改为新增容量成本形式，见下一节。

# 4. 修正年化成本目标 (f_1)

## 4.1 当前问题

新版中年化成本类似：

```latex
f_1(\mathbf{x})=
\sum_j
\left(c_RR_jL_j+c_PP_j+C_j^{loss}+C_j^{om}\right)
```

这个写法可能把全部规划容量都计入成本，而不是只计入新增容量。如果论文声称“annualized cost saving”，审稿人可能质疑是否重复计入既有资产成本。

---

## 4.2 推荐修改方案 A：有既有容量数据时

如果文中允许引入既有容量 (S_j^0)，推荐写为：

```latex
\[
f_1(\mathbf{x})=
\sum_{j=1}^{K}
\left[
c_R\left(R_jL_j^p-S_j^0\right)_+
+
c_PP_j
+
C_j^{\mathrm{loss}}(\mathbf{x})
+
C_j^{\mathrm{om}}(\mathbf{x})
\right].
\tag{8}
\]
```

解释：

```text
Here \(S_j^0\) is the existing transformer capacity, and \((\cdot)_+\) ensures that only additional capacity is charged.
```

---

## 4.3 推荐修改方案 B：没有既有容量数据时

如果不想引入 (S_j^0)，保留容量代理成本，但必须明确其含义：

```latex
\[
f_1(\mathbf{x})=
\sum_{j=1}^{K}
\left[
c_RR_jL_j^p
+
c_PP_j
+
C_j^{\mathrm{loss}}(\mathbf{x})
+
C_j^{\mathrm{om}}(\mathbf{x})
\right].
\tag{8}
\]
```

正文必须补充：

```text
The capacity term is used as an annualized capacity proxy rather than an incremental investment accounting model.
```

这样可以避免读者误以为这是完整工程造价模型。

# 5. 明确储能 (P_j) 与反送功率、EENS 的关系

## 5.1 保留残余反送功率定义

新版中已经加入：

```latex
\[
\tilde r_j(P_j)=\max\{0,r_j^0-P_j\}.
\tag{3}
\]
```

该公式可以保留，但需要确保解释准确：

```text
Here \(r_j^0\) is the pre-storage reverse power, and \(\tilde r_j(P_j)\) is the residual reverse power after local storage absorption. \(P_j\) is therefore interpreted as the storage power rating available for reverse-power absorption.
```

注意：
如果 (P_j) 表示能量容量而不是功率容量，不能直接与 (r_j^0) 相减。必须统一为 `storage power rating`。

---

## 5.2 明确储能是否参与 N-1 风险

当前新版风险目标写成：

```latex
f_2(\mathbf{x})=
\sum_j \mathrm{EENS}_j(R_j,T_j,L_j^p)
```

这意味着储能不参与 N-1 供电风险，只用于反送功率约束。这个设定可以接受，但必须明确。

---

## 5.3 推荐方案 A：储能只用于反送吸收，不计入 N-1 firm backup

如果采用此设定，请保持 (f_2) 不包含 (P_j)，但必须补一句建模假设：

```text
In this short-horizon planning model, storage is counted only as reverse-power absorption capacity and is not credited as firm N-1 backup supply.
```

然后风险目标写为：

```latex
\[
f_2(\mathbf{x})=
\sum_{j=1}^{K}
\mathrm{EENS}_j(R_j,T_j,L_j^p).
\tag{9}
\]
```

---

## 5.4 备选方案 B：储能也参与 N-1 支撑

如果希望储能也影响 N-1 风险，请改为：

```latex
\[
f_2(\mathbf{x})=
\sum_{j=1}^{K}
\mathrm{EENS}_j(R_j,P_j,T_j,L_j^p).
\tag{9}
\]
```

并解释：

```text
Storage is credited as available emergency support up to its discharge power and energy-duration limits in the N-1 evaluator.
```

同时 EENS 计算中也要包含 (P_j)。

---

## 5.5 本文推荐采用方案 A

为了避免篇幅过长，建议本论文采用方案 A：

```text
储能只用于吸收反送功率，不作为 N-1 firm backup。
```

理由：

```text

2. 与当前公式结构一致；

```

# 6. 补充 EENS 的最简定义

## 6.1 当前问题

新版中 EENS 仍然更像一个名称，而不是可计算指标。
如果写 `expected energy not supplied`，至少需要说明期望是对 outage states、概率和持续时间求和。

---

## 6.2 推荐加入最简公式

在 (f_2) 前后加入：

```latex
\[
\mathrm{EENS}_j
=
\sum_{s\in\mathcal{S}_j}
p_s h_s
\left[
L_j^p
-
S_{j,s}^{\mathrm{avail}}(R_j,T_j)
\right]_+ .
\tag{9}
\]
```

如果采用“储能不参与 N-1”设定，保持：

```latex
S_{j,s}^{\mathrm{avail}}(R_j,T_j)
```

如果采用“储能参与 N-1”设定，则改为：

```latex
S_{j,s}^{\mathrm{avail}}(R_j,P_j,T_j)
```

解释：

```text
Here \(\mathcal{S}_j\) is the N-1 outage-state set of station \(j\), \(p_s\) and \(h_s\) are the probability and duration of outage state \(s\), and \(S_{j,s}^{\mathrm{avail}}\) is the available supply under the outage condition.
```

---

## 6.3 总风险目标

加入 EENS 单站定义后，总目标写为：

```latex
\[
f_2(\mathbf{x})=
\sum_{j=1}^{K}\mathrm{EENS}_j .
\tag{10}
\]
```

注意相应调整后续公式编号。

# 8. 伪代码修改要求

## 8.1 当前问题

当前 Algorithm 1 有类似写法：

```text
1: P ← WarmStartSampling(D, N); Repair(P); evaluate f1, f2
```

这个写法有两个问题：

```text
1. Repair(P) 没有赋值；
2. 一行塞了多个操作，OCR 和阅读都不清楚。
```

---

## 8.2 必须改成分行形式

将 Algorithm 1 开头改为：

```text
1:  P ← WarmStartSampling(D, N)
2:  P ← RepairProjection(P)
3:  Evaluate \(f_1\) and \(f_2\) for all individuals in \(P\)
```

---

## 8.3 推荐 Algorithm 1 完整结构

请将 Algorithm 1 修改为如下逻辑：

```text
Algorithm 1: Engineering-prior-guided NSGA-II

Input:
    Station data D, ratio bounds, storage bounds, aggregate-ratio band,
    reverse-power parameters, population size N, generations G.

Output:
    Feasible nondominated solution set A.

1:  P ← WarmStartSampling(D, N)
2:  P ← RepairProjection(P)
3:  Evaluate f1 and f2 for all individuals in P
4:  for t = 1 to G do
5:      Q ← SelectionCrossoverMutation(P)
6:      Q ← RepairProjection(Q)
7:      Evaluate f1 and f2 for all individuals in Q
8:      U ← P ∪ Q
9:      P ← FastNondominatedSortAndCrowdingSelection(U, N)
10: end for
11: A ← feasible nondominated individuals in P
12: return A
```

注意：

```text
- Input 和 Output 必须单独成行；
- 不要把所有输入参数挤在一行；
- RepairProjection 必须出现在初始化后和交叉变异后；
- 最终输出必须是 feasible nondominated individuals。
```

---

## 8.4 正文补充 WarmStartSampling

在算法前后补充：

```text
WarmStartSampling generates station-level ratios inside their engineering bounds, projects the load-weighted aggregate ratio into the target band, and assigns initial storage to stations with larger residual reverse-power pressure.
```

---

## 8.5 正文补充 RepairProjection 顺序

请明确写出修复顺序：

```text
RepairProjection clips variables to their bounds, repairs the aggregate-ratio band, checks station-level reverse-power gates, repairs the upstream reverse-power gate, and then performs a final feasibility check.
```

---

## 8.6 必须说明无法修复时如何处理

加入：

```text
If the final feasibility check still fails because all adjustable variables have reached their bounds, the remaining violation is passed to the constraint-domination ranking.
```

---

## 8.7 删除或替换 “one forward pass”

当前如有：

```text
Repair maps each back toward feasibility in one forward pass.
```

请删除或替换为：

```text
Repair performs a constraint-ordered projection followed by a final feasibility check.
```

不要强调一次修复即可闭合，除非有数学证明。

# 9. 实验结果表述修改要求
