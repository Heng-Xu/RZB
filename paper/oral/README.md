contains only this oral-presentation directory and its prompt/current-state records.

[`EPG_NSGA_II_MIND2026_Oral_20261020/`](EPG_NSGA_II_MIND2026_Oral_20261020/README.md).

records are retained there. Earlier delivery aliases are archived inside the
project, with SHA256 records in `validation/cleanup_manifest.json`.

retains two editable Office Math formulas. PDF visual inspection covers the
actual delivered file; the PPTX was validated structurally for Microsoft
PowerPoint, which is not installed in this environment.
