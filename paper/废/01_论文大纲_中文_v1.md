## ★ 贯穿逻辑线（论文的脊梁——写作时每节都要回扣这条线）

分布式光伏高渗透 → 中午净反送把主变推向反向重载 → 现行"全县刚性容载比 2.0"非过投资即留隐患 → 提出**容载比"向下弹性"**：按站间异质把县容载比在合规带内降下来、用配储与联络替代盲目增容 → 这落成一个**县级多站联合的"成本 ↔ N-1 风险"多目标优化**；**县容载比带 + 上级系统潮流把各站耦合成不可分、强约束、随站数指数膨胀的搜索空间** → 正是"可行域随维度骤缩"这一结构，让经典 NSGA-II / NSGA-III 在有限预算下**早期收敛慢、可行解稀** → 我们提出 **FG-NSGA-II（Feasibility-Guided NSGA-II）**：以**可行性修复算子（把解直接投影到近似可行）+ 启发式热启动（初始种群即可行）**引导搜索，让可行性由构造保证、进化预算全花在权衡搜索上 → **应用层**给出省 13.1%、一站一策的县级方案；**算法层**FG 用**一半预算（gen400）即胜过两条 baseline 的 gen800**、等价 **~5–12× 更少代数**（充分收敛后 baseline 大体追平，如实交代）。

**一句话**：问题结构（站间耦合、强约束、大规模）既是经典算法前期收敛慢的原因，也决定了修复与热启动为何见效——**同一处结构，应用价值与算法价值一并成立**。正因如此，本文既不同于套用现成算法的应用论文，也不同于脱离场景的纯算法论文。

## I. Introduction（约 1.5 栏；三段漏斗 + 贡献列表 + 结构导航）
- **(a) 领域铺陈**：高渗透分布式光伏下的反向潮流与容载比规划挑战；两条引证线——反送承载力/容载比导则一条、EMO 在电网规划应用一条。
- **(b) 点缺口**（逐层递进，套用范文"贬低"话术）：现行刚性容载比对全县取同一值、未用站间异质与同时率；已有 EMO 电网规划多为小规模/弱约束；**经典约束处理靠惩罚调参、修复后信息未复用、随机初始化浪费评估预算**，在本类**强约束（反送闸+容载比带+上级潮流）、可行域稀疏、随站数膨胀**的离散规划上收敛慢、可行解稀。
- **(c) 自我定位 + 贡献**（用 1)/2)/3) 编号）：
  1) 把"容载比向下弹性"形式化为**县级多站联合的约束多目标优化**（决策=每站 R+P，目标=年化成本 vs N-1 EENS，约束=反送闸+容载比带+上级系统潮流），并**诊断问题结构**——带与系统约束的耦合使问题不可分、可行域随站数 K 稀疏化，这正是通用 MOEA 在此失效之因；
  2) 针对该结构提出 **FG-NSGA-II**：以**领域定制的可行性修复为主驱动**（利用问题解析结构把搜索约束在可行流形上）、**启发式热启动为早期加速的次要件**，使县级大规模寻优可解——**贡献落在"结构诊断 + 定制约束处理"，而非从零的新算法**（避免被当纯算法论文审）；
  3) 在**公开数据合成的县级基准**上给出双层证据：应用层相对刚性 2.0 **省 13.1%** + 一站一策；作为效率证据，FG-NSGA-II **用一半预算（gen400）即胜过经典 NSGA-II 与 NSGA-III 的 gen800、等价 ~5–12× 更少代数**（充分收敛后 baseline 大体追平，如实交代）。
- 末段：Section 导航。

## II. Problem Formulation（对应范文"形式化 + 基准"，公式密度高，8–10 个编号式）
- **A. 决策变量与容载比弹性**：x=[R₁..R_K, P₁..P_K]，R∈[1.2,3.0]（→主变容量）、P∈[0,6]MW（E=2h 从属）；说明"向下弹性=在带内能降尽降"。
- **B. 目标**：min f₁=县年化成本（资本年金 CRF + 双向 Z4 网损 + 储能 + O&M − 残值，给公式）；min f₂=县 N-1 ΣEENS（未来峰荷 (1+g)ⁿ）。一句注明"为何 cost↔risk 而非 cost↔弃光"（同式坍缩）。
- **C. 三约束（G≤0）**：①逐站反送闸（式，0.85 裕度）②县聚合容载比带 [1.8,2.2]（同时率 0.85，**核心耦合→不可分**）③上级系统潮流（Σ反送≤L_rev，R₂₂₀=1.8）。
- **D. 合成基准算例**：IEEE33 缩放 + PVGIS 三地；每站按四元组抽样——源荷比（`generation-to-load ratio`）、联络度（`tie-line interconnection level`）、峰荷因子、反送时长；主算例 K=20；声明合成非实测。
> 逻辑承接：本节把"弹性"落成可计算的 CMOP，并暴露"带+系统约束→不可分、强约束、随 K 膨胀"，为 III 节的算法必要性铺垫。

## III. Proposed Method: Feasibility-Guided NSGA-II (FG-NSGA-II)（★ 范文所无、本文必加；配 Algorithm 1 + Fig.1 流程图）
- **A. 融合框架**：物理评价器（Z4-LCC compute，3.8ms/次，无需代理模型）+ NSGA-II 搜索器；**约束是"处理"非"求解"**（判定/修复/选择三分，一段讲清）。
- **B. 可行性修复算子 FeasRepair（主驱动）**：一次前向、闭式/贪心地把不可行解投影到**近似可行**（缩放 R 入带 → 逐站补储能/必要时升 R 过反送闸 → 补储能满足系统约束）；强调**不调用目标函数**→不占评估预算，残余越限交 constraint-domination 兜底。**消融证据：repair_only 收敛处处≈FG**。
- **C. 启发式热启动 WarmStartSampling（早期加速器）**：LHS 多样性 + 注入 25% "低 R+0 储"种子，全部经修复 → 初始种群即近似可行。**消融证据：warmstart_only 早期即超经典，但收敛后洗掉**。
- **D. 为何 FG 奏效 + 为何仍需 EA**：大 K 可行域骤缩→随机撞不进→经典早期收敛慢；修复直接构造可行解绕过、使 FG 一半预算即追平 baseline 满预算；但修复只给可行、给不出前沿，权衡仍靠 EA（呼应逻辑线）。
- **Algorithm 1**：FG-NSGA-II 主循环伪代码（热启动→评价→非支配排序+拥挤度+可行性优先→交叉变异→修复→选择）。
- **Fig.1**：融合框架/修复流程示意图（类比范文 Fig.3 的"机制示意图"）。

## IV. Experimental Study（对应范文"结果"；两层证据 + 变体阶梯 + 参数/规模扫描）

- **C. 算法结果（核心创新的效率证据）**：
  - **Fig. 3 ★核心 ＝ 逐代 HV 收敛**（4 个 K 各一子面板、5 变体 mean±std）：一图讲清"FG 早期显著领先（gen100 比值随 K 增至 K=40 的 1.36/1.42）、消融归因（repair-only 全程≈FG、warm-start-only 早期超经典而收敛后洗掉）、收敛后 baseline 追平"——**由压缩句提升为核心整图**；
  - **两优化点消融（各自效果；读 Fig. 3 的 repair-only / warm-start-only 两条曲线 + Table I 两行——明确回答"每个改进点各贡献多少"）**：
    ① **可行性修复算子 = 主驱动**：单开修复（repair-only）即得收敛 HV = 完整 FG 的 **0.997 / 0.998 / 0.999 / 1.000**（K=10/20/30/40，几乎重合），iso-quality 加速比也基本由它贡献；反证——去掉修复、仅留热启动（warm-start-only），收敛回落到经典水平（≈0.99×）；
    ② **启发式热启动 = 早期加速器**：单开热启动在**早期**明显超经典（gen100 warmstart-only/classic = 0.996 / 1.027 / 1.063 / 1.046，K 越大越明显），但优势**收敛后被洗掉**（收敛≈经典）；叠加于修复之上只让 FG 早期轨迹略快于 repair-only、**终值不变** → 只提前、不改质量；
    ③ 归因一句话：可行域随 K 骤缩下，**修复把不可行解直接构造回可行流形**（贡献主要且持续），**热启动令初始种群即近可行**（贡献早期、随收敛消退）；
  - **Fig. 4 ＝ iso-quality 加速比随 K**（FG 达 baseline gen800 收敛质量所需代数 → **4.8–11.8×（约 5–12×）**，预算无关；vs Classic 6.6/4.8/5.3/9.5×、vs NSGA-III 7.5/9.1/11.1/11.8×）；
  - **Table I**：5 变体 × K 收敛 HV + 加速比（以 **3 seed mean±std** 报告离散性；正式显著性检验 Wilcoxon 列为扩展版工作）；**消融变体并入本表加行**（repair-only=主驱动、warm-start-only=早期加速器）；**口径注**：主张为"效率"（更少 gen/NFE/时间），非收敛质量——收敛 HV 差 K≤30 <1%、K=40 才 4.8%，如实披露，堵"多跑即翻盘"；
  - 求解器验证（E2 小 K HV≈1 对 Minkowski parity）+ 可扩展性动机（E4 穷举 K=8=1.38×10¹¹、K≥12 不可枚举、NSGA-II 近线性 K=40≈4 min）各压成正文 1 句。
