市区29座仿真站统一按用户确认的A类规划，样本原类别和既有设备事实另列保留；市区既有及目标转供率50%、上限70%。邳州仍按原B/C类别，既有率28.287889%、目标30%、上限50%。两个方案、两个区县均采用主变退出后保障全部转接后负荷的同一静态研究情景。
