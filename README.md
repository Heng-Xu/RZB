# 徐州地区110 kV容载比弹性指标优化研究

2026-10-01恢复刚性、弹性共同采用增容、储能、10 kV联络三类措施，完成两区县四条路径同步优化。回滚模型锚点为 `eb417e0`，回滚状态提交 `3011fdc` 已推送。

最新[逐年具体措施与有效性审查](docs/2026-10-01站级转供率三措施优化/逐年具体措施与有效性审查.md)及[逐站措施与负荷转接工作簿](docs/2026-10-01站级转供率三措施优化/逐年具体措施与负荷转接审查.xlsx)：采用区县内站级等效负荷配置，转供能力由固定的转接前站级负荷基数乘以转供率确定，新增联络仅提高能力比例。主变供电安全容量按转接后负荷校核。392条站年记录通过复核；刚性每年R≤2.0，两区县弹性每年R>2.0，同方案市区每年低于邳州。

费用要求尚未全部满足：邳州弹性13855.33万元低于刚性19558.17万元，市区弹性17201.60万元高于刚性2818.17万元。市区弹性净增633 MVA、刚性净增100 MVA，额外增容主要受每年R≥2.001的指定条件驱动，不能全部解释为负荷增长的必要需求。当前结果用于仿真审查，未宣称实现全部原要求。

费用阶段达到0.5%认证近优精度；随后固定所选刚性整数布局，在同一费用上界内以0.5%精度优选弹性容载比，最后固定全部整数布局求最小转接量。重复求解的18份CSV逐字节一致。[模型与参数说明](docs/2026-10-01站级转供率三措施优化/模型与参数说明.md)记录精度、范围及代理数据限制。既有率采用邳州28.2879%、市区50%研究设定；独立新增单元7.49106117 MW来自局部原型标定。

此前共同10%实际转出限制结果保留在[历史交付](docs/2026-10-01三措施联合优化/逐年具体措施与有效性审查.md)，本轮取消该限制，采用站级能力预算。
