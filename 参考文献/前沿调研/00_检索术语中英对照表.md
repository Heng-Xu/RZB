# 检索术语中英对照表（English Terminology Glossary）

> 用途：分方向文献检索（尤其英文检索）前统一术语口径，避免直译误检。English 列经 IEEE / Elsevier / MDPI / Frontiers 文献核实（见末尾来源）。
> 口径约束：沿用 DL/T 5729-2023 校正——容载比范围 1.5–2.0、"弹性容载比"为项目内部规划概念（非国标术语）、正向容载比选取 + 反向承载力校核协同。

## 一、核心指标 Core metrics

| 中文 | 推荐英文（首选 / 同义） | 说明 / 检索用法 |
|---|---|---|
| 容载比 | **Capacity-Load Ratio (CLR)** / capacity-to-load ratio | 中国规划专有宏观指标；英文文献多写 CLR。变电容量÷年最大负荷。 |
| 综合容载比 | composite capacity-load ratio | 多电压等级加权。 |
| 变电容量充裕度 | Transforming Capacity Adequacy / transformation capacity adequacy | 容载比的等价表述之一。 |
| 弹性容载比（项目内部概念） | flexible / adaptive capacity-load ratio | **无国际标准术语**；英文检索改用 flexible planning / dynamic hosting capacity 等代理词。 |
| 分布式电源承载力 | **Hosting Capacity (HC)** / DER (PV/DG) hosting capacity；Hosting Capacity Analysis (HCA) | EPRI 定义：不影响电能质量/可靠性可接纳的 DER 规模。 |
| 动态承载力 | Dynamic Hosting Capacity (DHC) | 计及时序的承载力。 |
| 系统级/设备级承载力 | system-level / device-level hosting capacity | 对应 DL/T 2041-2025。 |
| 最大供电能力 | **Total Supply Capability (TSC)** / TSCmax | 肖峻团队术语；配电网安全域 = Distribution System Security Region (DSSR)。 |
| 净负荷 | **net load** | 负荷减分布式出力。 |
| 反向潮流 / 反送 | **reverse power flow** | 反向过载 = reverse overload；反向负载率 = reverse loading rate。 |
| 装机渗透率 | (installed) capacity penetration rate | 分布式装机容量÷峰值负荷。 |
| 电量渗透率 | energy penetration rate / level | 分布式年发电量÷年用电量。 |
| 源荷比 | source-load ratio / DG-to-load ratio | 近似装机渗透率（容量口径）。 |
| 联络度 / 转供能力 | interconnection degree / load transfer capability | 联络度非国标强制指标。 |
| 主变负载率 | transformer loading rate / loading level | 多工况时序统计。 |
| 鸭子曲线 | duck curve | 高光伏净负荷形态。 |

| 中文 | 推荐英文 | 说明 |

| 年费用法 | annual cost method / Equivalent Annual Cost (EAC) / annualized cost | 一次投资折等额年值。 |
| 残值 | residual value / salvage value | 期末成本抵扣项。 |
| 工程造价 | engineering cost / construction cost | 变电站/线路造价。 |
| 成本驱动因子 | cost driver | 回归建模自变量。 |
| 投资决策 | investment decision-making | 精准投资 = precise/targeted investment。 |
