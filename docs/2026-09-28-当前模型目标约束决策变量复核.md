# 当前模型的目标、决策变量与约束复核

日期：2026-09-28。本文说明首轮`regional_revision_run.py`实际执行的错误起点模型；2021年正确仿真初始状态与修正入口见`2026-09-28-2021仿真初始状态纠偏.md`。下文首轮数值不作为正式推荐。

## 1. 时段、范围和输入

`joint_lifecycle_optimizer.solve_layer`对一个区县、一个电压层分别求解2022—2025年路径，2021年为主变配置起点。邳州110 kV起点区域容量为2027 MVA，2021年区域最大正向净负荷731.77 MW；站点主变配置由区域实有总量按2025年站点权重分配，是历史资产代理。市区模型仅覆盖29个站点样本，不代表全市区站点完整台账。各年站点正、反向压力使用静态典型场景估计；区域容载比的分母使用年度区域最大正向净负荷。

## 2. 决策变量

| 变量 | 代码含义 | 是否已进入当前运行入口 |
| --- | --- | --- |
| `x[i,y,p]` | 站点`i`在年`y`选择一对离散主变规格`p`，二元变量 | 是 |
| `t[i,y,p,q]` | 从上年规格`p`转为当年规格`q`，二元变量，决定新购主变投资 | 是 |
| `n[i,y]`、`b[i,y]` | 当年累计储能柜数、累计已安装储能包数，整数变量 | 是 |
| `transfer[y,s,k,i,hub]` | 正向或反向场景`s`中，站点通过既有或新建区域10 kV联络池转出/转入的功率，连续变量 | 是 |
| `built[y]`、`line_addition[y]` | 累计新线条数与当年新增条数，整数变量 | 是 |

区域联络池只表示区县内可转移比例与新增线路总能力，尚未按实际开关、馈线和受端逐条建网络拓扑。正向、反向场景各有独立的转供流量，不表示它们同时出现。

## 3. 目标与求解顺序

主目标是2022—2025年投运措施对应的全寿命成本现值最小：

`min C = Σ新增主变规格投资×主变现值因子 + Σ新增储能柜/包投资×储能现值因子 + Σ新增10 kV线路投资×线路现值因子`。

既有主变和既有联络的历史投资不再计入；既有联络的年度调用没有单独运行费用。`prefer_reserve_at_equal_cost=True`时，在最小费用不变的条件下最大化各年容量/负荷之和；`canonicalize_tie_dispatch=True`时，再在同费用、同容量解中最小化转供量。当前区域运行入口未启用`capacity_first`，故并未先求容载比上限或最少主变容量，也未将会议提出的三个工程分析阶段分别完成。

## 4. 当前主要约束

1. **状态衔接。** 每站每年选恰好一对主变规格，并通过转移变量衔接上一年配置。储能柜数、储能包数不随年份减少，新线条数不减少。
2. **站点功率。** 正向场景使用`0.95 S[i,y] + B_f[i,y] + T_out,f[i,y] - T_in,f[i,y] ≥ P_f[i,y]`；反向场景使用`0.8×0.95 S[i,y] + B_r[i,y] + T_out,r[i,y] - T_in,r[i,y] ≥ P_r[i,y]`。储能有效功率按每柜`min(0.1 MW, 0.215 MWh/场景持续小时)`取值。反向的`0.8`是静态筛查假设，不是已完成的设备运行校核。
3. **区县内10 kV转移。** 既有联络转出上限是初始可转移比例乘本站场景功率；新联络转出上限是新增比例乘本站场景功率，并受`累计新线条数×9.05 MW/条`的全区上限控制。区县内转出总量等于转入总量；因此转移只能重排站间负荷，不能减少区域总负荷。
4. **容载比控制。** 代码给区域主变容量施加`Σ_i S[i,y]≤R_cap×P_region,max,y`；最低容载比默认不设。`P_region,max,y`是年度最大正向净负荷，不以光伏装机、反向峰或站峰之和替代。
5. **可选的基期裕度保持。** `preserve_baseline_forward_margin=True`时，每站还要求`0.95 S[i,y]+B+T_out−T_in ≥ P_f[i,y]+max(0,0.95 S[i,2021]−P_f[i,2021])`。这是为研究“新增负荷由什么措施承担”设置的规划情景，**不是导则容载比定义或导则强制备用规则**；当前区域运行入口没有启用。
6. **可选的容量增长预算、停运恢复比例、容载比下限。** 当前区域运行入口均未启用。停运恢复比例依据不足，不能把代码里的可选参数当作已获认可的规划指标。

## 5. 当前入口与用户要求的差别

`regional_revision_run.py`虽使用2021年起点，却传入`R_cap=2.0`、`allow_capacity_release=True`、`preserve_baseline_forward_margin=False`。邳州2022年区域峰值825.004 MW给出的容量上限仅1650.008 MVA，低于2021年2027 MVA；主变必须减容约377 MVA才能满足硬约束。这使原试算2025年容载比1.591成为减容路径的结果，不能解释为需求驱动的最优推荐。代码中`rigid=True`还强制`R_cap=2.0`，因而直接把`allow_capacity_release=False`切换为不减容会无解。

以2021年起点、不减容、宽松的3.2技术上限（非推荐值）进行对照试算：不保持基期正向裕度时，邳州2022—2025年均保留2027 MVA，正向新增主变与储能投资为零；保持全部基期绝对正向裕度时，邳州2022/2024/2025年分别增加110/60/80 MVA，2025年选2277 MVA、容载比2.381、储能0柜、新线0条，利用既有联络池转移部分站间压力。这说明“是否保护2021年裕度”支配措施需求，须作为可追溯的研究假设单独比选。该对照试算是现有代码的参数扫描，代码会把`R_cap=3.2, rigid=False`标为`elastic`，并不构成已实现的刚弹两方案。

下一版应将2021年容量不减、存量超建议区间的过渡评价、刚性措施集、弹性措施集分开编码；再按同一数据与成本求解逐年方案。源荷比、电量渗透率与净负荷增长率按导则名称和公式计算，当前均不是优化约束或决策变量；不得把静态情景参数改称导则核心指标。

## 6. 对新增负荷承载力约束的判断

当前正向约束只要求“当年可用能力不低于当年站点峰值”。令2021年可用裕度`H_i,2021=max(0,0.95S_i,2021−P_i,2021)`；只要新增负荷未耗尽这部分裕度，最低成本模型就没有理由购买主变、储能或新线路。邳州2021—2025年区域最大正向净负荷增加约224.68 MW，而2021年区县容量按0.95折算后与区域峰值之差约1193.88 MW；该区域差额不能代替逐站裕度或安全校核，但解释了为什么仅凭区域峰值增长并不会自动产生投资。旧版`R≤2.0`属于容量上界，会倒逼压减既有主变，并不是承载力下界。

若要明确比较“新增负荷由主变、配储、10 kV转移中哪项承接”，应先确定各站2021年可用裕度`H_i,2021`及需保留的安全裕度`M_i,y`，再逐年校核：`ΔP_i,y ≤ 0.95ΔS_i,y + ΔB_i,y + ΔT_out,i,y − ΔT_in,i,y + H_i,2021 − M_i,y`。转供增量应相对2021年运行基线计算。安全裕度应来自设备能力、运行标准或显式情景，不得自行命名为导则指标。允许动用全部基期裕度会得到近乎零投资；强制保留全部绝对裕度又会过度推动扩容。应同时核算区域转移守恒、受端主变及线路容量、储能功率和持续时间，并保留零投资的可行结果，不人为要求必须建设某种措施。
