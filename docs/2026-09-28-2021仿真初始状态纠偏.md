# 2021年仿真初始状态纠偏

2026-09-28复核：此前把甲方2021年实有110 kV容量直接分配为优化初始主变，是基准状态混用，应撤销该组新试算的推荐资格。

| 邳州110 kV的2021年量 | 数值 | 用途 |
| --- | ---: | --- |
| 甲方年度表实有变电容量 | 2027 MVA | 历史资产与容量退出量对照，不直接代替仿真起点 |
| 甲方年度表降压负荷 | 731.77 MW | 区域容载比的2021年分母、正向场景标定 |
| 已建立的共同仿真起点容量 | 1453.5 MVA | 2021年规划初始状态、2022—2025措施的容量起点 |
| 已建立的共同仿真起点容载比 | 1.9863 | 1453.5/731.77，符合事先设定的起点不超过2.0 |
| 相对实有容量的仿真基期退出 | 573.5 MVA | 2021年反事实规划设定，按已讨论口径不计退出费用；不表示真实退役 |

共同初始状态原文件为`实验/研究/rebuild_2026/source_audit/planning_2021_common_baseline_stations.csv`及`planning_2021_common_baseline_layers.csv`。逐站主变规格取本地目录，依据估计的2021年站点正向峰和2025年设备分布代理构造；其总容量在2021年场景下尽量接近而不超过区域容载比2.0。2021年逐站真实台账、光伏出力与联络运行状态未完整覆盖，所以逐站容量和早期反向场景必须标为仿真估计，不得写成2021年实绩。

2021年是**状态确定年**：先固定区县范围、历史与仿真容量、站点配置、正向和反向典型场景、储能及10 kV联络初始可用能力和各项来源；随后从2022年开始计算措施增量。2022年后主方案逐站主变容量不减，配储和10 kV转移与必要扩容共同承担新增负荷。2021年12月分布式光伏装机由2023、2024年同月数据几何回推：邳州约141.885 MW、市区约124.276 MW，属于情景估计；市区29站模型容量与全市区实有容量不作差。储能初始零柜、邳州28.29%与市区50%的可转移比例也为仿真条件。2021年反向场景、储能或联络缺少实测值时，逐项记录依据并做敏感性，不用2025年状态直接冒充。

旧`regional_revision_run.py`默认诊断入口调用`baseline_historical_proxy.build()`，把2027 MVA实有总量重新分配为仿真起点，同时允许2022年以后免费减容；其原输出目录`regional_revision_2026_09_28/`只保留为错误基准诊断。新入口`regional_2021_initial_run.py`读取上述共同初始状态，禁止2022年后减容，并核对2021年正反向静态场景。其结果、光伏回推和转移比例的来源状态见`实验/研究/rebuild_2026/source_audit/capacity_release_simulation/regional_2021_initial_2026_09_28/README-STATUS.md`。该新试算尚未构成正式逐年推荐或通用矩阵。
