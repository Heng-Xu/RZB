# 核心指标口径与市区、邳州数据标定

日期：2026-09-28。状态：建模修正前的口径锁定；数值重算尚未开展。

## 依据和统计边界

本轮按项目保存的2025年4月《配电网规划设计技术导则（修订稿）》定义研究指标，按DL/T 2041—2025核对反向负载率及承载力术语。前者是修订稿，报告不得把其条号或建议范围标为现行DL/T 5729—2023的已核实条文。两地成本优化和推荐矩阵只涉及市区、邳州；源荷和电量指标按各自区县统计范围计算。110 kV与35 kV是不同电压层，不把上下级容量、负荷或电量直接相加。市区29站时序样本不是全市区统计边界。

以下锁定的是**标准指标的名称、定义和公式**。输入量可以由典型场景估计，但估计方法、年份及范围必须列入来源栏；不得改变标准公式或将估计量重新命名为另一个核心指标。

| 指标与出处 | 锁定的定义和计算 | 本项目的输入要求 |
| --- | --- | --- |
| 净负荷，修订稿3.1.13 | 同一区域、同一电压等级公用变压器在同一时刻输送功率之和；向下为正，向上为负。区域峰值为`max_t Σ_i N_i(t)`，反向极值为`min_t Σ_i N_i(t)`。 | 区县、年度、电压层及同一场景时刻一致；站级各自峰值不得相加称为区域峰值。 |
| 容载比，修订稿3.1.16、6.2.2 | `R_s=Σ_i S_{e,i}/P_max^+`；分子为规划区域该电压等级公用变压器总额定容量，分母为该电压等级最大正向净负荷（网供最大负荷）。 | 原始年度统计与规划后容量分别标识；反向峰值的绝对值不进入容载比分母。 |
| 分布式电源装机渗透率（源荷比），修订稿3.1.18、6.5.4 a） | `R_p=P_DG/P_L,max`；分子为同范围已并网分布式电源装机容量，分母为所供用户最大用电负荷。 | 区县边界统一；在途容量不计入现状装机。不能用光伏瞬时出力或最大正向净负荷替代公式中的量。若其他分布式电源存在，须计入分子。 |
| 分布式电源电量渗透率，修订稿3.1.19、6.5.4 b） | `R_i=E_DG/E_L`；分子为同范围年度分布式电源发电量，分母为用户年用电量。 | 两项必须同县、同年；装机容量、峰值功率和少数典型时刻不能替代年度电量。 |
| 年最大净负荷平均增长率，修订稿6.2.2表2 | 对同一电压等级、同一区县的年度最大正向净负荷序列计算增长率。修订稿列出指标和分档，本项目所用加权规则属于研究计算规则，不能称为导则原式。 | 2021—2025共四个同比增长率，可形成2025年的四年加权值；2022—2024若无更早年度资料，不能各自声称已有四至五年历史加权值。 |
| 转供能力，修订稿3.1.11 | 元件停运时通过本级或下级电网转移负荷的能力。 | 本轮区域优化把“现有可转移比例”设为基于实际数据估计的模型输入，新线提高可转移容量；35%和50%均不是导则规定值，也不是已核定的工程转供能力。 |
| 反向负载率，DL/T 2041—2025第3.6、6.4条 | 流经变压器的反向输送功率与额定容量之比；允许值应按变压器运行方式确定。 | 不把所有站的总容量统一乘0.8视为完整标准校核；原设备表的“负载率(%)”需另核其计算式。 |

## 2025年区县最大用电负荷的静态标定

源文件：`实验/研究/data/tuomin/电网建模数据_Agent整合版_V1.2/2025设备负载统计表.xlsx`的“主变1”表，以及同目录的《近5年容载比.xlsx》《逐月分县分布式光伏.xlsx》《光伏8760小时数据.xlsx》。光伏月表的“万千瓦”单位按项目已确认口径使用；8760曲线是统一场景曲线，非两地分布式光伏实测出力。

1. 县域共同时间点：主变表的2025年最大调度负荷时刻为7月5日21:10。110 kV记录按区县求和，邳州956.45 MW、市区1528.82 MW，分别与年度容载比表的2025年降压负荷相等。所给光伏曲线在21:00系数为0，故这是用户用电负荷的夜间候选标定点。
2. 日间共同时间点：主变表还给出8月20日12:40的“全社会最大负荷时刻”记录。110 kV区县主变净负荷和为邳州254.26 MW、市区1497.83 MW。该场景按当月已并网容量和同一时刻的光伏出力系数加回光伏功率；月末容量用于月中时刻需做前月值与当月值敏感性。光伏曲线为小时级，12:40的取值规则必须预先固定。
3. 另选夏季高用电白天、春秋高光伏低负荷等场景。前者参与最大用户负荷估计；后者用于反向承载压力，不将低负荷与独立出现的最大光伏出力相加后称为实测用户最大负荷。
4. 对每个用于用户最大负荷的场景，计算`L_c(s)=N_c(s)+P_DG,c(s)`，有其他分布式电源或储能充放电时按实际功率平衡补充；取`max_s L_c(s)`作为静态研究的`P_L,max`估计。分子用同年度年末已并网装机。该结果按标准公式计算，但分母来源写为“区县典型场景估计”，不得称为全年实测最大用电负荷。

2025年站表各站自己的年度最大负荷不同时发生，不能直接求和。市区29站时序样本峰值1307.315 MW也不能直接代替全市区1528.820 MW。邳州110 kV有效逐时样本峰值951.660 MW与区县年度值956.450 MW的差异保留为覆盖核验，不把样本直接覆盖原表。

按上述静态场景及2025年区县分布式光伏年末装机重算，邳州最大用电负荷估计956.450 MW、源荷比1.630653；市区最大用电负荷估计1545.195 MW、源荷比0.317876。另以月度装机、8760光伏曲线和站点净电量估计，同年度电量渗透率分别为40.28%、8.69%。详细输入、覆盖外推与补值小时见`实验/研究/rebuild_2026/source_audit/capacity_release_simulation/regional_revision_2026_09_28/2025区县导则指标估计.csv`。这些数值按标准公式计算，但分子和分母中的发电量、用户电量属于估计，不得写成原始实测统计。

## 其他仍需核定的数据条件

| 条件 | 当前证据 | 进入正式矩阵前的处理 |
| --- | --- | --- |
| 2021—2022年区县光伏装机 | 分县月表从2023年开始；2025年后另有2026年部分月份。 | 优先补原统计；若回推，逐年标注模型情景并做增长率敏感性，不写成历史实测。 |
| 光伏以外的分布式电源 | 当前分县月表只登记分布式光伏。 | 核对两地是否有需要计入`P_DG`、`E_DG`的其他并网分布式电源。 |
| 年度分布式电源发电量和用户用电量 | 当前报告未有同范围的直接年度电量闭合记录；时序和统一光伏曲线可产生估计。 | 优先查原始电量统计；若用时序估计，列出缺时补齐、月度装机及场景曲线，并将结果标为估计，不以装机比替代电量渗透率。 |
| 历史净负荷场景 | 年度汇总有2021—2025年峰值；站级完整时序主要是2025年，早期站级时刻与分布由模板缩放。 | 年度统计和历史场景分列；早期时序不称实测。 |
| 四至五年加权增长率 | 现有2021—2025年峰值可计算2025年的四个同比值。 | 权重须在计算前明确，建议从早至近取1:2:3:4；这一权重是研究设定。早期年度若没有足够历史窗口，矩阵不得填写伪四年值。 |
| 市区全区与29站样本 | 市区原年度统计为全区；模型只有29站逐时样本及仿真容量。 | 区县指标用全区原表与全区光伏数据；站级优化结果标注29站，不混合成同一统计值。 |
| 2025设备表“负载率” | 原表列有MW最大负荷、MVA容量和百分数；例如34.64/126×100%=27.49%。 | 报告保留原表口径，并核对功率因数及逐台运行方式后，才把它用于标准运行负载率结论。 |
| 反向运行及10 kV转供 | 0.8反向系数受运行方式限制；停运恢复比例无可靠依据；市区、邳州初始可转移比例可从现有数据估计。 | 删除停运恢复比例约束后重求模型。区域优化阶段以市区50%、邳州35%作明示情景假定，并扫描其变动；新线按新增有效MW与条数计费。工程落地另核实际馈线、开关、受端余量。 |
| 线路和储能造价 | 当前线路使用44.543万元/km；会议要求90%架空+10%电缆基准并给工程依据。 | 按工程范围和报价重建基准，两个成本比例系数作为敏感性条件，不作为标准指标。 |

## 矩阵准入规则

正式核心列只使用上表标准名称和原公式。原“光伏出力代理和/毛负荷代理和”“光伏装机/110 kV降压峰”“最大站反向峰”“95%峰值持续时间”“成本比系数”都不得以源荷比、区域反向极值或导则指标之名进入核心列；如确需保留，放入模型输入/情景说明并标明来源与用途。净负荷绝对峰可用于设备压力筛查，容载比分母仍为最大正向净负荷。旧矩阵按源荷比1分档及由此形成的相关性、通用推荐范围，在新口径重算前暂停使用。

## 建模引用与成本边界补充

修订稿7.1.2规定近期逐年预测及中期、远期预测的时间安排；典型日正向负荷与反送场景见7.1.3。区域10 kV转供的关联条文是9.2.1.2，其指出能力取决于主变和线路裕度、分段及联络；该条同时提出原则上不设置变电站间中压专用联络线。因此“新建线路”在模型里是提升区域中压网络联络能力的规划措施，不应直接写成新建站间专用联络线或已完成工程可行性验证。

存量容量可在规划模型中零成本退出；新购容量、线路和储能仍按增量投资计费。两项成本比例系数分别依据同一服务量下的基准工程成本计算“主变/线路”和“增容/配储”，基准数值由实际估价得出，不能先人为归一为1。比例变化只作敏感性情景，不属于导则核心指标。
