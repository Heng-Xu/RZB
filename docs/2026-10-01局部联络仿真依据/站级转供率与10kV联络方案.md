# 站级转供率与10 kV联络等效建模方案

确定采用“站级负荷基数×转供率”的等效能力模型。当前没有全区县既有馈线、分段和联络拓扑，不以补齐这些数据为建模前提。新增线路只提升等效转供率；局部线路案例用于标定新增一个独立联络单元的增量。

主变增容、储能、10 kV联络共同参与刚性、弹性优化。年度求解器已接入站级等效能力约束，以区县内各站转出、承接和新增单元数量直接优化。旧10%限制结果保留用于对照；本轮结果入口为[站级三措施优化](../2026-10-01站级转供率三措施优化/模型与参数说明.md)。

以单站原正常供电范围为统计边界，是结合上述条款作出的研究口径。“宜”是推荐要求；比例区间支持规划参数的选择，不是具体站的既有能力实测值。本模型以该口径设置等效规划能力，实际优化用途仍是区县内正常负荷转接，不将事故恢复量混入年度负荷优化，也不声称完成了全区县逐个停运工况校核。

## 2. 确定负荷基准乘数

B_i,t = 年度规划工况下站i原供电范围的转接前总负荷，单位MW。

B在优化前固定，并对同区县的刚性、弹性方案采用同一数值。增容、储能或转接决策不改变B；基数不使用主变容量，不使用转接后的负荷，不使用六条馈线的平均值。

当前可复用的站级输入为estimated_station_forward_peak_mw。它来自站级正向功率峰值模板和年度负荷比例，市区还经过区县边界校准；属于站级总负荷的仿真代理，不是已经测量确认的供电区域毛负荷。参数文件及参照CSV明确记录此状态，避免把正向净潮流峰值称为实测区域总负荷。

前版5.586297 MW仅保留为局部馈线规划负荷的讨论资料，不作为本轮站级转供率的分母。

## 3. 既有能力由转供率确定

Q_i,t_existing = rho_i_initial × B_i,t。

既有率是情景输入，既有线路细节在本轮不展开；不要求先从全区县既有馈线逐条求出Q，再反算rho。站间分配变量表示区县内的等效负荷转接，不把任意站对都描述为已经核实存在实际联络。

保留此前配置：邳州初始率0.28287889057972354、目标率0.30；市区初始率0.50、目标率0.50。本轮不重新估计这两个初始率。邳州初值源自局部六馈线样本9.983428/35.292234，迁移为站级等效初值是研究假设；市区50%也是既定仿真假设，两者均不是全区县既有能力实测结论。导则推荐区间用于检查目标与所选规划上限的口径。

## 4. 单条新增线路的局部数据标定

选“墩振线23—24杆拟分段，24杆以下负荷由河湾变新专用10 kV出线承接”为独立新增单元原型。按现有节点、边和节点负荷种子：

- 可隔离下游25个节点。
- 2025馈线压力负荷种子合计7.49106117 MW。
- 本轮固定单元增量DeltaQ_line = 7.49106117 MW，展示为7.49 MW。
- 新单元独立承接该区段，不把既有河炮共享馈线的余量重复计入。

这是基于具体可切换区段的等效增量标定，不是六条线路的简单平均，也不是导则规定的单线容量。原型迁移至其他站时标明为仿真假设；该增量以新增通道能够独立承接原型区段为条件，受端站容量仍由优化校核。普通新联络若继续共用原有瓶颈，不能自动享有这一完整增量。

复核函数：rebuild_2026.new_line_section_audit.designed_new_line_section()。复核输入为node_master.csv、feeder_master.csv、base_debug_edges.csv、node_load_seed_pf095.csv；参数JSON保存SHA256与原型区段说明。

## 5. 新增线路只提升转供率

单个独立新增单元对站i在年度t的原始提升量为：

DeltaRho_i,t = DeltaQ_line / B_i,t。

rho_i,t_effective = min(rho_i_ceiling, rho_i_initial + n_i,t × DeltaRho_i,t)。

Q_i,t_cap = rho_i,t_effective × B_i,t
          = min(rho_i_ceiling × B_i,t, rho_i_initial × B_i,t + n_i,t × DeltaQ_line)。

n为在役新增独立单元数，建设状态逐年保留。规划率上限在参照接口中取A+/A类70%、B/C类50%，是基于推荐区间的研究控制选择。

固定的是一条新增单元的MW增量，不是每条线路统一增加若干百分点。站负荷基数不同，提升百分点不同；年度负荷基数增加时，同一新增单元的比例贡献下降，不让单线能力随区县负荷自动放大。达到所选率上限后，超出部分不再计入本轮有效增量。

Q已经包含新增单元贡献，不能随后再加一次n×7.49 MW，也不能因建线扩大B。本轮采用简化的站级等效模型，sum(n)=2N，每条项目对应两个站端并只计一次费用。端点计费配对与负荷分配在求解后生成，不是实际线路路由；本轮不据此报告逐线路同时转接能力或利用率。

例：B=60 MW，初始率30%，既有能力18 MW；一个新增单元提高12.4851个百分点，达到42.4851%，能力25.4911 MW；两个数值都使用同一60 MW基数。

## 6. 不足时建设与实际转接

Q_i,t_req = rho_i_target × B_i,t。

DeltaQ_i,t_gap = max(0, Q_i,t_req - Q_i,t_existing)。

若启用目标能力要求，优化约束Q_i,t_cap >= Q_i,t_req，并选择新增独立单元补足缺口。若目标不另设硬约束，是否新建由负荷转接需求和费用比较决定。基数和初始率相同，不保证所有区县或年份都需新建。

正常实际转出量q_out_i,t <= Q_i,t_cap；区县sum(q_out)=sum(q_in)。能力上限不等于必须转接的负荷量。

为避免双端项目重复使用能力，区县所有站超出既有预算的实际转出量之和不得超过N×7.49106117 MW。站端关联能力可在不同工况由不同端使用，但一个项目的同年度实际新增预算只计一份；不设置具体站对路由。

P_i,t_post = P_i,t_before - q_out_i,t + q_in_i,t。

受端主变、储能与已约定的供电安全容量按转接后负荷校核；区县总负荷守恒，区县容载比分母不因内部转接下降。既有能力与新增贡献只累计一次。原模型额外10%的使用上限不能继续覆盖新接口，否则提升后的转供率无法体现到可用转接能力中。

## 7. 交付与实现状态

- 站级参数接口：实验/研究/rebuild_2026/station_transfer_equivalent.py。
- 固定参数与来源：站级等效转供参数.json。
- 逐站逐年基数、既有量、目标缺口和增加一个单元的参照：逐站逐年转供基数与单线增量参照.csv。
- 表内单站需要单元数用于能力缺口检查，不可把两端站数直接相加当作全区县线路项目数。
- 参照表沿用旧年度结果中的固定站负荷输入，仅计算能力参数与单单元变化，不是新的优化结果。

复现：在实验/研究下运行python -m rebuild_2026.station_transfer_equivalent生成参数参照，运行python -m rebuild_2026.joint_shared_measure --case station_rate --breakthrough all_years重算年度优化。
