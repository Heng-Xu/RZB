# 区域转供优化首轮建模诊断结果（暂停作为推荐方案）

日期：2026-09-28。结果范围：2021年资产为共同起点，逐年优化2022—2025年110 kV规划；邳州为主要案例，市区29站为补充样本。旧版v4冻结结果未覆盖。机器可读结果见`实验/研究/rebuild_2026/source_audit/capacity_release_simulation/regional_revision_2026_09_28/`。

**2026-09-28复核结论：本文件的“推荐”仅指错误起点试算中的数学最优解，不作为报告中的正式推荐容载比或工程方案。** 该试算把2021年实有容量2027 MVA误作已确认的仿真初始状态；已确认的共同规划起点实际为1453.5 MVA、容载比1.986。程序还允许2022—2025年免费改小主变，在年度`R≤2.0`硬约束下形成2025年1.591的结果。应从已确认的2021年规划状态重新求解，详见`2026-09-28-2021仿真初始状态纠偏.md`。

## 本轮模型口径

- 目标为2022—2041年增量投资、固定运维和到期更新费用折至2021年末的最小现值；沉没投资不再计入。存量主变容量允许零成本退出，之后重新购置仍计费。
- 区域内部110 kV站间通过10 kV网络调配正向负荷和反向光伏压力。每站现有可转移上限为对应典型场景压力的初始比例；不足时可按每条9.05 MW新增联络能力购建，单条3 km、暂按44.543万元/km计。正向和反向典型场景分别校核，不要求是同一时刻。受端主变容量约束、区域转移功率守恒与新线容量约束同时进入优化。
- 邳州比例由现有六条馈线、三处跨站联络的2025年电流源端静态筛查估计：可转移上侧值9.983428 MW/六线电流等效功率35.292234 MW=**28.29%**。这是样本比例向区域优化的外推情景，不代表全部邳州馈线实际具备该比例。市区初始比例按会议情景假定**50%**。模型所称“新线”是区域中压网联络能力增量，非已选址的站间专用联络线。
- 删除了无依据的“停运恢复比例”约束。反向变压器能力仍沿用`0.8×0.95×在役MVA`的保守静态筛查，不能作为逐台运行方式合格证明。容载比始终为同范围在役公用主变容量/最大正向净负荷；反向峰不进入其分母。

修订稿7.1.2为供需预测期限要求，典型场景对应7.1.3，转供能力的直接关联条款为9.2.1.2。该条还指出原则上不设站间中压专用联络线；具体工程须选取普通馈线联络、分段或其他合规形式，再做潮流与设备校核。

## 两项实际基准成本比

取本地投资表第21行“50 MVA替20 MVA”工程静态总投资1151万元，按新增`(50−20)×0.95=28.5 MW`服务量折算；新线按3 km×44.543万元/km和9.05 MW能力折算；储能按10柜210.456262万元、每柜0.1 MW/0.215 MWh及邳州样本典型3小时压力折算。三项基准投资分别为**40.386、14.766、293.660万元/有效MW**。2025年同一投运时点计入各自寿命、更新及运维后：

- 主变/线路基准成本比 `κ_TL=2.735`；主变和线路寿命及运维规则相同，现值比与投资比相同。
- 增容/配储基准成本比 `κ_ES=0.0813`；若只看首次投资，比值为0.1375，储能在研究期内需更新，因此进入目标函数的现值比更低。

具体为`κ_TL=(1151/28.5)/(133.629/9.05)`；`κ_ES=[(1151/28.5)×f_T,2025]/[(210.456262/(10×min(0.1,0.215/3)))×f_S,2025]`，其中`f_T,2025=0.872142`、`f_S,2025=1.474539`为模型全寿命现值因子。这两个数值由价格和同等有效MW服务量求得，基准没有归一为1。

分别将两项**实际基准比**改变±20%，保持主变基准不变，通过调节线路或储能价格重求邳州四年路径。四组情景的在役容量、容载比和措施均与主案例相同，路径新增费用仍为0；这是因为基准情景可用已估计的零增量成本区域转移能力。该结果说明本案例在此价格区间不敏感，不能据此推论通用矩阵不受价格影响。线路44.543万元/km只有90%架空、10%电缆的暂定折算说明，缺少可追溯的两项工程单价及开关、保护费用；造价边界必须随报告明示。

## 校核与继续使用的边界

独立审计核对了3个案例、12个年度结果、552个站点典型场景约束，以及转移守恒、初始比例、新线容量、年度容载比和费用复算，状态`PASS`。求解器对三个案例和四个成本比情景均返回已证明最优。结果仍是静态规划情景：邳州六线比例向全区外推、2021—2022年光伏回推、2025年以前站级反向压力和D95模板、线路造价及市区29站覆盖均属于估计条件。不能把区域枢纽流量当成已经确定的具体馈线操作。

## 通用参数矩阵

另构造2021年用户最大负荷100 MW、两站初始主变容量合计160 MVA的标准区域，独立于市区、邳州站点资产。按标准定义计算源荷比和电量渗透率，扫描源荷比`0.5/1.25/2.0`、年最大净负荷平均增长率`−2%/3%/8%`、初始可转移比例`0/15%/30%`、甲站光伏装机占比`65%/80%`，共54种组合。用户年负荷率暂按55%、光伏等效发电小时1200小时；2025年中午出力按装机80%和用电负荷夜间峰30%构造典型场景。两项成本比取上节实际估价基准。逐年要求容载比落在修订稿建议的`1.5—2.0`区间内，重求2022—2025年最小费用路径。

54个2025年刚性条件试算值的容载比为`1.510—1.843`；15个场景选择新建10 kV联络，3个场景选择配储，其中1个同时选择联络与配储。矩阵同时列出规划期扩容投资、存量容量退出、线路及储能措施，中文核心列沿用导则名称。成本纯最优但未加1.5下限的诊断矩阵另存档。机器可读表沿用初版文件名`generic_matrix/通用推荐矩阵_导则指标名称.csv`和`generic_matrix/generic_annual_paths.csv`，54个场景、216个年度行已逐项核验；其中“推荐”字段在新模型重算前只能解释为该刚性约束下的数学选择。该矩阵是**明确假设下的通用参数外推**，不是从两个地区数据统计回归得到的全国通用阈值；电量渗透率在本轮固定发电小时和负荷率下随源荷比联动，不宜据此作独立因果解释。

后续写报告时应使用本轮结果文件，并把参数、估计边界与逐年措施同时展示；核心指标名称、定义沿用`2026-09-28-核心指标口径与数据标定.md`，不能将代理变量改名为导则指标。
